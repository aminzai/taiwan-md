## 🔍 本次結案順帶發現的結構問題（給下次 harvest）

**harvest 的留言掃描會漏掉巢狀回覆**。證據：本次在 @haoyingmiao 留言的 permalink 頁看到 **@xiesuqin45**（「我朋友一樣有力晶，還很開心興奮的告訴我們這件事，事後賺很多」），這個帳號在 8/5、8/6 兩份 harvest log 裡**完全沒出現過**。原因是 harvest 掃 `[data-pressable-container]` 只拿得到 top-level 留言，巢狀回覆要點進該留言的 permalink 才會渲染。

同一結構也解釋了為什麼 8/5、8/6 log 裡有 8-9 個 handle（littlefish_lee／huwenxian54／michael.tsai.1690／kevin\_\_\_0112／a0912597052／wciren／healling2026／jasonbosox）今天在 top-level 掃不到——它們可能一直都是巢狀層，也可能已被作者刪除，現行掃描法無從區分這兩者。

**candidate（給 self-evolve / SPORE-HARVEST-PIPELINE）**：留言掃描加一層——對每則 top-level 留言讀出它的回覆數，回覆數 > 0 時進該留言 permalink 補掃巢狀層。否則 harvest 記錄的「留言全貌」永遠只有第一層，而且**漏掉的部分不會留下任何痕跡**（REFLEXES #82／#69「儀器只看見存在、看不見缺席」在 harvest 層的又一個 instance）。
