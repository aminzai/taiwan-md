### Spore #148 本體（Threads 主貼 — 不含連結，self-reply 放 URL）

```
你知道嗎？🐢

宜蘭外海那座龜形的島，幾乎每個宜蘭人都看著它長大。從雪隧開出來往右一瞄，看見它就知道快到家了。

但有一個人從沒把它當風景。黃陳裕阿嬤在島上住到三十三歲才搬到頭城，受訪時已經六十八歲。她記得當年為什麼非走不可：島上沒水沒電，還發生過嬰兒出生就夭折的事，為了下一代只好離開。

1977 年國防部封島，龜山島變成軍事管制區，一封就是二十二年。岸上的宜蘭人天天看著它，卻連登島都不行。

差別在這裡：岸上的人看得到、上不去；真正在島上長大的阿嬤，回不去了。她說：「龜山人無這座島不行。」搬到頭城三十年，她每天晚上作的夢，還是龜山島上的一切。

人在岸上睡了三十年，夢卻從沒上岸。
```
