## 孢子本體（Threads 主貼 / X 主文）

```
你知道嗎？🎹

有個台灣歌手卡了七年，寫不出一張自己的中文專輯。他寫歌全靠靈感，硬逼也擠不出來，那幾年他只說「我都在房間裡」。

他一直是這樣寫歌的。有一次一個人去印度，在孟買一間簡陋的旅館撿到一把壞掉的吉他，就這麼哼出一整首歌的雛形，錄進手機傳給製作人陳建騏。

後來某次在陳建騏的音樂會後台，他摸到一台從沒拿來寫歌的鋼琴。他說：「真的好久沒彈，好陌生，但隨便彈著彈著發現自己很想繼續彈下去的感覺。」

那份陌生，反而繞過了卡住的地方。2024 年他發了《My Nova》，十首全新的歌，全用他更自在的英文寫成。

他叫柯智棠。原來把自己寫回來，靠的是換一件陌生的樂器，加一種更自在的語言。
```
