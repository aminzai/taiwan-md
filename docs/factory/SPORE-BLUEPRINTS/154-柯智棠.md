## 孢子本體（Threads 主貼 / X 主文）

```
你知道嗎？🎸

2013 年，一個大學生被同學起鬨報名，自彈自唱 Coldplay，居然拿了海弦獎冠軍。隔年那支破百萬點閱的金士頓廣告〈It Was May〉也是他唱的，只是那首歌不是他寫的。

他叫柯智棠。兩張陳建騏製作的專輯，兩度入圍金曲最佳國語男歌手，接著他七年沒再交出一張自己的中文專輯。

大家說他消失了七年。其實他沒消失，這期間他跟劉若英合唱、替電影寫過主題曲，他只是寫不完一首真正屬於自己的中文歌。他講得很白：「其實就是中文專輯寫不出來。」

直到某次在陳建騏的音樂會後台，他摸到一台從沒拿來寫歌的鋼琴，換成他更自在的英文，才把自己寫回來，寫成一張全英文的《My Nova》。

2025 年，讓最多人記住他的〈神的回信〉拿下金鐘，偏偏又是替一齣客家劇唱的。唱別人的歌，他很早就會了；寫自己的話，他花了七年。
```
