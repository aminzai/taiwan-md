# Spore #155 Fact Blueprint — 台北吸菸室

## PICK

**核心角度**：從最近台北幾個地方出現的戶外負壓吸菸室開始，回看四十年菸害防制如何讓菸從國家的生意、室內的日常，逐步移到街頭的指定空間。重點是引導讀者理解政策發展足跡，不把玻璃屋寫成對市府或吸菸者的控訴。

**Hook anchor**：「你有好奇過，最近台北幾個地方出現的吸菸室嗎？」

**讀者帶走**：從 1984 年民間拒吸二手菸運動、1997 年《菸害防制法》、2009 年室內公共場所全面禁菸，到 2026 年戶外負壓吸菸室，菸的活動範圍一圈圈縮小；吸菸室是這段歷史走到戶外的新節點。[^hpa]

**Hook tier**：Tier 1b。從讀者近期可能在台北街頭看到的新設施提問，再以時間軸與兩條統計線回答「它為什麼出現」。

### 查核護欄

- 不寫「世界首創」；官方範圍是「全國首創」。
- 不把「負壓」寫成完全安全或完全阻絕二手菸，只寫氣流控制原理。
- 不使用「一座 150 萬元」：那是議會答詢中的規劃估算，不是逐座決算。
- 27.8% → 3.2% 僅指室內公共場所；48.9% 僅指室外非禁菸公共場所，不混為整體二手菸暴露率。
- 不把吸菸者寫成被驅逐、低等或妨礙市容的人；焦點留在公共空間如何分配。

## WRITE

### Threads／X 共用主文

```text
你有好奇過，最近台北幾個地方出現的吸菸室嗎？🚬

西門町、心中山一帶開始全面禁菸時，街頭也多了戶外負壓吸菸室。門一開，空氣往裡走，濾網接住菸霧，把原本散在騎樓與路口的吸菸集中到指定空間。

這些玻璃屋，其實站在一條很長的時間線末端。1937 年松山菸廠動工，1958 年長壽菸上市；菸曾是國家的專賣生意，也是辦公室、火車、餐廳裡的日常背景。

1984 年，因菸害切除一片肺葉的嚴道參與成立董氏基金會，孫越也開始推動「人人有權拒吸二手菸」。1997 年《菸害防制法》上路，2009 年室內公共場所全面禁菸，2023 年再擴大禁菸範圍。

改變留在數字裡：2008 到 2024 年，室內公共場所二手菸暴露率從 27.8% 降到 3.2%；室外非禁菸場所卻仍有 48.9%。

於是 2026 年，菸的足跡從國家的生意、室內的日常，走到街頭的一格指定空間。吸菸室不只是玻璃盒子，也是台灣重新分配公共空氣時，最新寫下的一站。
```
