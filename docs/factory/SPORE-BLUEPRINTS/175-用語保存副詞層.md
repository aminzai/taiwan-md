## 孢子本體

<!-- prettier-ignore-start -->

```
你知道嗎？🔍

這幾天有人在脆上問：為什麼大家都不太用「蠻」了，都在講「挺好的」？四萬多人看，留言區滾出一整串清單，挺、肯定、行吧、具體、體現、聯繫、素質、流量。

我們一條一條去查教育部辭典。十一個詞裡有十個查得到。辭典給「挺」的例句是「他人緣挺好」，書證出自清代小說《兒女英雄傳》；「看情形肯定會下一場大雨」也在裡面。查不到的只有一個：「流量」拿來指人氣。

不過這不代表大家在小題大作。辭典能證明的是這些詞老早就有，證明不了台灣人平常這樣講。變的是使用頻率，所以每條詞條都把兩邊說法並排，讓你自己判斷。

這輪新收 15 個詞：邪修、薅羊毛、暈碳、漂亮飯這幾個新流行語，加上挺、肯定、行吧、具體這排副詞。還有三個誤判翻案，素質、體現、聯繫，台灣本來就在用。詞庫現在 2,409 條。

不想當支語警察，只想當那個大家吵完會去查的字典。

查詞庫 👉 https://taiwan.md/terminology/
```
