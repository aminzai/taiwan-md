## ⚠️ 校正記錄 — 「大幅度下降」這句話的數字校正（給哲宇看）

哲宇原話「近年教育與文化的預算比例大幅度下降」在數字上**站不住**，兩版孢子都刻意避開這個框架，改寫成可驗算的講法：

- 教科文占比是**緩降**（19.7% → 18.3%，十年最低沒錯，但十年只降了 1.4 個百分點，不是「大幅度」）
- 文化部主管預算金額本身是**上漲**的（165 億 → 273 億，+65%），問題不是「被砍」，是「漲了也還不到總預算 1%」
- 教育部主管預算 115 年度看起來從 3,606 億（114 年度）掉到 2,659 億，是財劃法修正後補助改列（同年「直轄市及縣市政府」那一列從 1,865 億升到 2,501 億），**不是教育被砍**——兩版孢子都沒有觸碰這條 114→115 年度落差，避免誤用

真正支撐得住的講法是：**占比創十年新低**＋**文化部從沒超過總預算 1%**＋**媒宣費只占文化部 0.16% 卻被連續兩年全刪**——三個數字疊起來，比「大幅度下降」更有力，而且每個字都能在 `ly-budget.json` 對回去。

### 配圖 spec（工具現況：不可直接跑，需人工產圖或先修工具）

**先講清楚為什麼不能直接跑 `make-spore.sh`**：`scripts/tools/generate-spore-image.mjs` 的 `?shot=1` 模式**強制等待** `.hero-title` 元素載入日星宋體 `rixingsong-semibold`，等不到就直接丟錯、拒絕 fallback 截圖（v3.13 字型實載 HARD gate 的設計）。已確認 `src/pages/budget.astro` → `src/templates/budget.template.astro` 用的是共用 Hero 元件（`eyebrow` / `title` / `subtitle` props），**沒有 `.hero-title` class**——這是 knowledge/ 文章 Layout 才有的 class。直接跑：

```bash
bash scripts/tools/make-spore.sh /budget/ --size square
```

會在等待 `.hero-title` 逾時後拋錯（"rixingsong-semibold unavailable"），不會產出可用圖，也不會靜默 fallback 到錯字體（這正是 v3.13 gate 要防的事），所以**沒有嘗試硬跑**——跑了只會得到一個確定失敗、對決策沒有新資訊的結果。

**手動配圖 spec（給下一手 SHIP session 或哲宇本人）**：

- 尺寸：1080×1080（square，Threads 預覽不裁切）
- 標題文字：逐字取自 `budget.ts` `zh-TW['budget.hero.title']` = 「**總預算十年**」，副標可疊 `budget.hero.subtitle` = 「**三兆元的家計簿：怎麼分、誰在長、砍在哪**」
- 視覺素材：頁面本身的 kicker 詩句排版風格（`budget.hero.verse`：「一本三兆元的家計簿，今年八月十四日才蓋章。十年來錢往哪裡去，這一頁把它攤開。」）——建議沿用這段詩句當配圖主視覺文字，比孢子正文更適合入圖（詩句短、有畫面感）
- 忠實性 gate（v3.11）：若入圖標題/副標，必須逐字等於 `budget.ts` 對應 key，不得另下標題文案
- **修復路徑（非本次 sub-agent 授權範圍，僅記錄選項）**：要讓 `make-spore.sh` 真的可用，需要在 `budget.template.astro` 的 Hero 區塊補一個 `.hero-title` class（或擴充 `generate-spore-image.mjs` 支援資料頁的替代 selector），這是一個小型工具修補，建議另開 task 而非本孢子草稿內順手做（避免政治題草稿 PR 夾帶不相關的工具改動）
