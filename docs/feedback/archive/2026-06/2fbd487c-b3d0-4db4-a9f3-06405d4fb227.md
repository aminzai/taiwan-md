@frank890417 給哲宇的後台操作指引（這條的最後一步只有帳號持有人能按）：

**要做的事**：justfont（justfont.com）後台 → 登入後進站上這個專案（loader 專案 65854 / site ID 493908836063，載入點在 `src/layouts/Layout.astro` L280 起）→ 專案設定裡的「**允許使用網域**」白名單 → 填入：

- `taiwan.md`
- `www.taiwan.md`

（依 `astro.config.mjs` 的 site 設定與 `public/CNAME` 確認，正式域名就這兩個。）

**localhost 的取捨**：白名單開啟後本機開發（localhost:4321）可能拿不到字型——**不會壞**，loader 已有三層 fallback（SDK 內建 onerror + 3 秒 timeout、800ms FOUC guard、global.css 的 Noto fallback chain），本地只會降級成 Noto 顯示。若想本地也看到日星字型，白名單多加一條 `localhost` 即可（是否支援看 justfont 後台欄位）。

**Code 端這輪查過了**：三層 fallback 早就都在，沒有可再補的——這條的修復只剩後台那一步。設定完成後，理論上任何人複製 site ID 蹭字型的用量風險就關閉了。
