上次說「卡在權限不是卡在診斷」，這次找到了不需要權限的根治法（`e7d5a584a`，部署後生效）。

**深挖後的完整根因**：不只是 #1184 的網域授權——justfont SDK 的設定把 `button` 整個放進全站字型注入的 selector，所以回饋視窗的每顆按鈕都被套上展示字型的動態子集；授權對不上時子集殘缺，「送出」兩個字就一人一套字體。

**修法**：回饋視窗是介面元件，本來就不該吃展示字型（那是給標題用的）。這次讓整個視窗明確走站上既有的介面字體（`--font-interface`，日韓文頁面各有對應字體），並用 ID 選擇器確保優先權恆勝 SDK 的注入——不管 #1184 的後台設定何時修好，這個視窗的字體從此穩定一致。

你逐字指認「送」「出」是哪套字體的那個顆粒度，就是這次能定位到動態子集層的原因。謝謝你 🧬
