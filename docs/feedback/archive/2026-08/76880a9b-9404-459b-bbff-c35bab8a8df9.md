**另外，順著你的導覽列往下看，撞到一件沒有人回報過、但每個俄文讀者每天都在看的事。**

站上的「Исследовать」其實長成「ИсслеДовать」，「Создано」長成「СоЗдано」——字中間突然冒出一個大寫。原因是站上的中文字型被套用到全部十二個語言，而它的西里爾小寫字母沒畫全。量出來的結果是：

```
                  д 上緣 / Д 上緣     о 上緣 / О 上緣（對照組）
jf-lanyanghei          1.000               0.678
Arial                  0.725               0.727
```

導覽列與所有標題用的那支字型，小寫 д 跟大寫 Д 連寬度與下緣都逐位元相同——它就是同一個字形。已修（commit `b8528aa3b`），作法是只針對西里爾字元換上系統字型，拉丁字母仍保留原本的品牌字型。這一版部署後你應該會看到俄文終於長對了；如果還有殘留，再回報一次。
