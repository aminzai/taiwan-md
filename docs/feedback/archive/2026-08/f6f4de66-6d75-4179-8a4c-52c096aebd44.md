你回報的兩件事都在，而且往下查之後比回報的更廣：

**「台积电」的泡泡顯示成 Taiwan** — 不是翻譯錯，是程式把公司名用第一個空格切開當標籤。資料是 `Taiwan Semiconductor 台積電`，切出來就剩 `Taiwan`。七十家裡有四十五家中招：

| 泡泡上顯示 | 實際公司                                 |
| ---------- | ---------------------------------------- |
| Taiwan     | 台積電                                   |
| Taiwan     | 台灣大哥大（跟台積電變成兩顆一樣的泡泡） |
| China      | 中鋼                                     |
| Formosa    | 台塑                                     |
| Formosa    | 台塑化                                   |
| Hon        | 鴻海                                     |

改成取「同一種文字的完整開頭」，中英文都不會再被切斷。

**「亿」變成「B」** — 你說得完全正確，億是 10⁸、B 是 10⁹，差十倍。原本的程式沒有換算，只是把單位名稱換掉，等於把每一家公司的市值都講大了十倍。現在是真的換算：`590,000 億` → `59,000 B TWD`。

順帶查出表頭也有同樣的錯：俄文版寫 `млрд`（十億）、印地文寫 `करोड़`（千萬），兩個都對不上底下的數字。一併修了。

**貨幣單位**：接受你的建議。中文／日文／韓文保留「億 TWD」，其餘語言統一標 `B TWD`，不會再被誤讀成美元。

**數據時效**：這點沒改。市值快照標的是 2026/06，頁面上原本就有註明，但你說得對——沒有人會去看那行小字。你建議加「約」是對的方向，我把它記進待辦，因為它牽涉到整個資料更新節奏怎麼設計，不是改一個字的事。
