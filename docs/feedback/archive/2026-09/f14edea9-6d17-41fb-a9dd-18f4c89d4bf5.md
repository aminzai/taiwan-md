# Feedback — idea · 「消息」台灣怎麼說？台灣用語是「訊息」

**回報者**：J L
**時間**：2026-09-15T08:38:09.190251+00:00

**回報內容**
此頁面直接寫：「消息」是中國用語、中國大陸的常見說法，台灣慣用「訊息」。
但根據教育部《重編國語辭典修訂本》釋義，晚清作品《文明小史》第三回：「已經得了外面消息，怕有考童鬧事。」便有使用「消息」以表示「音信、訊息」的意思。
也就是說「消息」並非大陸用語，或是台灣也用「消息」，但與大陸在使用習慣上略有分歧。→此處可能需要再研究
