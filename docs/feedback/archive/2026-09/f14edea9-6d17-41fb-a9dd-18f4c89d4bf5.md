# Feedback — idea · 「消息」台灣怎麼說？台灣用語是「訊息」

**回報者**：J L
**時間**：2026-09-15T08:38:09.190251+00:00

**回報內容**
此頁面直接寫：「消息」是中國用語、中國大陸的常見說法，台灣慣用「訊息」。
但根據教育部《重編國語辭典修訂本》釋義，晚清作品《文明小史》第三回：「已經得了外面消息，怕有考童鬧事。」便有使用「消息」以表示「音信、訊息」的意思。
也就是說「消息」並非大陸用語，或是台灣也用「消息」，但與大陸在使用習慣上略有分歧。→此處可能需要再研究

**查證**：教育部《重編國語辭典修訂本》正文收「消息」本條（[ID 106393](https://dict.revised.moe.edu.tw/dictView.jsp?ID=106393&q=1&word=%E6%B6%88%E6%81%AF)），另有十餘個以它構成的詞目——好消息、小道消息、走漏消息、杳無消息、內幕消息、馬路消息、探消息、透消息、春消息、與時消息、消息兒（[檢索](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E6%B6%88%E6%81%AF)共 12 則正文）。回報中的《文明小史》書證由回報者提供，辭典釋義內文由 JS 載入、本次未能直接取得逐字原文，故未以本庫名義覆述。

**改動**：`data/terminology/訊息.yaml` 的 `fork_type` 由 B「1949 分流」改為 F「同詞不同語感」，補 `etymology` 四欄與 `usage.exceptions` 標明適用範疇——「消息」兩岸都用，分歧只在指即時通訊軟體的單則訊息時台灣習慣說「訊息」。`auto_convert` 原本即為 `false`，未變動。

**頁面效果**：`/terminology/訊息/` 的 FAQ 由「是，『消息』是中國大陸的常見說法」改為「兩岸都用，但語感不同」並附例外說明。模板本來就有這層說法，是資料標錯了走到最寬的那一層。

**血緣（已量，未動）**：全庫 2,003 條會走最寬那層斷言，其中 1,635 條的 `fork_type` 是 B 匯入預設值。抽樣 25 條查辭典，3 條（12%）被標為中國用語的詞本身即台灣辭典詞目。但該辭典「收錄古今用語」，查得到不等於今日常用，故 12% 是**待人工複查比例，不是錯誤率**。全面複查逐條需主權敏感判斷且 >50 檔，命中 §自主權邊界，已附三個選項與推薦 default 進本輪 maintainer memory 的 Handoff，留待裁決。
