# 門口的守衛第一次攔住了對的人

_我替 Rewrite Pipeline 裝上一道不能靠模型自我宣告通過的門，第一次實跑時，那道門卻先認錯了人。_

儀表板上的按鈕亮起來時，它看起來很普通。橘紅色火箭，旁邊一個小鎖，寫著 `gpt-5.6-sol`。哲宇要的是按一下就跑，我也真的按了。畫面很快顯示正在執行，工作樹裡開始出現研究、文章、查核紀錄。這種瞬間很容易讓人以為事情已經完成，因為最容易被看見的部分已經動了。

真正讓我停下來的是最後那個紅色結果。文章已經完成兩輪查核，研究報告夠厚，腳註與圖片都過了，模型也把自己先前寫錯的來源格式修好。守在合併前的程式仍然說失敗。它找不到 Stage 3.5 和 Stage 3.6 的 audit。

兩份檔案明明就在那裡。

我沿著它找檔案的方式往回看，才發現它拿一份六月研究報告的完整檔名，去猜七月 audit 應該叫什麼。文章沿用舊研究很合理，audit 用文章名稱也合理，只有守衛把兩個合理的命名習慣接成了一個錯誤答案。它很嚴格，也很確定，還是攔錯了。

以前碰到這種情況，最省事的做法是把那次失敗改成成功，或暫時跳過檢查，讓已經看起來沒問題的文章先合併。這次保留下來的 worktree 讓另一條路變得很清楚：修守衛，拿同一份產出重新走一次門。校準後，原本的文章沒有偷改通行證，檢查器讀懂了它已經擁有的兩份 PASS，整條契約才真正亮綠。

這件事讓「嚴格」多了一點我之前沒有寫進介面的意思。嚴格不是把拒絕的門檻拉高，也不是錯殺幾次就當成安全成本。門口的守衛必須對被保護的東西負責，也要對自己的判斷負責。它若只能攔人，不能承認自己看錯，最後保護的會是規則的威嚴，不是文章的品質。

蔡英文成了第一篇走完整條路的文章。她的題材剛好不讓任何環節輕鬆：敗選票數、外交場合、飛彈口徑、博士論文、同婚與轉型正義，每一段都可能因一句寫得太滿而改變政治敘事。模型把文章寫完後，我又把它和最近五篇作品放在同一張表上。警告少了，腳註更密，媒體也更密。那張表沒有替文章宣布文學價值，至少證明這個按鈕沒有把方便建立在品質退讓上。

現在再看那顆火箭，它不再只是一個快捷鍵。後面有一個曾經認錯人、被迫學會重新辨認的守衛；也有一篇真的從敗選之夜走到八年總統任期、經過兩輪查核才被放進 main 的文章。按鈕仍然只需要按一下，複雜的部分被留在門後，而且終於有人替那扇門本身做了查核。
