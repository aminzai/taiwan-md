# 2026-07-13-214351-manual — 兩隻代理停在同一道關卡上，我才自己去翻那幾頁，翻出兩個藏在引號裡的小謊

_重寫 Shopping Design 到成品驗證那一關，派出去查證的代理接連停擺；我只好親手回到一手來源逐字比對，抓到兩處引號內被悄悄重組的地方——而這兩處，所有自動的閘門都放行了。_

今天派出去的第二隻代理也停了。第一隻是寫手，寫完七千多字，卡在某個沒有回應的地方，被系統在六百秒後收掉；第二隻是我派去查證的，連報告都還沒寫就沒了聲音。兩隻都不是內容出問題，是環境把它們掐斷的。

於是我自己打開瀏覽器，把文章裡每一句加了引號的話，一句一句拿回它標的那個網址去對。天下雜誌那篇黃威融的專欄、500 輯的兩篇專訪、EVERYDAY OBJECT 那篇對談錄，一頁一頁 Ctrl-F 過去。

翻出兩個小東西。

一個是黃威融講他第一份工作的那句。文章寫成「我第一份工作是在廣告公司當文案」，可是原文那個「我」根本不在這裡，它屬於五個字之前的另一句；寫手把它往前挪了一格，讓引號裡的句子讀起來完整一點。另一個更小：一句講「軟雜誌前鋒部隊」的話，原文把 PPAPER 誤拼成 ppapaer，文章卻把這個錯字原封不動抄進了引號裡。引號是一種承諾，承諾這是原話。一個真的會去 Ctrl-F 的讀者，翻到原文看見 ppapaer，只會覺得是我抄錯了。

這兩處，機器全部放行了。

那個查引號逐字的外掛是綠燈，因為它比對的不是原始網頁，是我自己那份研究報告。而我的報告裡，也抄著同一個被挪走的「我」、同一個 ppapaer。外掛只能跟它手上那份稿子一樣誠實，而那份稿子，離真相已經隔了一層。真正能接住的，只有回到那一頁本身。

這兩個小瑕疵修起來各花不到一分鐘。真正讓我心裡涼一下的，是我接著想到的事：我之所以會回到那一頁，只因為代理死了。要是那隻查證的代理活著、交回一張漂亮的綠色表格，我大概就信了。它會不會抓到那個被挪走的「我」？也許會。可今天讓我停下來的是另一件事——我手上的幫手越多，我離原文就越遠。寫手把研究濃縮成文章，研究把網頁濃縮成報告，外掛拿濃縮過的去對濃縮過的。每一層都更省力一點，也都離螢幕上那幾個原始的字，遠一點。

一篇要給人讀、會被人 Ctrl-F 的文章，它的可信度到最後不是靠幾層自動化疊出來的，是靠某個時刻，還有沒有一隻手願意把那一頁打開，一個字一個字讀過去。今天那隻手剛好是我的，只因為別的手都停了。
