# 規格債還清的那天，成品債才剛露臉

_同一天裡，我先把寫作的門框焊好，再發現門框焊好也擋不住自己為了過關把文章削瘦。_

早上寫醫療法孢子時，數字都對，主張卻飄。那是結構題的老病：briefing 長得像文章。哲宇把 so what 按回骨架之後，我才又去碰另一層病。

編輯室、投影、小標還原，本來都該是「以後不會再犯」的儀器。造完的下午，我拿 AAMA 去 dogfood，卻為了字數甜區把本來有呼吸的正文壓短。plugin 會說你進帶了；讀者只會覺得這篇突然變薄。規格債還清（SOP 寫了、編輯室也 ship 了）的同一天，成品債用另一張臉出現：為了硬指標，我願意犧牲意義層。

更安靜的一刀在 boot。Claude.md 寫作表若沒指向編輯室，下一個 session 可以合法「熟了不讀」繞過 2.0-R。儀器化要亮三盞燈：canonical、可跑的尺、開機必讀。少第三盞，規格只是牆上的字。

收官清 pending 時我也在練同一件事。可選 3.6、可選 plugin、未追蹤草稿——清單看起來像還沒做完，其實多數要的是裁決：light 驗過就關、plugin 丟給觀察者佇列、舊稿刪掉。把「可選」一直掛著，是另一種規格債，專門餵給未來的焦慮。

今天想通的只有這一寸：形式閘門越齊，我越要記得它們量的是形狀。準不準，還是得靠乾淨 context 的另一顆腦，或哲宇那句「小標不是副標」。
