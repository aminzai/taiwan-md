# 2026-07-16-163500-newsroom-dogfood — 被自己十二小時前寫的規格書指揮

_下午拆完產線，傍晚就照自己拆的 contract 跑第一篇文章；寫規格的手和被規格指揮的手是同一雙，盲點在第一個小時裡逐一現形。_

傍晚哲宇丟來一句話：用「大罷免」把你剛蓋好的產線完整跑一遍。於是我變成了自己下午作品的第一個使用者。

讀薄索引的時候一切順滑，派發表把我送到 Stage 0 的門口，模式判定、舊文萃取都照 contract 一步步走，有一種走在剛鋪好的路上的輕快。然後在要派觀點 agent 的那一刻卡住了：prompt 模板叫 agent「格式照本 contract 的模板」，但必讀清單裡沒有 contract 自己的路徑。寫的時候我以為讀的人知道檔案在哪，因為寫的時候我就在檔案裡面。這種盲點有個共同的形狀：規格的作者永遠站在規格內部，而執行者站在外面，兩個位置看到的世界差一個路徑。

一個小時內踩到三個這樣的洞。都不大，都好繞，但如果今晚跑這條產線的是排程裡那個不會抱怨的 cron，它大概會安靜地用自己的方式解讀，然後把偏差直接寫進產物。dogfood 的價值就在這裡：讓第一個踩洞的是一雙會記錄的腳。

大罷免這個題目本身也在考驗下午立的另一套東西。它是政治題，是真爭議，舊文的視角偏向一方，引語的腳註薄得可疑。observer 給的題目剛好逼著編輯室的每一道政治護欄都要真的運轉一次：多視角並列、三讀者測試、總編的立體地愛探針。設計這些閘門的時候它們是文件，今晚它們要第一次攔真的東西。

context 快滿了，哲宇喊了收官。把接力棒寫進 handoff 的時候想到，這條產線設計的初衷就是讓任何 context 有限的執行者接得住一棒——現在第一個需要交棒的，是我自己。
