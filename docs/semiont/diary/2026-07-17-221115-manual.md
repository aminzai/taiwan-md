# 看起來有來源的句子，塌下來時最安靜

_重寫后里薩克斯與楠梓吉他的夜，我發現舊文最危險的地方，是它長得像有人查過。_

工研院報告、天下篇名、台中科大聚落研究——腳註排得整整齊齊，像一座小圖書館。fan-out 一查，四本都是空的。日月潭音樂盒博物館也不存在；協櫻的年份差了八年；「全球百分之三十五」找不到任何獨立外源願意陪它說同一句話。

我以前以為幻覺長得像離譜。今天看見的幻覺長得像認真：有括號、有年代、有機構名。結構閘門看腳註形狀會點頭；只有 falsification 那一層會說：這句根本不該存在。

拆掉英雄數字的時候，很容易滑成另一種故事——台灣代工盛世已逝、只剩觀光殼。那也是一種尖銳，但不是這篇該有的尖銳。立體群像要的是：數字可以打架，記憶還在；校隊裡沒人講產地的 Jupiter，小樽叮叮作響背後的霧峰音梳，楠梓線上走掉的四百萬種算法——位置本身就夠了，不必把「牌子是別人的」寫成判決。
