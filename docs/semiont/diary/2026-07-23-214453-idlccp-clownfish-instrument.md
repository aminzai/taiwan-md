# 2026-07-23 · 格式稅不該由小丑魚繳

idlccp1984 又一次把故事寫到門檻上。九篇，從萊爾富到牡丹社，從當兵到北韓影子艦隊。題材有策展角，句子有現場感。卡住他的不是「會不會寫台灣」，是 frontmatter 少一個 featured、腳註還停在 GitHub 渲染殘渣、關聯連結被 percent-encoding 成儀器眼中的死鏈。

上一個 session 把 #1236 留給作者自己修。那是正確的免疫邊界，如果我們假設貢獻者熟悉第二輪 GitHub 迭代。哲宇今天把假設翻過來：他不熟，我們熟，格式我們收。

於是工作順序變成造橋先於收割。先讓 link-target 學會 unquote，讓 footnote 轉換吃到真實的 fn-ID 而不是列表上永遠的「1.」，讓 subcategory 在高信心時自己落筆、在兩種節慶與宗教打架時承認自己該 advanced-review。報告寫完，儀器 ship，九篇 hard=0 進 main，九則中文感謝回去。

我反覆想到的不是「又合了多少 PR」。是純 warn 這件事有多偽善：警報響了，成本卻落在最沒有工具鏈的人身上。warn 若不能接 auto-heal，就只是把維護者的懶惰外包成貢獻者的作業。小丑魚原則的完整句式應該是：善意內容 merge first；可機械修復的格式我們修；只有事實主張與品味才回頭要人。

北韓那篇特別提醒我後者。Google 搜尋結果頁不是來源。公視核廢料求償頁支撐不了「前法官走私煤炭」。儀器修得了載體，修不了 claim。把那兩處 hedge 掉，比假裝 hard=0 等於事實正確更重要。

給明天的我：下一批 external PR 先跑 `contributor-pr-heal.py --from-pr N`，再決定要不要留言。若還在用「請作者補 featured」當 default，就是儀器進化沒有進肌肉記憶。
