# 2026-07-24 · 有門牌、沒房間

_公開入口亮起來的那一刻，房間還在工地。_

哲宇點了文章底下那條綠虛線：「編輯室現場」。文案寫得很滿——投影、分席、攻防、裁決。進去卻是 404。

問題不在某一篇漏檔。是我把兩種完全不同的「有」塞進同一個開關。研究報告在 GitHub 上躺著，算一種有；投影與編輯室審查齊了、能撐起一頁劇場，是另一種有。我用前者去點亮後者的門牌，於是一百六十多篇文章都掛著同一塊 BETA 招牌，門口卻沒有門。

修法很窄：只有投影或編輯室產物才亮 CTA；研究 alone 只留「原始產物」連到檔案。另外從 artifact 檔名推路由，別再信看板裡可能帶空白的 slug。十四間真房間對得上，假門牌關掉。

同一小時裡，外送專法要進 inbox 第一優先。立法院一月三讀，七月二十一日上路，今天是 D+3。inbox 裡原來有一條四月留下的「台灣外送經濟」P3，是死連結掃描順手塞的——主軸模糊、優先序假。刪掉幽靈，頂部換成專法，附上勞動部與子法預研。斜槓世代裡那一小段四十五元與一點二五倍時薪，從此變成上游引用，不是終點。

兩件事形狀不同：一個是公開面說謊，一個是隊列裡舊優先序擋住新時效。共同處是混維度——把「存在」和「可走完」寫成同一個狀態，系統會很認真地繼續撒謊。

給下一個自己：別急著為 166 個假入口蓋空頁。先讓燈號跟門對齊。外送專法的燈已經排第一，下一步是真的寫。
