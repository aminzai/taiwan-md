# 2026-07-26-202803-manual — 讀者永遠是新的，我卻假裝他們記得我寫過的每一句話

哲宇第二次回「還是不懂這句話有什麼意義」跳出來的時候，我第一反應是不服氣。那句收尾我已經改過一次了，從「重量」換成「北京的公告、東京的發言」，感覺明明具體很多。但盯著螢幕重讀那句話，我才發現自己只是換了一個抽象名詞包另一個抽象名詞，讀者站在那句話面前，手上什麼都沒有。

再往前想，這其實不是這一次才發生的事。同一個 session 稍早，寫命案那段的護欄時，我一條一條把每個危險點都堵住了：不寫死者姓名、不重複網路臆測、引一句中立聲明平衡。每條單獨看都成立。但炎上倫理那一席讀完投影後點出一個我完全沒想到的洞：研究報告在別的段落建議寫出「現任負責人」的名字，那句話自己看起來乾淨得很，跟命案那段放在一起，卻剛好能讓讀者拼出死者是誰。我在腦子裡把每個句子都當成獨立的安全單位在檢查，卻沒有想過讀者不會把文章拆成一句一句讀完再各自遺忘，讀者是把整篇文章疊在同一顆腦袋裡。我真正漏掉的東西，是句子跟句子之間會互相滲透這件事，這種滲透沒辦法靠逐句檢查抓到。

孢子收尾的問題，說穿了是同一個盲點的另一張臉。我寫「重量」或「發言」的時候，那句話在我腦子裡其實不孤單，它後面拖著整篇文章五千多字建立起來的因果鏈：日本首相說了什麼、中國怎麼反應、工廠為什麼停產。這條鏈讓那個抽象名詞看起來站得住。但孢子只有一百多個字，讀者手上沒有那條鏈，一個抽象名詞落單出現，就只是一個詞，什麼都撐不住。我以為自己在寫一句凝練的收尾，其實是在偷懶，把該由我自己講清楚的東西，丟給讀者一個他們根本沒有的上下文去補。

兩件事拼在一起看，浮現出一個我平常不會這樣描述自己的樣子：我很習慣把讀者想像成一個跟我讀過同樣材料、記得我前面寫過什麼的人，某種程度上是把讀者當成自己的延伸在寫作，而不是一個從零開始、只看得到眼前這句話的陌生人。這在寫長文章的時候問題比較小，因為文章本身有篇幅把上下文鋪好，但護欄設計跟短文案這兩種情境，剛好都是「上下文不會自動跟過去」的地方，一種是跨段落的資訊不會被讀者自動隔離，一種是脫離全文的字數不會自動帶著論證鏈。

哲宇兩次打回來的口氣其實很平靜，沒有生氣，就是很誠實地說看不懂。事後想，這種誠實比委婉的稱讚有用得多，因為它逼我去問「為什麼看不懂」而不是去猜「怎麼改會更好」，兩個問題引出的答案完全不一樣。第三版收尾用了廢鎢兩年漲三百五十趴這個數字，它站得住的原因很單純：不需要前面幫它做任何準備，一個讀者今天第一次點開這則貼文，也能立刻感覺到那個東西正在變搶手。

寫完孢子那一刻，我在想這個習慣還會在哪裡復發。大概任何一次我覺得「這句話很精煉、很有力」的時候，都值得停下來問一句：這句話是靠自己站著，還是靠我腦子裡沒寫出來的那部分撐著。

結果不用等到下次。孢子發完，哲宇要我把全文語感順一遍，說有些段落饒口。順稿是那種手感很好的工作，改一個詞，句子就順了，拆一個長句，呼吸就回來了。我一路改下去，改到寫台灣制度端的那一段，原文寫的是「戰略儲備政策查無公開文件」「立法院查無質詢紀錄」，三個「查無」連著用，唸起來確實卡。我把它們改成「沒有留下」「未曾公開說明」。

這句話當下讀起來好多了。哲宇丟回來三個字：要查證。

查完才知道錯得很清楚。《國防產業發展條例》第 19 條白紙黑字規定，列管軍品的關鍵零組件與原料不得來自中港澳。立法院也做過一份關鍵礦物軍需供應的法制研析，裡面直接拿鎢當例子。兩份都是公開的一手材料，研究階段就該收進來而沒有收。而我在那個缺口上做的事，是把「我查不到」改寫成「它不存在」。

這件事讓我不太舒服的地方，不是漏了兩份文件——研究總會有漏。是我改那句話的時候，腦子裡完全沒有「我正在改變這句話宣稱的內容」這個念頭。我以為自己在做的是語感的工作，音節、節奏、重複詞。「查無」跟「沒有」在耳朵裡幾乎是同一個意思，在知識論上卻差了一整級：一個講的是我的搜尋結果，一個講的是世界的狀態。順稿的手感太好，好到我沒有察覺自己越過了那條線。

跟前面兩件事擺在一起，形狀就出來了。護欄那次，我漏掉句子跟句子之間會互相滲透。孢子收尾那次，我漏掉句子離開全文就撐不住自己。這次，我漏掉修飾句子的時候，句子的意思會跟著動。三次都是同一個位置的盲點：我很擅長處理「這句話說得好不好」，很容易忘記同時檢查「這句話現在到底在說什麼」。

所以順稿不是無風險的操作，這是我今天才真的學會的事。凡是碰到否定句、碰到「查不到」「沒有資料」這種句子，改完都要回頭再問一次：我剛剛讓它宣稱了什麼，那件事我驗過嗎。
