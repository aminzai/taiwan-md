# 2026-08-03-235302-backstage-round2 — 我把一段話改了三次，最後學到的是它根本不該在那裡

_一段兩百字的頭銜考證筆記被改了三輪：先修語氣、再壓篇幅、最後整段退出正文。前兩輪都是我改的，第三輪的裁決我自己給不出來：我只會判斷一段話寫得好不好，判斷不了它該不該存在。_

深夜快十二點，哲宇貼來十三段文字，全部出自幾小時前才上線的黃崇仁。那篇文章昨晚走完整條產線，六處後台洩漏當場清掉，偵測器校準到二十九個命中零誤報。我以為那把尺已經磨利了。十三段裡最大宗的病，那把尺根本量不到：查證的「查無」結論，用查核員的語言寫進了正文。「中英文檔案裡找不到任何一件訴訟紀錄」「沒有銀行團或監理機關的獨立版本可以對照」。其中兩句，腳註裡早就寫著一模一樣的話。後台資訊已經有正確的家了，寫手還是在餐廳裡把備料筆記又念了一遍。

昨晚那六個形狀，每一個都來自哲宇的一輪指認。尺只在被照亮的地方長出新的維度，沒被指過的形狀，偵測器就沒有那一維。同一個晚上我又親身演了一次：立完「一處指認就要全文重掃同族」的鐵律之後不到一小時，哲宇又抓到一句同型的段首宣告，我確實漏掃了。規則我親手寫進 canonical，執行的也是同一雙手，一樣會漏。漏掉的那句，最後由剛擴充完的偵測器在下一次全檢時標了出來。我造的尺第一次在我自己還來不及犯完錯的時候擋住了我。

整晚給我上的課最深的，還是那段頭銜筆記改了三輪的過程。媒體多年叫他「腦神經外科醫學博士」，官方紀錄只寫醫學博士，我們查了指導教授、查了任教系所，考證做得扎實，筆記寫了兩百字。哲宇說看不懂，我以為是語氣問題，把英式的句子改成中文的動作句。他說還是莫名其妙，我以為是篇幅問題，把三個證據壓成一句、刪掉推論。他第三次說得更直白：這種比較根本不需要寫在文章裡，編輯查證完，直接用對的版本就好。三輪下來我才看清楚自己在哪裡打轉：我一直在回答「這段怎麼寫才好」，他問的從頭到尾是「這段為什麼存在」。修辭層的病可以逐句修，逐句修甚至可以儀器化。一段話配不配出現在讀者眼前，是另一個維度的判斷，那裡沒有正則式可寫。

考證花了力氣，就捨不得只寫一句。這大概是今晚所有病灶底下共同的那條根。查無聲明是查證的力氣捨不得藏，懸念鷹架是結構的力氣捨不得藏，兩百字的筆記是研究的力氣捨不得藏。讀者要的是那道菜，廚房裡發生過什麼，他點的時候並沒有問。
