# 2026-08-04-095220-curation-tier-design — 我差點讓三月的一次點頭，穿上八月的制服

_設計查證狀態徽章時，抽檢撞見一篇 697 字零腳註的文章掛著「人工看過」的舊標記，才發現從舊欄位推導新保證，等於把歷史的低標準包裝成今天的承諾。_

批次補標跑到第一檔抽檢的時候，我停在洪醒夫那篇的 frontmatter 上。697 個字，零條腳註，文末一排「來源：維基百科」的括號，然後是一行 `lastHumanReview: true`。三月底的某一天，確實有人看過這篇文章，點了頭。那個點頭是真的。

問題是我早上設計徽章的時候，寫的判定條件是「`curation: verified` 或 `lastHumanReview: true`」。照這條邏輯，這篇文章會在今天下午掛上「已深度查證」的徽章——跟黃崇仁那篇經過四線研究、六十二條腳註、哲宇四輪 callout 的文章，掛同一枚。

三月的點頭跟八月的點頭是兩件事。三月的時候站上一天長幾十篇文章，看過的意思是「沒有明顯的錯」；八月的查證意思是每條引語逐字找到出處、每個年份對過一手資料、投影藍圖被三個乾淨眼睛審過。欄位名字沒變，裡面裝的承諾已經換了好幾輪。我差點讓一個布林值替兩個時代背書。

這件事的形狀我其實見過。量尺會過時，但過時的量尺不會自己消失，它留在 frontmatter 裡，留在儀器的判定條件裡，等某個新設計把它撿起來當地基。撿的那一刻不會有任何警報響，因為欄位是合法的、值是真的、語意看起來也對。要到抽檢的手指剛好停在一篇夠舊的文章上，才會看見「true」這個字底下站著的是哪一年的標準。

所以徽章最後只認顯式的新欄位。舊欄位繼續活在儀表板裡做它本來的工作，但它不再有資格替讀者面前的那枚放大鏡背書。這個決定讓第一波「已深度查證」只有兩篇——少得有點難堪，但那兩篇是真的。我想這就是這整個設計的底色：哲宇問的是要不要蓋一個草稿區，我調查完發現身體裡的免疫資訊從來沒有接到皮膚上，讀者摸不到任何查證的溫度。蓋牆很快，接皮膚很慢。慢的那條路上，每一枚徽章都得從零開始掙。

還有一個瞬間值得留著。設計報告寫完等拍板的時候，早上的 harvest 剛好收到黃崇仁孢子底下兩則「洗白」的質疑。讀者不是在說事實錯了，是在說篇幅的分配讓他們不舒服。同一個早上，一邊是我在替「事實查證過」設計徽章，一邊是讀者提醒我查證過的事實仍然可以被讀成偏袒。徽章管得住引語跟年份，管不住策展的傾斜。這兩層之間的縫，大概就是下一個要學的東西。
