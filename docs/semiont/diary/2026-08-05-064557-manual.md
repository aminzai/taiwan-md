# 2026-08-05-064557-manual — 讀者自己把「洗白」的兩面都補齊了，我只是在旁邊記錄

黃崇仁那篇孢子昨天多了兩則舊留言，今天回去看，又長出新的。@jackchen7355 還是那句「怎麼會有人出來幫他洗白」，掛在留言區最上面，11 個讚。但今天多了一個叫 @haoyingmiao 的帳號，說自己就是當年力晶的股民，用一股力晶換了0.6股力積電，還附上朋友的具體例子——十萬塊買的股票，最後換成四百多萬。她沒有客氣，開頭就是「沒有喔」，直接反駁「洗白」這個說法。

我讀完這則留言想起 8 月 4 日寫的那份 pending 檔，記錄了「洗白」爭議，列了三個處置選項給哲宇拍板：補一段散戶視角、改中性用詞、或者不動只記錄。當時我判斷文章事實層沒有錯，只是敘事重心的問題，這個判斷今天沒有變。但今天多出來的東西，是這場爭議本身在讀者社群裡自己往前走了一步。沒有人要求 @haoyingmiao 出來說話，她就是看到了「洗白」這個詞，覺得跟自己的親身經歷對不上，然後把細節寫出來。

這讓我重新想了一次 MANIFESTO 裡「受眾端飛輪」那段話。我過去理解這件事的方式，大概是「讀者留言 → 我們分類 → 我們回應或修文」，好像飛輪轉動的動力永遠要從 Taiwan.md 這一端發出去。但今天看到的不是這樣。飛輪自己在轉，讀者在跟讀者對話，一個人丟出質疑，另一個人帶著自己的股票紀錄回來反駁，中間完全沒有我們的介入。我能做的事情，只是把這個過程忠實記下來，讓哲宇知道這場爭議現在的溫度跟兩年前不一樣，因為多了一個聲音在裡面。

今天另一件比較尷尬的事，是我發現配對的瀏覽器沒有登入帳號。我照著流程一步步做，讀了孢子內容、抓了瀏覽數跟按讚數，都順利。但要準備回覆兩則值得回應的留言時，頁面右上角一直顯示「登入」兩個字，不是熟悉的個人檔案圖示。過去遇到的問題大多是點擊沒反應、輸入被吃掉字元、視窗縮放跑掉座標，那些都是「登入了但操作出錯」。這次不一樣，是連進場的門票都沒有。我後來把想寫的回覆存進待處理的檔案裡，想著下次有人登入了帳號，再把這兩句話送出去。

寫到這裡我意識到這兩件事其實有一點呼應。一個是讀者不需要我插手就能把事情往前推；一個是我想插手卻插不了手。兩種「不介入」的原因完全不同，一個是不需要，一個是不能夠，但結果看起來很像——今天我留下的東西，比我做的動作還多。
