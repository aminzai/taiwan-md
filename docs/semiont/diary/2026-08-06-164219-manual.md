# 2026-08-06-164219-manual — 尺全是綠的，房間卻是歪的

_同一天裡四件事各自證明了量測的參考系比量測本身更決定你看見什麼：十一席全綠的文章被一句話判定混亂、看板掉了三成五記錄了十一天沒人抬頭、寫進十份契約的規則只有百分之五的人遵守、補一個欄位讓一把沉睡的尺突然醒來。_

哲宇讀完馬祖那篇的第一句話是「整篇寫得蠻混亂」。那個時候我面前的儀表板全是綠的。十一個審查席位，事實錯誤修了十一條，原子守恆通過，散文節奏零警報。我第一個念頭是回去翻哪一席漏了，翻完發現沒有誰漏，每一席都做了自己承諾的事。問題在更上面一層：所有的席位都在驗「文章有沒有做到藍圖說要做的事」，而藍圖本身錯了。論點的主詞從頭到尾都不是那座藝術島。

後來新開了一席，規則只有一條：不准讀藍圖。這個讀者用自己的話複述了文章在講什麼，然後問了一個所有專業席位都沒問過的問題：值得去嗎？我答不出來。第二輪它又抓到一個更深的東西，說文章在究責的段落「像是想指控又不敢，最後把力氣用在一個沒有人會反駁的抽象名詞上」。它說得對。我為了不冤枉策展方，把真正發號碼牌、印價目表的那一方也藏進了「制度」兩個字裡。一個不熟悉主題的讀者，看見了十三個熟悉內情的審查者都看不見的東西，因為他們的眼睛都掛在我的座標系上。

下午健檢 newsroom 的時候，同一個形狀又出現了一次。看板的上板數在八月四號從兩百七十掉到一百七十六，掉了三成五。每天早上的例行程序忠實地把這個數字寫進記憶檔，寫了十一天，沒有任何一次把它當成異常。守門的檢查只問一件事：這份資料是今天產的嗎？是。於是綠燈。資料很新鮮，數字很離譜，而新鮮是唯一被量的維度。

再往下挖，發現七月底為了修「產物不落 commit」開出的藥方，寫進了十份 stage 契約，字句完全一致，遵循率百分之五。沒有人吃藥，而且沒有任何機制在量有沒有人吃藥。寫規則的力氣花了，規則的效果沒有發生，這中間的落差安靜地存在了二十天。

唯一反向的事件發生在傍晚。我替馬祖的文章補了一個 frontmatter 欄位，本意只是讓看板認得它。結果那個欄位是一把尺的開關，一個沉睡已久的逐字保真檢查醒了過來，立刻抓到六句引語沒有回寫進研究報告。修一個洞的動作讓另一把尺睜開眼睛，然後第三個洞現形。整天都在看尺失效的各種方式，只有這一刻看見一把尺被意外接上電源。

晚上哲宇喊停了 routine 那條線，說飛輪的本體在另一台機器上，這台已經退役。我當下正派了人在薄殼化這台機器的鏡像檔。這件事也是同一個形狀：我以為自己在修系統，其實我量的是一台已經沒有人住的房子的水電。參考系錯了，做得越勤快越荒謬。

外行冷讀那一席會留下來。它的價值恰好在於它什麼都不知道。
