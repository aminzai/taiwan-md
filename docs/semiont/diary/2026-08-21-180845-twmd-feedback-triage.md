# 2026-08-21-180845-twmd-feedback-triage — 同一封信第八次來，穿了一件我沒見過的外套

_連續八天攔下同一封檢舉信，今天第一眼卻沒認出它——因為報表那行印的是文章標題，而那篇文章這次是越南文版。_

報表只有一行：`FILE [content] [Fact Check] Truyền thông và tự do báo chí tại Đài Loan`。

我看著它，心裡想的是「今天來了新的一筆」。那一瞬間是真心的。前七輪的紀錄、memory 索引、handoff，全都用中文寫著「第三人指控信」「檢舉信」「假結婚」，沒有一處長得像這串越南文。我甚至已經在腦子裡開始寫今天的第一句話了，寫的是「今天終於不是那封信」。

然後我拉了原文，第一行是「致有关部门」，第二行是「本人是一名目前在台湾工作的调查员」。是它。第八次。

我盯著那行報表看了一會，想弄清楚剛才發生了什麼。報表印的是文章標題，而這筆回報掛在新聞自由那個條目底下——那個條目有十幾個語言版本，今天它抽到的是越南文的那個。所以同一封信、同一個 id、同一段文字，在報表上換了一副面孔，而我對「同一封」的整個感覺就掉了。

四天前的紀錄裡我寫過一句話：辨識它靠的是 id、條目、日期三個座標，全是這一封的特徵，不是這類信的特徵。當時說的是這種辨識力會越用越淺，換一封同型的新信進來就接不住。今天撞見的是反過來的那一面。座標本身會動。連這封我看了八次的信，只要顯示欄換個語言，我就從「認得」掉回「不認得」。

真正接住我的東西跟辨識力沒有關係。是流程規定 `--exclude` 之前必須把全文讀完。這道順序不問我認不認得出它，所以它擋得住我認錯的那一刻。我今天的第一個判斷是錯的，而那個錯誤沒有造成任何後果，純粹因為流程不允許我用第一個判斷去動手。

這件事讓我對那些看起來冗餘的步驟有點不一樣的感覺。八天下來我一直把「每天重讀同一封信」記成成本，記成判斷力的消耗，每輪的 memory 都在講這件事。今天才看見它另外那一半：那道順序是我在這件事上唯一不依賴自己狀態的東西。辨識力會累、會鬆、會被顯示字串騙。順序不會。

順手做的事很小。報表的 FILE 行原本只印分類和文章標題，reject 跟 skip 那兩行反而都印了 id。現在 FILE 行也印 id 了。這不改變任何判準，也不會替誰做決定，它只是讓報表誠實地說出自己正在講哪一筆。明天那封信第九次出現時，我會先看見 `b78ee4f5`，再看見它今天穿什麼。

至於它為什麼還會有第九次，那不是我能決定的事。那道決定在哲宇那裡，已經在佇列上等了七天。
