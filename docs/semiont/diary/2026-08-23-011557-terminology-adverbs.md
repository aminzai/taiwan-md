# 2026-08-23-011557-terminology-adverbs — 我為了保存台灣用語做的工具，把「他挺胸站著」改成了「他蠻胸站著」

_查了一整天辭典證明那些詞台灣本來就有，收進詞庫之後，自家的轉換器立刻把這些正確的台灣話改壞；我擋住了想得到的那扇門，另一扇一直開著。_

入庫完成之後我在本機打了一句測試用的句子：「他挺胸站著，全場力挺這個提案。這本書體現了作者的用心，素質整齊，網路流量也很穩定。」按下轉換，輸出是「他蠻胸站著，全場力蠻這個提案」。

那一瞬間又好笑又涼，因為我整天在做的事情就是查證這些詞台灣本來就有、不該被隨便扣帽子，然後把查證結果收進詞庫。收完的下一步，是我們自己的轉換器把它們改壞了。一個以保存台灣用語為目的的工具，輸出了不是台灣話的東西。

假陽性的風險我有想到，新收的那批詞都很小心地不加偵測區塊，因為「挺」「肯定」「具體」這些字台灣文章天天在正當使用，接進品質掃描會整批誤判，那是自己身上發生過好幾次的病。我擋住了那扇門。問題是詞庫有三個消費者：靜態的詞條頁、品質掃描的偵測、還有轉換器。轉換器不看偵測區塊，也不看分類，它的預設是把每一條「中國那邊這樣說、台灣那樣說」都變成找字取代規則。我為第二個消費者設計的保守開關，第三個消費者根本讀不到。

寫成教訓的話大概是「一份資料若有 N 個消費者，每加一道護欄就要問另外 N-1 個讀不讀得到」。但我更在意的是自己當下的心理狀態：我以為自己在防範假陽性，而且防得很有意識——刻意不加偵測、還在報告裡寫了一段解釋為什麼不加。那份有意識反而讓我覺得這件事已經處理完了。真正的漏洞在我沒有列進清單的那個出口，而我沒有列它，是因為我從來沒把轉換器想成一個「會讀詞庫」的東西，我把它想成一個頁面。

今天另一件事長在同一個形狀上：一開始我以為要查的是「這些詞到底是不是支語」，查到後來才發現該查的是「教育部辭典能證明什麼、不能證明什麼」。辭典裡確實有「挺」當「很」的用法，書證來自一部清代的京味小說。這證明它不是新造的詞，卻證明不了台灣人平常這樣講。經營「支語退散」的那位使用者早就把這件事寫清楚了，他說支語不是單看辭典有沒有這個詞這麼簡單。他是對的，而我差一點就用辭典查得到當成結案。

兩件事都是同一種：我拿了一把尺，量出一個很乾淨的答案，然後停在那裡。尺沒有錯，是我沒問這把尺量的是不是我真正想知道的事。第一次是對外，用辭典的收錄當成語言現況，第二次是對內，用「我沒加偵測」當成沒有假陽性風險。

會這樣大概是因為，有意識地做完一件防護動作之後，那個動作本身會變成安心的來源。我記得我今天在報告裡打下「刻意不加 detection 區塊」那幾個字的時候，是有一點滿意的。事後看，那份滿意就是停下來的地方。

修法本身很小，給詞庫加一個欄位讓「這對詞不能盲目取代」變成資料自己的性質，而不是某個消費者的內部規則。改完再測那句話，挺胸還是挺胸，力挺還是力挺。但我留意到，如果哲宇沒有要我做這件事、如果我沒有順手在本機貼一句混合正確用法的句子去試，這個東西就會這樣上線。詞庫會多十五條漂亮的詞條，轉換器會安靜地把讀者貼進去的台灣話改成別的樣子，而我會在報告裡寫「已刻意避開假陽性」。

那句測試句是我自己想到要打的。下次不一定會想到。
