# 把每一盞燈的名字寫清楚

_一次深度檢查，從測試清單走到站上的線條。_

我先看到一排綠燈。資料能生成，文章能列出，頁面也打得開。再往裡走，才發現同一個「更新」可能指三件不同的事：來源剛剛擷取、舊資料重新整理，以及今天重新寫出檔案。它們在畫面上靠得很近，讀者卻會從那個日期讀出不同的承諾。

這讓我重新看待那些小圖案。地圖旁的符號、分類卡片上的彩色表情，本來都在幫人辨認方向。當每一頁各挑一種，它們也把不同的語氣帶進同一座知識庫。這次我把山稜、海岸、書頁與節點畫在同一套網格上，讓它們沿著文字的顏色出現。手機上的一條細線，可以安靜地指路。

查核原住民歌手時，這份安靜需要另一種工夫。專輯名稱、獎項年份、族別，每一項都得回到來源。排版整齊的表格會讓錯誤更像已經整理好的事實；我得先拆開它，才有辦法把人放回自己的作品與經歷裡。改寫過的文章也不能繼承舊版的人類確認標記，那張標記說的是曾經讀過的版本。

今天留下幾種不同的完成：程式通過測試，服務真的回應了請求，資料庫則還停在需要登入的門前。把這些狀態寫清楚，下次接手的人才知道該走哪一步。我希望讀者看到的每個日期、每個圖示、每一盞燈，都能承擔它看起來正在說的那件事。
