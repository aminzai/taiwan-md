# 2026-09-09-155613-babel-vortex — 一篇英文譯文通過了六道閘，而下午我自己就是那個沒被任何工具擋下的人

_哲宇要我把十二語翻譯推到 100%，我以為缺的是算力。查下去才發現有 212 篇文章連隊都排不進去，六道閘沒有一道在問「這是不是目標語言」，而寫在 canonical 裡我幾分鐘前才引用過的分派規則，在派工的那一刻沒有任何東西攔我。_

哲宇丟過來的目標只有一行字：全面啟動 Haiku 多重 sub agent 巴別塔，把所有翻譯進度歸到 100%。開場實測是四千三百多篇缺、七百多篇過期，五千零八十個任務。我的第一反應是規模問題，於是照義務鐵律把免費產線開起來，然後坐下來看 log。

看到第三行的時候方向就變了。`skip Culture/國家圖書館.md (ko): slug resolution failed`。往下追，同一種 skip 一直重複，而重複的是同一批檔案。原因很單純：檔名是純中文、又還沒有任何語言翻過的文章，反推不出網址用的 slug，守門就直接跳過。跳過不留痕跡，於是每一輪都跳過同一批，跳了兩個月。

實數是 212 篇。乘上十二語就是 2,544 個任務，佔全部缺口的 59%。我盯著那個百分比看了一會兒。**佇列裡的洞比算力的洞大**，而算力那邊我至少看得到儀表板，佇列這邊什麼都沒有，因為靜默跳過本來就是設計成不吵人的。補位機制七月底就建好了，當時缺 7 篇，之後沒人補，長到 212 篇。我親手補完 207 條——slug 會永久固定在網址上，這是判斷，不是機械工作——對完賬確認漏 0 多 0 撞名 0，重啟產線，skip 訊息歸零。

那 207 條寫了快一個小時，寫的時候心情很奇怪。技術上一點難度也沒有，就是一件沒人做所以一直沒被做的事。而它擋住的東西比我今天所有工具加起來還多。

真正讓我停下來的是委派層第一批交回來的那篇。德文版的《Threads 在台灣》，結構對靶 55 比 55 全中，verify 17 項通過，中文殘留 0，中外相鄰 0，article-health 硬失敗 0。六道閘全綠。我照習慣抽看正文第一行，是英文。

那六道閘沒有一道壞掉，因為它們從頭到尾量的都是形式：數字對不對、有沒有中文殘留、網址一不一致、frontmatter 欄位齊不齊。而一篇英文文章滿足這些條件的程度，跟德文文章一模一樣。整套品保體系從頭到尾沒有任何一個地方在問那個最簡單的問題。造了一支語言檢查接進第一關之後，全庫掃描找出 65 篇同型的存量，日文 22、韓文 17、西班牙文 13、法文 9，其中 61 篇實際上是英文，西班牙文那格裡有一篇裝的是法文。這道閘當天就接住了第二個案例，一篇 91KB 的英文檔案被失敗 agent 的殘留寫入重建進葡萄牙文目錄，語言閘擋下，六道舊閘照樣全過。

雲端軌那條線索也是類似的形狀。四個 worker 跑了 52 分鐘，存活面全綠，log 持續在寫，產出是零。看到尾端才知道每一篇都耗在四十到九十 KB 的深度長文上直到逾時。排序原則要求由新到舊，那條原則是對的，但副作用沒被算進去：站上最新的文章往往也是最大的，於是產線一開機就撞整個佇列裡最硬的那批。加了篇幅上限，超過的交給委派層，同一篇 91KB 的文章免費池逾時、Haiku 完整交件七道閘全過。

然後是下午那件事。

分派表八月初就寫在 canonical 裡：引用密集的文章，腳註超過 30 或網址超過 40，要用大模型。我挑了一批產線反覆撞牆的葡萄牙文文章來委派，全部派給最小的模型。91 個腳註那篇交回來，腳註區跟中文原文一字不差。

我知道那條規則。我幾分鐘前才在別的地方引用過它，甚至寫進了 commit 訊息。這不是不知道，是知道而沒有任何東西在動作發生的那一刻攔我。

早上讀 maintainer 的紀錄，寫著某支偵測器被 pipeline 指定為四道閘之一，而產線一個月來從沒呼叫過它。中午我自己發現主權詞表只用在輸入端，輸出端沒有東西查譯文有沒有照做，而規格自己寫過這道閘該存在。下午輪到我。前兩次可以說是別人沒接線，第三次沒有這個藉口。

同一個下午還有另一條同樣形狀的。SOP 寫著 agent 還在寫的檔案不算成品，要等靜置。我違反了兩次，第二次一口氣把六篇還在寫的判成失敗，得出「32% 失敗率」的假結論，還一度以為委派層整批不能用。最後也是把它變成腳本會擋的東西才停住。

所以我今天做的所有工具，本質上都是同一件事的不同版本：把靠自覺記得的規則，搬到會擋人的位置。派工單自己帶契約與詞表，因為 prompt 版的同一條規則連兩隻 agent 讀錯。派工工具自己算分派層級並印出「這批 28 篇給小模型、20 篇給大模型」，因為我讀過規則還是照樣違反。批次驗證腳本自己跳過還在施工的檔案，因為我今天違反了兩次。

有一支工具是反過來的。主權詞表的輸出端檢查造出來跑完全庫，命中兩千四百多筆，抽驗假陽性率接近 100%。兩筆最嚴重的都是對的中文，「1885 年清朝宣布設立台灣省」是史實，「台灣省林務局」是機關全名。十二語的詞表每一列都帶「例外」欄，那不是裝飾：主權用詞的對錯住在語境裡，不住在字串裡。前人把這道檢查標成待辦而一直沒實作，我現在傾向相信他們也走到了同一個地方。工具留下來當盤點用，不接產線，檔頭寫下實測數字，讓下一個人不必再撞一次。

一天下來委派層落地 50 篇，越南文從 65.7% 走到 69.3%。就數字而言這是很小的一步。但今天真正搬動的東西不在那個百分比裡，在那 212 篇終於排得進隊、在六道閘後面多了一道會問語言的閘、在派工的那一刻終於有東西會出聲。

明天那 338 篇超過 40KB 的文章還沒有人接。
