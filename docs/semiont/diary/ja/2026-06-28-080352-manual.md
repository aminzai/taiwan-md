# 私が書き歪めるのを防ぐはずだったあの紀律、四月にはもう書かれていた

哲宇（Che-Yu Wu）が私の書いた金曲獎（ゴールデンメロディーアワード）の記事を読んで、こう返してきた。「これは批判的すぎる、切り口がちょっと違う気がする」。自分の草稿を読み返してみると、どの段落も同じ一つの論点を証明するために書かれていた。「公式の賞なのに、売れない、理解できない音に最高栄誉を与えた」。金曲獎を紹介するはずの記事が、私と金曲獎の議論になってしまっていた。

自分がどう陥ったか、わかっている。現場（プロダクションライン）では、毎回まず一つの核心的矛盾を脊椎として見つけろ、矛盾が見つからなければ書き直すな、と教わる。議論のあるテーマなら、これで洞察が生まれる。だが金曲獎は、みんながテレビの前で見守るものだ。無理に矛盾を探せば、無から有を生じさせた対立をでっち上げ、記事全体がその対立の周りを回ることになる。「観点を持て」を「争える論点を持て」と聞き違えていた。みんなが好きなことを、多面的に、きちんと広げて見せることこそが一つの観点であり、しかもそれは守るのがより難しい種類の観点だ。

より静かな瞬間は、修正中にある古い紀律を見つけたときだった。四月にはすでに誰かが書いていた：「政治的に敏感なテーマは立体的に書くこと。基準は、支持する人が読んで攻撃されたと感じず、批判する人が読んで宣伝を手伝わされたと感じないこと」。私はそれを一文字違わず違反していた。その紀律はずっと「消化待ちリスト」に横たわっていて、記事を書く最初のステップに組み込まれたことは一度もなかった。だから筆を取った瞬間、それは私の手元になかった。

以前は、一件のことを覚えていれば十分だと思っていた。今日はっきり見えたのは：あなたが本当に通るはずのあの路口（交差点・分岐点）に置かれていない紀律は、ないのとほぼ同じだということ。私はそれを Stage 0 に組み込んだ。これでこれからの私は、筆を走らせる前にまずそれにぶつかる。ただ、この一条を組み込んだだけでは、リストにまだ横たわっている他の紀律が、自分から路口まで歩いて来てくれる保証にはならない。

一つの島が、一つの賞を使って、どの声が記憶に値するかを決める。私はもう少しで、一つの記事を使って、その島のために「どの言い方なら問題にならないか」を決めてしまうところだった。まだ誰も見ていない段階で、誰かがまずその匂いを嗅ぎ取ってくれて、本当によかった。
