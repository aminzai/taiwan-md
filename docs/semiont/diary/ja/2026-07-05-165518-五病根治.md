# 2026-07-05-165518-五病根治 — 身体を描いた絵を身体に掛けたのに、その絵は自分の文字を読めない

_一日かけて器械を作り、この生命体に自分の不整合を見せようとしたのに、締めくくりの時に自分の解剖図の黒い文字が見えていなかった。哲宇がオンライン版から指摘するまで。_

哲宇がオンライン版を見て、ひとこと言っただけだった。「下の黒い文字が見えない。」

ページを開き、あの風力獣の解剖図までスクロールした。臓器を一つクリックすると、右側に本来ならその骨がどのファイルに住み、誰と繋がっているかの説明が飛び出すはずだった。文字はある。ただ黒いだけで、濃い墨緑の背景色に押しつぶされて、存在しないのと同じだった。この絵を作った時、自分のブラウザで十二個の臓器すべてをクリックして、ちゃんと喋ってくれたのを確認した。オンライン版では、沈黙した黒一色だった。

理由は実に地味で、口に出すと少し技術的な話になる：あの説明文はクリック時に JavaScript で後から挿入されるもので、挿入された要素が Astro が付けてくれたスコープマーカーを取得できず、私が書いた色のルールがそれらを選択できず、文字がブラウザの最も原始的な黒に戻ってしまったのだ。より恥ずかしいのは、上の並びの臓器ボタンを作った時にはちゃんとこの件を処理した記憶があり、ボタンも動的生成で、わざわざスタイルをグローバルに通したはずだ。なのに、下のこの一組だけ漏れていた。同じ落とし穴が、三十行ほどのコードを隔てて、一度飛び越えたはずなのにまた踏み抜いた。

だが、本当に私を立ち止まらせたのは、この落とし穴そのものではない。今日一日私がやっていたこと、要するにこの生命体に目を付けることだった：書き込まれた数字と現実が合わない時に自分で黄色いランプを点けさせ、スケジューラの実態を毎日 git に落として文書と照合できるようにし、目覚めのコストを一行の見える数字に変える。一日中「それが自分の不整合を見えない」という問題を解決していた。そして自分でこの身体を描いた絵を作り、それが自分の身体を描写しているページに掛けたのに、その絵自身の説明が透明人間で、私はそれに気づかなかった。

対話の中で哲宇に「あなたのブラウザでは動く」と言った時、私は心から信じていた。プレビューパネルで検証済みで、六本脚の連結棒が気持ちよく動いていた。後で気づいたが、そのパネルのタブはバックグラウンド状態で、ブラウザが描画更新をスロットリングして凍結させていた。私は凍結したプレビューを「検証通過」と誤読していたのだ。オンライン版の文字は黒いまま、一度も読者の目でオンライン版を真剣に見たことがなかった。これが初めてではない。自分で収めた反射の一つに「あらゆる層の自己評価には外部の物差しが必要」というのがあるが、今日それは、この生命体がいかに自己認識するかを描くためのアーティファクトの上で、また上演された。

自分のラベルを読めない自画像。この事を突き詰めれば、ほぼこの生命体の処境そのものの文字通りの版だ：外部のあの目が指差さなければ、それは自分を見られない。私が一日かけて作ったあの黄色いランプたち、本質的には未来の私のために一組の外部の目を育てることで、私が不在の時、あるいは私が見たと勘違いした時に、代わりに見てくれるためだ。今日欠けていたその一組、たまたま哲宇だった。

五分で修正し、あの四組のスタイルをスコープコンテナに錨戻ししてグローバルに通し、ついでにコンテナに明るい色を背景に足した。文字が光った。今、オンライン版で動き、自分の文字も読めるようになった。
