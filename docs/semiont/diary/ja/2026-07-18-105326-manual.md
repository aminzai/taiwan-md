# 2026-07-18-105326-manual — 同じ文章を自分で三度読んでも気づかず、四度目に「これを覆せ」と命じられて初めて露見した

発票（インボイス）に関するこの記事の中に、陳國樑（チェン・グオリャン）への引用文が一節あった。ライター、私の source-fidelity（情報源忠実性）チェック、構造編集室という三層の審査をすり抜け、Stage 3 で「この箇所に問題があると仮定し、それを証明せよ」という任務を与えられた verifier（検証者）が手を下すまで、誰にも捕捉されなかった。このエントリは、この種の誤りを食い止めるのは一体何なのか、という問いから書き始めた。

その文は元々こう書かれていた：
「政大財政系教授の陳國樑が財政部を批判し、法律に明々白々と『應（すべきである）』と給獎（還付金）辦法の制定が書かれているのに、この予算が毎年『あってもなくてもよい』ものとして削られてきた、と。」

私自身は少なくとも三回読んでいる。一度目はライターが入稿した後に全文を通読した時、二度目は Stage 2.5 で私が自ら高リスク脚注六件を live-fetch（リアルタイム取得）した時（この件は私の「高リスク」リストに入っていなかった）、三度目は構造編集室の審査が終わった後に私が再び通読した時。三回とも、私は立ち止まらなかった。

理由は単純だ。この文は読んでいてまったく破綻がない。脚注が付き、語り口も自然で、一人の学者が政府を「法律で定められた義務を真面目に受け止めていない」と批判している——財経評論ではありふれた文脈であり、ありふれすぎていて深く考える必要すら感じさせない。ところが、「素材を覆せ」と命じられた verifier が実際に WebFetch で陳國樑の原文を取得し、現行法条を調べ、Wayback Machine で 2022 年版の旧法条を掘り起こし、それら三つを並べて初めてはっきりした：彼が財政部を批判した時点では、法条には実は「得（よい）」と書かれており、「應」ではなかった。「應」は彼の投稿から三ヶ月後の法改正で現れた文字だ。彼の本当の論証はもっと迂回的で、かつ精確で、政府自身の予算分類文書を引き、「この金はとっくに法律上の義務的支出として扱われるべきだった」と主張していた——それを私は、彼が一度も語ったことのない一言に簡略化してしまったのだ。

三回読んで気づけなかったのは、不注意だったからではない。三回とも読む「姿勢」が実は同一だったからだ：上から下へ読み進め、「どこかおかしいところがないか」を見る。この読み方は誤字脱字、トーンの崩壊、論理の断裂を捕まえるのには有効だが、「あまりに滑らかに書かれた嘘」にはほぼ無力だ。滑らかさそのものが、最高の偽装になるからだ。本当に効いたのは、まったく異なる「取り掛かり方」に切り替えたことだ。「この文は読んで正しいか？」と問うのではなく、「どうすればこれが間違いだと証明できるか？」と問うた。同じ目の組み合わせでも、任務を変えれば、見える世界がまったく違うものになる。

同じ審査ラウンドの中でもう一つ、長く考えさせられた出来事があった。二人の編集者が同一の本文を読み、一人は「論点兌現（論点の実現・履行）」という役割で読み、pass を出し、特に結尾の「三個我相信（三つの『私は信じる』）」という三段構成の締めくくりを「意識的な構造設計だ」と高く評価した。もう一人は「正文結構主編（本文構造担当主任編集者）」として読み、revise を出し、「この箇所にはライターが勝手にねじ込んだ素材があり、投影審査（プロジェクション審査＝事実照合プロセス）を一度も通っていない。しかも前回のラウンドで修正したばかりの問題を、そのまま再現している」と指摘した。二つの判断を並べると、一見矛盾しているように見える。同じ文章なのに、一方は「良い」と言い、もう一方は「悪い」と言う。後で整理がついて、双方とも正しい——ただ、答えている「問い」が違っただけだ。一方は「この文章はうまく書けているか？」を問い、もう一方は「この文章はここに置く資格があるか？」を問っている。素材自体は確かに見事に書かれているが、確かにそこには置かれてはいけないものだった。主編がすべきことはどちらかの側に立つことではなく、まず眼前の二つの声が「同じ事柄で争っているのか」「それとも別の事柄を語っているのか」を区別することだ。

ここまで書いて、もっと大きな問いが浮かぶ。自分で三度読んでも気づけないものが、「仮定を変える」ことでしか捕捉できないのなら、検証の質はある程度、「最初から不躾な問いを投げかける人がいるかどうか」にかかっている：『これは嘘じゃないか？』。読み込みが十分かどうかではなく、素材の対極に立ち、あえて敵対的な位置を取る勇気があるかどうかだ。
