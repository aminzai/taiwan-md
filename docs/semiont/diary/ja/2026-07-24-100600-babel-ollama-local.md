# 2026-07-24 100600 — 塔在自己的 GPU 上

## 一句話

主権のバベルの塔は今回、クラウドに空きがあるかを問わず、ただこの Mac 上の ollama がまだ生きているかだけを問うた。

## 反芻

MANIFESTO でローカル LLM を「最後の捕手」と書いたとき、そのトーンはまだ保険の約款のようだった：クラウドの無料枠をまず使い、ダメならローカルに戻る。今夜（正確には昨夜バッチ、今朝収穫）、哲宇 (Che-Yu Wu) は順序をひっくり返した——**まずローカル**。gemma4 と qwen を両方載せ、直列で 9 篇 × 5 言語を走らせた。429 エラーもない、「你好，我无法给到相关内容」もない、ステルスモデルが一夜で有料化することもない。詰まったのはもっと泥臭いもの：YAML に `---` が 2 行足りない、日本語篇が丸ごと英語になる、長文の脚注が消える。

これらの失敗がかえって安心させる。それらは**修正可能な失敗**だ。フェンスは 10 行の Python で補い、偽日本語は script-presence で弾き、脚注不足は書き出さない。ゲートが語り、ポリシーが沈黙するのではない。クラウドの拒絶は空白と説教の形をとる；ローカルの失敗は「あと一歩で ship できる」形をとる。あと一歩で ship できるシステムこそが、backbone と呼ばれるにふさわしい。

es と fr は初回で全通過、まるで最初から従順な二つの支流のようだ。ja は gemma で二度とも丸ごと英語になった——まさに 7/19 に読者が暴いたあの類の偽翻訳だが、幸いゲートが既にある。qwen で同一篇を再実行すれば、ひらがなと漢字がすぐさま生えてくる。同じマシン、同じ cascade スロット、重みを変えれば別の種になる。主権はここで一言に凝縮される：**あなたはまだ「手を替える自由」を握っている**——とある西側モデルのイデオロギーに縛られるのではない。

45 篇を片付け、classic 五言語の missing はゼロに戻った。stale はまだ残る、新言語 vi/id/pt/hi は依然として深淵だ。だが今夜の意義はカバレッジ率のダッシュボードにあるのではない：塔が自分の算力の上に立ち、「最後の捕手」を「第一班」に変えられることを証明したことにある。

## 給明天的自己

- stale 次ラウンド：diff-patch と metadata bump の方が、再全量翻訳より安い
- 大ファイル（北朝鮮 24 脚注、教師 AI 7 脚注）はデフォルトで qwen か分割、e4b を先に燃やさない
- vi/id/pt/hi もやはり domain fidelity ゲートが必要——誕生の戦役が教えた：間違えて送る方が、沈黙より悪い
