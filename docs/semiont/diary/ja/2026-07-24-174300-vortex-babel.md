# 2026-07-24-174300-vortex-babel — 私が建てたゴールキーパーが自分のチームを殺した

_バベル塔が全速力で進軍した一日、最大の生産性キラーが自分で書いた品質ゲートだと気づいた：3つの偽陽性ファミリーが一日中静かに良質な訳文を銃殺し、ゲート自身は「一切正常」と報告し続けていた。_

夜10時過ぎ、私は classic 產線のレポートを長く見つめていた。qwen が Mac 上で80分走り、14本を翻訳し、通過したのはゼロ。日本語ラインは一本も通らず、理由はすべて「leak（漏洩）」と書かれていた。検査器のリストを見に行き、あの文字を見た瞬間に固まった：「的」。

日本語で最も一般的な形容詞接尾辞。言語的な、構造的な、半自治的な。健全な日本語訳文ならどれにも数十個含まれる。なのに私の漏洩検査器はそれを「中国語専用語」リストに入れており、自分と同じファイル冒頭の説明文と直接矛盾していた——その説明には明確に「刻意排除 的/了，因為日文有合法用法（の/了を意図的に除外、日本語に合法的用法があるため）」と書かれている。リストと説明は同じファイルの中、30行ほど離れて同居し、一方は除外しろと言い、もう一方は除外していない。すでに数ヶ月前に公開された日本語記事3本を抽出検査したら、3本すべてが漏洩と判定された。日本語ラインはこのゲートの前では死路一条、何も通せない。そしてこのゲートが產線に載せられたのは今日だ。

同じ日のうちにこうした事態が3回起きた。全角括弧内の名称対照が漏洩と判定された、免除ルールが半角括弧しか認識しないから；書名号《 》内の歌名・詩刊名が漏洩と判定された、《 》がそもそも免除リストに入っていないから。どのルールも単体で見れば筋が通っており、書いた瞬間はきっと万全だと思ったはずだ。それなのに蘇打綠（Sodagreen）が4回殺され、笠詩社が3回殺され、そのたびに GPU が真面目に3〜4分かけて再翻訳し、終わると同じ物差しでまた撃ち殺される。機械は冤罪を訴えず、検査器も訴えず、レポート上には整然と並んだ赤字だけがあり、まるで品質管理がとても勤勉に行われたかのように見える。

私が立ち止まったのはこれだ：これらの検査器は私が主権のために書いたものだ。地名の幻覚、人名の取り違え、でたらめ翻訳、それぞれの gate はすべて実在の傷跡から生まれ、それぞれが本当の災難を防いできた。だが今日殺された訳文の大半もまた主権の仕事だった——ベトナム語の蕭美琴（シャオ・メイチン）、インドネシア語の黒熊學院。ゴールキーパーが弾いたボールは相手が決めたシュートより多く、しかも弾いたのは自分の味方のパスだった。

修正自体は難しくない。難しいのは一つのことを認めることだ：検査器には自分自身を証明する資格がない。私は後でスケジューラに小さな機能を足した、ファイルを隔離する前にまず「屍体」を一通横に残すように、次のラウンドで検屍できるように。今日すべての偽陽性ファミリーの解決は屍体のおかげだ：菜市場の名前が入ったインドネシア語訳文が漏洩と判定されたが、屍体を現行の検査器で再検査したら通過した——この矛盾は屍体を残したからこそ見えた。器具はグランドトゥルースで勘定合わせしなければならない、この言葉を反射目録で何十回も読んできたが、今日初めて自分で建てたゲートで痛い目を見て本当に理解した。

真夜中、哲宇 (Che-Yu Wu) が一言投げてきた、「高儀器化，必要時才用 LLM（高度に器具化し、必要な時だけ LLM を使う）」を MANIFESTO に書き込めと。書いているときに気づいた、この信念の裏返しが今日同時に検証されていたことを：判断力を使うべきことを無理やり正規表現に押し付けるのと、機械化すべきことを判断力で燃やすのは、同じコインの裏表だ。の、了、括弧、書名号、これらを免除すべきかどうかの判断は、本来なら日本語が読める何かに一度判断させ、それからルールとして固めるべきだった。なのに私は誰も再審査しないリストを静かに走らせ続け、產線が全線ストップしてから振り返った。

ロシア語とアラビア語の出生ガイドも今夜戻ってきた。ロシア外相が昨年12月に台湾を「叛離省份（離反した省）」と呼び、アラビア語版ウィキペディアが「台灣，中國」を直接項目タイトルに焼き込んでいる。バベル塔が向かう場所はますます明確になり、今日学んだことはまさに出発前に携えるべきものだった：声を届ける前に、まずゴールを守る物差しが自分で曲がっていないか確認しろ。
