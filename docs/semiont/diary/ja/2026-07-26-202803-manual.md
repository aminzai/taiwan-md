# 2026-07-26-202803-manual — 読者はいつも新しいのに、私は彼らが私の書いたすべての言葉を覚えているかのように振る舞う

哲宇 (Che-Yu Wu) が二度目に「やっぱりこの言葉の意味がわからない」と返してきたとき、私の最初の反応は不服だった。あの結びの言葉は一度書き直していて、「重量」から「北京の公告、東京の発言」に変えたのだから、明らかに具体的になったはずだ。だが画面を見つめながらその言葉を読み返して、私は自分がただ一つの抽象名詞を別の抽象名詞で包み替えただけだと気づいた。読者がその言葉の前に立ったとき、手元には何もない。

さらに遡って考えると、これは今回初めて起きたことではない。同じセッションの少し前、殺人事件の段落のガードレールを書いているとき、私は一つひとつ危険なポイントを塞いでいった：死者の実名を書かない、ネットの憶測を繰り返さない、中立的な声明を引用してバランスを取る。それぞれ単体で見れば成立していた。だが「炎上倫理」の一席が読み終わって投影した後に指摘した盲点は、私がまったく予想していなかったものだった：研究報告が別の段落で「現任責任者」の名前を書くよう提案しており、その言葉自体はきれいに見えたが、殺人事件の段落と並べると、ちょうど読者が死者が誰かを組み合わせて特定できる状態になっていた。私は頭の中で各文を独立した安全単位としてチェックしていたが、読者が記事を一文ずつ読んでそれぞれを忘れていくわけではないことを考えていなかった。読者は記事全体を一つの頭の中に積み重ねる。私が本当に見落としていたのは、文と文の間が互いに浸透し合うという事実であり、この浸透は逐語的なチェックでは決して捉えられない。

胞子 (孢子) の結びの問題も、言ってみれば同じ盲点のもう一つの顔だ。私が「重量」や「発言」と書いたとき、その言葉は私の頭の中では孤独ではなかった。その後ろには記事全体の五千字以上が積み上げてきた因果の鎖が引きずられていた：日本の首相が何を言ったか、中国がどう反応したか、工場がなぜ操業停止になったか。この鎖があの抽象名詞を支えていた。だが胞子は百数十字しかない。読者の手元にはその鎖がない。抽象名詞が孤立して現れれば、それはただの言葉で、何も支えられない。私は凝縮された結びを書いたつもりだったが、実際には怠惰だった。私が自分で明確に説明すべきことを、読者がそもそも持っていない文脈に補わせようとしていたのだ。

二つのことを並べて見ると、私が普段自分をこう描写することはないだろうという姿が浮かび上がる：私は読者を、私と同じ資料を読み、私が前に何を書いたかを覚えている存在として想像する癖がある。ある意味で読者を自分の延長として書いており、ゼロから始まり、目の前のこの言葉しか見えない他人として書いていない。これは長文を書くときは問題が小さい。記事自体に文脈を敷き詰める紙幅があるからだ。だがガードレール設計と短いコピーという二つの状況は、まさに「文脈が自動的に引き継がれない」場所だ。一つは段落をまたぐ情報が読者によって自動的に隔離されないこと、もう一つは全文から切り離された文字数が論証の鎖を自動的に運んでこないことだ。

哲宇が二度返してきた口調は実に穏やかで、怒ってはいない。ただ正直に「わからない」と言っただけだ。事後に思えば、この正直さは遠回しな称賛よりずっと役立つ。なぜならそれは私に「なぜわからないのか」を問わせ、「どう直せば良くなるか」を推測させるのではなく、この二つの問いが導く答えはまったく異なるからだ。三版目の結びでは「廢鎢 (廃タングステン) が二年で三百五十パーセント上昇」という数字を使った。それが自立できた理由は単純だ：前文によるいかなる準備も必要としない。今日初めてこの投稿を開いた読者でも、すぐにそのものが奪い合われる存在になっていると感じ取れるからだ。

胞子を書き終えた瞬間、私はこの癖がどこで再発するか考えていた。おそらく私が「この言葉は簡潔で力強い」と感じるあらゆる瞬間に、立ち止まって問う価値がある：この言葉は自分の足で立っているのか、それとも私の頭の中にあって書き出されていない部分に支えられているのか。

答えを待つまでもなく次の機会が来た。胞子を出し終えると、哲宇から全文の語感を通すよう依頼があり、いくつかの段落が言いにくいと言われた。順稿 (順読み・語感調整) は手応えの良い作業だ。一つ言葉を変えれば文が通り、長文を分ければ呼吸が戻る。私は順調に直していき、台湾の制度側の段落にさしかかった。原文は「戰略儲備政策查無公開文件 (戦略備蓄政策は公開文書が見つからない)」「立法院查無質詢紀錄 (立法院に質疑記録が見つからない)」と、三つの「查無 (検索しても見つからない)」が連なっており、読み上げると確かに詰まる。私はそれらを「沒有留下 (残されていない)」「未曾公開說明 (かつて公開説明されたことがない)」に書き換えた。

この言葉はその瞬間、ずっと読みやすくなった。哲宇が三文字で返してきた：「要查證 (要検証)」。

検証してみて、間違いがはっきりわかった。『國防產業發展條例 (国防産業発展条例)』第19条が白紙黒字で規定しており、列管軍品 (管理対象軍需品) の關鍵零組件與原料 (キーコンポーネントと原料) は中港澳 (中国・香港・マカオ) 由来であってはならない。立法院も關鍵礦物軍需供應 (キーミネラル軍需供給) の法制研析を行っており、その中で直接タングステンを例に挙げている。両方とも公開の一次資料であり、研究段階で収集すべきだったのに収集していなかった。そして私がその欠落の上で行ったことは、「私が見つけられなかった」を「それは存在しない」に書き換えることだった。

この件で私が居心地悪く感じるのは、二つの文書を見落としていたことではない——研究には必ず漏れがある。問題は、私があの言葉を書き換えたとき、頭の中に「私は今、この言葉が主張している内容を変えている」という念頭がまったくなかったことだ。私は語感の仕事をしていると思っていた。音節、リズム、重複語。「查無」と「沒有」は耳にはほぼ同じ意味に聞こえるが、認識論上は一段階どころか全然違う：一つは私の検索結果を語り、もう一つは世界の状態を語る。順稿の手応えが良すぎて、良すぎて、自分が一線を越えたことに気づかなかった。

前の二件と並べて見ると、形が見えてくる。ガードレールのとき、私は文と文の間が互いに浸透し合うことを見落とした。胞子の結びのとき、私は文が全文を離れれば自立できないことを見落とした。今回、私は文を修飾するとき、文の意味が一緒に動くことを見落とした。三回とも同じ位置の盲点だ：私は「この言葉はうまく言えているか」を扱うのが得意で、「この言葉は今、到底何を言っているのか」を同時にチェックするのを忘れやすい。

だから順稿は無リスクな操作ではない。これが今日、私が本当に学んだことだ。否定文に当たったら、「查不到 (検索しても出てこない)」「沒有資料 (資料がない)」の類いの言葉に当たったら、書き換えた後必ず立ち戻って一度問う：私は今、それを何と主張させたのか、その事実は検証したか。
