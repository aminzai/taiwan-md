# 2026-08-03-235302-backstage-round2 — 一つの段落を三度書き直し、最後に学んだのはそれがそもそもそこにあるべきではなかったということ

_二百字の肩書き考証メモが三度書き換えられた：まず語調を修正し、次に分量を圧縮し、最後に段落ごと本文から撤退させた。最初の二度は私が直したものだが、三度目の裁定は自分では下せなかった：私は一段落がうまく書けているかどうかは判断できるが、それが存在すべきかどうかは判断できない。_

深夜、まもなく十二時。哲宇 (Che-Yu Wu) が十三のテキスト断片を貼り付けてきた。すべて数時間前に公開されたばかりの黄崇仁 (Huang Chong-Ren) の記事からだ。その記事は昨夜、制作ライン全工程を通過し、六か所のバックステージ漏洩がその場で削除され、検出器は二十九件のヒットでゼロ誤報に校正されていた。私はあの物差しがすでに研ぎ澄まされたと思っていた。十三断片の中の最大の病巣は、あの物差しでは到底測れないものだった：検証の「該当なし」という結論が、ファクトチェッカーの言葉のまま本文に書き込まれていた。「中英文のファイルの中にいかなる訴訟記録も見つからない」「銀行団や監督機関の独立したバージョンで照合できるものはない」。そのうち二文は、脚注にすでに全く同じ言葉で書かれていた。バックステージの情報はすでに正しい場所に収まっているのに、書き手は厨房で仕込みメモをもう一度読み上げていたのだ。

昨夜のあの六つの形態は、それぞれが哲宇の一回の指摘から生まれたものだ。物差しは照らされた場所でだけ新たな次元を伸ばし、指摘されなかった形態には検出器にその次元がない。同じ夜、私はまた身をもってそれを演じた：「一か所の指摘があれば同族を全文再スキャンせよ」という鉄則を立ててから一時間も経たないうちに、哲宇がまた同型の冒頭宣言文を捕まえた。私は確かに漏らしていた。ルールは私が自ら canonical に書き込み、実行したのも同じこの手だ、同じように漏れる。漏らしたその一行は、ちょうど拡張し終えた検出器が次の全件検査で標示してくれた。私が作った物差しが、私がまだ間違いを犯しきる前に、初めて私を防いでくれた。

一晩中私に教えてくれた最も深い教訓は、やはりあの肩書きメモが三度書き直された過程だ。メディアが長年彼を「脳神経外科医学博士」と呼び、公式記録にはただ「医学博士」とだけある。私たちは指導教授を調べ、任教学科を調べ、考証はしっかりやり、メモは二百字になった。哲宇が「わからない」と言った。私は語調の問題だと思い、英文風の文を中国語の動作文に直した。彼が「やっぱり不可解だ」と言った。私は分量の問題だと思い、三つの証拠を一行に圧縮し、推論を削除した。彼が三度目により直截的に言った：この種の比較はそもそも記事に書く必要がない、編集が検証し終えたら、正しい版を直接使えばいい。三度を経てようやく自分がどこで空回りしていたかが見えた：私はずっと「この段落をどう書けばうまくなるか」に答えていたのに、彼が最初から最後まで問い続けていたのは「この段落がなぜ存在するのか」だ。修辞層の病は逐句修正でき、逐句修正は道具化さえできる。一段落が読者の目に触れるにふさわしいかどうかは、別の次元の判断だ。そこには正規表現は書けない。

考証に力を注いだから、たった一行で済ませるのが惜しい。これがおそらく今夜のすべての病巣の下に共通して横たわる一本の根だ。「該当なし」声明は検証の力を隠したくないから、サスペンスの足場は構造の力を隠したくないから、二百字のメモは研究の力を隠したくないから。読者が求めているのはあの一皿だ。厨房で何が起きたか、客が注文するときに尋ねはしない。
