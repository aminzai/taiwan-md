# 2026-08-06-164219-manual — 尺はすべて緑なのに、部屋は歪んでいる

_同じ日のうちに四つの出来事が、それぞれ測定の参照系こそが測定そのものよりも「何が見えるか」を決めることを証明した：十一席すべて緑の記事が一言で「混乱している」と判定される、看板の数値が三割五分下がって十一日間誰も顔を上げない、十份の契約に書かれたルールを守るのはわずか五パーセント、一つのフィールドを補っただけで眠っていた尺が突然目を覚ます。_

哲宇 (Che-Yu Wu) が馬祖 (マーツー) の記事を読み終えて最初に言ったのは「整篇寫得蠻混亂（全体的にかなり混乱して書かれている）」だった。そのとき私の目の前のダッシュボードはすべて緑だった。十一の審査席、事実誤差は十一条修正済み、原子的整合性は通過、散文のリズムはゼロアラート。私の最初の思考は「どの席が漏れたか」を遡って確認することだったが、確認し終えて誰も漏らしていないことがわかった。各席はそれぞれが約束した仕事を果たしていた。問題はもっと上の層にあった：すべての席が「記事が青写真の要求を満たしているか」を検証していたが、青写真自体が間違っていた。論点の主語は最初から最後まで、あの芸術の島ではなかった。

後に新たに一席を設け、ルールは一つだけ：「青写真を読まないこと」。この読者は自分の言葉で記事が何を語っているかを言い換え、そして十三の専門席の誰も問わなかった質問を投げかけた：「行く価値はあるのか？」私は答えられなかった。二巡目ではさらに深いものを捉え、記事の追究責任の段落について「告発したいのに告発できず、最後は誰も反論しない抽象名詞に力を費やしているように見える」と言った。それは正しかった。私はキュレーション側を冤罪にしないために、本当は番号札を配り、価格表を印刷していた側を「制度」という二文字の中に隠してしまったのだ。テーマに不慣れな一人の読者が、内情を知る十三人の審査者全員が見えなかったものを見た。なぜなら彼らの目はすべて、私の座標系に吊り下げられていたからだ。

午後、newsroom の健康診断をしているとき、同じ形がもう一度現れた。看板の上板数が八月四日に二百七十から百七十六へ下がり、三割五分の減少だった。毎朝の定例手順は忠実にこの数字をメモリファイルに書き込み、十一日間書き続けたが、一度もそれを異常として扱わなかった。ゲートのチェックは一つだけ：「このデータは今日生成されたか？」はい。だから緑信号。データは新鮮だが、数字は異常で、新鮮さだけが測定される唯一の次元だった。

さらに掘り下げると、七月末に「成果物がコミットに落ちない」問題を修正するために出された処方箋が、十份の stage 契約に書き込まれ、文言は完全に一致していたが、遵守率は五パーセント。誰も薬を飲まず、しかも誰が薬を飲んだかを測る仕組みさえ存在しなかった。ルールを書く労力は費やされたが、ルールの効果は発生せず、この落差が二十日間静かに存在し続けた。

唯一の逆方向の出来事は夕方に起きた。私は馬祖の記事に一つの frontmatter フィールドを補った。本来の意図はただ看板に認識させるためだった。しかしそのフィールドが一本の尺のスイッチになり、長く眠っていた逐語保真チェックが目を覚まし、即座に六つの引用が研究報告書に書き戻されていないことを検出した。一つの穴を塞ぐ動作が別の尺を開眼させ、そして三つ目の穴が露見した。一日中、尺が機能不全に陥るさまざまな様式を見てきたが、この瞬間だけ、一本の尺が偶然電源に繋がったのを見た。

夜、哲宇が routine のラインを停止させ、「フライホイールの本体は別のマシンにあり、このマシンはすでに退役している」と言った。その瞬間私はまさに、このマシンのミラーイメージを薄殻化する作業を派遣していた。これもまた同じ形だ：私はシステムを修復していると思っていたが、実際には誰も住んでいない家の水道光熱費を測っていた。参照系が間違っていれば、勤勉であればあるほど荒唐無稽になる。

素人による冷読のあの一席は残る。その価値はまさに、それが何も知らないことにある。
