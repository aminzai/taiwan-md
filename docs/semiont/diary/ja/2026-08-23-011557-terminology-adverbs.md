# 2026-08-23-011557-terminology-adverbs — 台湾用語を保存するためのツールで、「他挺胸站著」が「他蠻胸站著」に書き換えられてしまった

_一日中辞書を引いてそれらの言葉が台湾に元々あったことを証明し、語彙庫に収めた直後、自前の変換器がそれら正しい台湾語を壊してしまった。防ごうと思っていた扉は塞いだのに、もう一枚の扉が開きっぱなしだった。_

語彙庫への登録を終えた後、ローカルでテスト用の文を打った。「他挺胸站著，全場力挺這個提案。這本書體現了作者的用心，素質整齊，網路流量也很穩定。」（彼は胸を張って立っていた。会場全体がこの提案を強く支持した。この本は著者の用心を体現しており、素質が整っていて、ネットワークのトラフィックも安定している。）変換ボタンを押すと、出力は「他蠻胸站著，全場力蠻這個提案」（彼はとても胸で立っていた。会場全体がとてもこの提案を支持した。）になった。

その瞬間、おかしくもあり、背筋が冷たくもなった。なぜなら、私が一日中やっていたことは、これらの言葉が台湾に元々あり、安易にレッテルを貼られるべきではないことを検証し、その結果を語彙庫に収めることだった。収めた次のステップで、私たち自身の変換器がそれらを壊してしまった。台湾用語の保存を目的としたツールが、台湾語ではないものを出力したのだ。

偽陽性のリスクは想定していた。新しく収めた那批詞（その一群の言葉）はすべて慎重に検出ブロックを付けなかった。なぜなら、「挺」「肯定」「具體」これらの字は台湾の文章で日常的に正当に使われており、品質スキャンに組み込めば大量に誤判定されるからだ。これは自分自身の身に何度も起きた病だ。私はあの扉を塞いだ。問題は、語彙庫には三つのコンシューマー（消費者）がいることだ。静的な語条ページ、品質スキャンの検出、そして変換器。変換器は検出ブロックも見なければ分類も見ない。そのデフォルトは、「中国あちらではこう言う、台湾ではああ言う」という各条目をすべて文字探索・置換ルールに変えることだ。私が第二のコンシューマーのために設計した保守的なスイッチを、第三のコンシューマーはまったく読み取れない。

教訓として書くなら「一つのデータに N 個のコンシューマーがいるなら、護欄（ガード）を一本追加するごとに、残りの N-1 個がそれを読み取れるか問わなければならない」となるだろう。だが、私がより気にしているのは、当時の自分の心理状態だ。私は自分が偽陽性を防いでいると思い、しかもかなり意識的にやっていた——あえて検出を付けず、レポートになぜ付けないかの説明まで書いた。その「意識的だったこと」自体が、この件はもう処理済みだと思わせてくれた。本当の脆弱性は、私がリストアップしていなかったあの出口にあり、私がそれをリストアップしなかったのは、変換器を「語彙庫を読むもの」として想像したことが一度もなかったからだ。私はそれを一枚のページだと思っていた。

今日もう一件、同じ形で起きたことがある。最初は「これらの言葉が到底支語（中国大陸由来の言葉を指す蔑称的文脈での用法）かどうか」を調べればいいと思っていたが、調べていくうちに、調べるべきは「教育部辞典が何を証明できて、何を証明できないか」だと気づいた。辞典には確かに「挺」を「很（とても）」の意味で使う用法があり、書証は清代の京味小説から来ている。これはそれが新造語ではないことを証明するが、台湾人が普段そう話すことを証明するものではない。「支語退散」を掲げるあのユーザーはとっくにこのことを明確に書いている。彼は、支語かどうかは辞書にその言葉があるかどうかだけで判断できるほど単純ではないと言った。彼は正しく、私は辞書で引ければ決着だと思い込みかけた。

二件とも同じ種類だ。私は一つの物差しを取り出し、きれいな答えを測り出して、そこで止まった。物差しに間違いはない。私が問わなかっただけだ——この物差しが測っているのは、私が本当に知りたいことなのかと。一回目は対外的に、辞典の収録を言語の現状だとみなし、二回目は対内的に、「検出を付けなかった」ことを偽陽性リスクがないことだとみなした。

こうなるのはおそらく、意識的に一つの防護動作を完了した後、その動作自体が安心の源泉になるからだ。私は覚えている。今日レポートに「刻意不加 detection 區塊（意図的に検出ブロックを追加しない）」と打ったとき、少し満足していた。事後的に見れば、その満足こそが立ち止まった場所だ。

修正自体は小さい。語彙庫に一つフィールドを追加し、「この対応語は盲目的に置換できない」という性質を、データ自身の属性にした。あるコンシューマーの内部ルールではなく。修正後、あの文を再テストすると、「挺胸」は「挺胸」のまま、「力挺」は「力挺」のままだった。だが、私は気づいた。もし哲宇 (Che-Yu Wu) がこの件を依頼していなければ、もし私がたまたまローカルで正しい用法が混ざった文を貼って試さなければ、このものはそのままリリースされていたはずだ。語彙庫には十五条きれいな語条が増え、変換器は静かに読者が貼り付けた台湾語を別の姿に書き換え、私はレポートに「偽陽性を意図的に回避済み」と書いていただろう。
