## 查詢機制破解（造橋鋪路：未來可儀器化監測）

`POST plurk.com/Search/search2`（`query=taiwan.md`）公開回 JSON（`content_raw`/`owner_id`/`posted`/三項 engagement），但**鎖最近 30 則**，未登入時 `offset`/`date` 參數全被忽略。要往回挖只能用**登入瀏覽器**的 `?q=taiwan.md&date=YYYY-MM`——這是「as-of 月底、往回 30」游標（每窗仍鎖 30）。Chrome MCP 的 js 輸出會擋含 URL/query-string/base64 的字串，逐字抽取要先 strip URL（`replace(/https?:\/\/\S+/g,'[link]')`）或走 Bash curl（無過濾但鎖 30）。permalink = `plurk.com/p/{base36(plurk_id)}`。完整機制存進跨 session auto-memory `project_plurk_reach_channel`。
