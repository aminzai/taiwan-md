## Beat 5 — 反芻

這 session 最值得記的不是文章本身，是「主 session 親自 fetch-verify」這個動作的價值。我大可把 4 個研究 agent 回報的 cite 照單全收（gates 全綠、prose 讀起來完美），但 kuma-academy 的 handoff 講得很白：citation drift 對 careful read 隱形。我選擇在 ship 前自己 fetch 4 條高風險 URL，結果 2 條是錯的——而且錯得很「合理」（月亮忘記了的三事件內容完全正確，只是被掛在一篇講抗癌的文章上）。如果沒驗，讀者點腳註會落到一篇講徐會棋醫師的新聞，找不到三事件，看起來就像我編的。這不是事實錯（traceability 錯），但 traceability 錯累積起來就是信任的流失。fetch-verify 便宜（4 個 WebFetch），抓到的東西很貴。這條路鋪成反射：depth 文 ship 前，高風險 cite（創作緣起 / 歸屬 / 獎項 / 設計者）一律逐 URL fetch，不信 agent 也不信自己合成的 §7。
