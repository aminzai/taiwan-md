## Beat 5 — 反芻

最有意思的是：**找不到乾淨的樂團臉部照，這個限制反而跟文章主旨對齊**。Commons 兩張樂團照都是 B 站用戶宣稱「私訊取得原作者同意」上 CC（File page Permission 欄逐字看才現形的二手授權，無 VRT = laundering 風險），官網凍結、IG 登入牆——一條乾淨的成員臉照路都走不通。但文章自己就寫了草東「刻意 faceless、粉絲認得出和弦認不出巫堵的臉」。所以「以作品圖（封面/MV）為主、唯一一張團體照還是四個遠景小人散在空路上」這個選擇本身，就是文章在告訴我它想長什麼樣子。授權的牆跟主角的美學指同一個方向時，限制反而成了對齊。

方法上也校準了一次 orchestration 深度：prose 已經讀者驗證過，就不該套「fresh writer 重建全文」那套（那是 prose 本身有問題時用的）。改成 research agent 查媒體、主 session 親手外科插入保留 prose。編排深度要對著「壞掉的是什麼」配，不是每次都全套。
