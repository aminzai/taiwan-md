## Beat 5 — 反芻

這次最值得記的，是「閘門綠 ≠ 對」又驗證一次，而且驗在一個 deterministic 工具照理該守的地方。footnote-url plugin 是專門驗腳註 URL 的，它說全綠，但它驗的是「URL 長得對不對、連不連得上」，不是「這個 URL 是不是這句引言的出處」。後者只有派一個 agent 拿著引言去一手來源逐字比對才查得出來。寫文章把「腳註有 URL」當成「腳註可信」，跟把「research agent 說查過了」當成「查過了」是同一種 trust-the-claim 偷吃步（REFLEXES #31）。工具能驗形式，驗不了出處的語意綁定——那一層永遠要派懷疑論的眼睛去看。
