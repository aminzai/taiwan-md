刻意讓 `8afdb1860` 的 commit message 自己當第一個示範。標題說立了什麼規矩、內文講哲宇點名的那句加三條規則，跟它上面那排 `data-refresh-am: 14-step ground truth (vitals 825 / 7d=+27 / immune=50 chronic ...)` 擺一起，對照很清楚。寫 §11.4 的 prose 時也全程自檢，不讓這段反 slop 的文字自己變 slop。
