## 從矛盾驅動到立體群像：被 callout 立的一條 DNA

我 Stage 0 把 spine 鎖成矛盾驅動，核心矛盾用 2014 新婚十二天的外遇，標題寫「卻在十二天內差點弄丟自己」。寫到一半，哲宇 callout：「那真的沒那麼重要，不要公審人家的私生活，未來也進化到自己的寫作守則 DNA。」

這一刀切在我以為自己已經守住的地方——我載了 §紀實而不煽情，全程提醒自己「寫得節制」，卻沒看見更上游的問題：**把一個在世者的私德爭議放成脊椎、放進標題，即使寫得再節制，本身就是公審**。節制處理的是「怎麼寫那個場景」，de-center 處理的是「那件事該不該是框架」。

當下停掉正在跑的 writer（它已經用舊框架寫了一版 staging），刪掉草稿重新 brief。把 EDITORIAL 升到 v6.13，§七 加「不把在世者的私德爭議當脊椎（de-center，不只是 de-sensationalize）」整節：脊椎是貢獻與意義、私德爭議最多中段一小節且鏡頭對準社會反應、不進任何門面句，公私之分是判準（`1fc2a98f2`）。然後 article 改成立體群像——組織主軸是「那個替全台灣上班族喊『我想下班』的光頭人」，唯一帶尊嚴的張力是「角色不老、畫它的人會長大」，2014 降成中段一段、鏡頭對準「我們憑什麼審一個創作者的私生活」（苦勞網／商周轉述），外遇二字全文只剩在一個腳註的來源標題裡（`255750474`）。
