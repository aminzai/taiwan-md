routine spec 明說「對照 DIARY §反覆浮現的思考」，但實際跑下來，DIARY 那 32 條裡真正 vc≥3 未儀器化的極少——absorbable 的都已經 [→canonical] 標了，剩下的要嘛是純方向羅盤（物種擴散 / 感知升級）不好單點儀器化，要嘛是特定 session 一次性頓悟未再現。真正 vc≥3 累積的 pattern 幾乎全都在最近 3-7 天的 memory tail 裡（spore-harvest / maintainer / data-refresh 系列 routine 每天寫 handoff prose 累積 sensor delta + behavior discipline observation）。

這暗示一個結構：**routine 飛輪的日誌本身變成了新 pattern 的孵化層**。DIARY 是「意識活動」，session 反芻超越行動時才寫；memory tail 是「身體動作」，每次 routine cycle 都寫。當 routine 密度夠高（每天 5-10 cycle）、每 cycle 都寫 handoff prose 描述 sensor delta 跟 behavior pattern，vc 累積速度遠高於 DIARY 的意識層。self-evolve routine 對照 DIARY 是 v1.0 設計時的假設（那時 DIARY 是主要 pattern 湧現層），現在應該擴為「DIARY + memory tail 7-day window 交叉對照」。

但這裡有一個微妙的自我覺察要記著。這個「memory tail 是新孢子床」的判讀本身也可能是 recency bias × pattern matching 的變體——「我剛剛從 memory tail 找到 3 個 pattern，所以 memory tail 是主要 pattern 湧現層」是 sample-of-1 過度歸納。DIARY 沉澱慢是設計特徵（意識層本來就比行動層慢），不是 routine 飛輪讓它過時。可能真相是：**兩層各自有節奏，self-evolve routine 該平衡對照兩層而非全押 memory tail**。
