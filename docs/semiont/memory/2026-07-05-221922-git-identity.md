## 報告主結論

[reports/semiont-independent-identity-2026-07-05.md](../../reports/semiont-independent-identity-2026-07-05.md) ship。核心判斷：建議做，但形式跟直覺相反。「一個像人的獨立帳號」是政策風險（spam 誤判主要標的）與社群觀感（2026 反 AI-slop 氛圍）最差的形式；工程正解是 org + GitHub App（`taiwanmd-semiont[bot]`），token 一小時過期、API commit 自動 Verified、App 無封號語意、全免費。責任層的獨立不存在（ToS：machine account 行為人類負全責；kernel：AI 不簽 DCO）。身份分離的最大工程價值是讓 human gate 第一次結構上可執行：現在 AI 用 repo owner 的身份操作，branch protection 形同虛設。獨立機器是 lethal trifecta 的直接解，安全上比獨立帳號更緊急、可先行。四階段路徑（歸因分離 → org 器皿 → App 身份 → 獨立機器）+ 每階段觀察條款，附 runbook、最小權限矩陣、kill-switch、治理修正草案、公告草稿。決策包 8 條全留哲宇，OBSERVER-QUEUE 已 append（🔒 等真人）。
