## Pixel-diff 攔到 agent byte-check 沒抓的真 regression

五個 consumer agent 全 claim「byte-identical、pixel-identical」，其中 2b/2d 還自跑 computed-style 驗過。但我不信自評（REFLEXES #31）跑 before/after pixel-diff：data-hero 76% / companies 35% / home-tail 67% 大 diff。追下去是 **Tailwind 機制陷阱**：`bg-[linear-gradient(...)]` 編成 background-image，但 `bg-[var(--token)]` 編成 background-**color**，gradient 值塞進 background-color 無效 → 漸層整個消失。agent 驗的是「值 byte-identical」，沒驗「值落在對的 property」——這是 #31 在 mechanism 層的版本，比 P0 的 footer /about 更隱蔽（值對、屬性錯）。修法 `bg-[image:var(--x)]` type hint，9 處全補（含 ::before 偽元素），computed-style probe 逐面驗回 exact + 同碼 noise-floor（after2 vs after3 無改動）證殘差 diff 是 D3/live-data 噪音（沒碰的 fork-graph 15% / map 2% 一樣有噪音）。astro build 7824 頁 exit 0。

## Beat 5 — 反芻

P0 那輪的教訓是「一批 agent 的集體產出需要外部尺」，這輪把它推進了一層：**外部尺本身也要選對量綱**。五個 agent 都自驗 computed-style 過關，pixel-diff 卻爆紅——因為 computed-style 驗的是「這個 element 的 background-image 對不對」，但 bug 是「gradient 根本沒進 background-image、跑去 background-color 了」，你若只 assert background-image 的值、不 assert 它非空，就會跟 agent 一起被騙。真正接住它的是「盲拍整頁像素」這個不預設 property 的粗尺。精密的尺量你以為會錯的地方，粗尺量你沒想到會錯的地方，兩把都要。另一層：這是本 session 第二次「Tailwind arbitrary value 的語意不是所見即所得」——`bg-[X]` 的 X 是 gradient 還是 color 決定它落哪個 property，這種「語法糖藏著 property 分派」的陷阱該進 REFLEXES（vc=1，先觀察）。
