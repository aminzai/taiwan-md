## 機制與 invariant

先釘死機制：頁面過 `readerSettings={true}` 才會被套 `data-theme='dark'`（HeadInlineScripts `if(!__TW_MD_READER_SETTINGS)return`），dark-polish.css 存 `:root[data-theme='dark']` override。所以每頁深色 = 加 readerSettings + 讓色彩響應（token 自動翻 / 硬編碼靠 dark-polish 規則）。invariant 跟前兩輪相反：**深色是刻意改外觀，但淺色必須 pixel-identical**（每條規則 scope 在 `[data-theme='dark']` + 頁面 wrapper 內）。驗證量綱也因此不同——不能用 pixel-diff invariant，改「淺色實拍逐張比對未變 + 深色目視 legibility + 關鍵頁 computed probe」。
