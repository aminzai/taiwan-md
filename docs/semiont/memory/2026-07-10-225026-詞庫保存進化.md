## LLM 全審器（新器官）

用語詞庫是 `data/terminology/` 底下 2,334 個 YAML，把台灣用語對照中國用語，是主權基建的語言本體。既有
10 支工具全是確定性 regex/白名單，完全沒有 LLM 審查詞條品質這一塊——哲宇要的「完整重看一次」得從零造。

新造 `terminology-llm-review.py`：本地 Ollama（qwen3.6:35b）兩層審查。Tier 1 本地模型全掃 2,308 條判
verdict＋issue_type，Tier 2 我（Opus）人在迴路 adjudicate。選本地不選 cloud 有兩個硬理由——詞庫含
屏蔽/翻牆/戒嚴 這類主權敏感詞，cloud content filter 會擋（2026-06-13 audit 就是 Opus agent summary 被擋
什麼都沒落檔）；加上 2,308 條走 API 有成本、本地零成本零出境對齊主權 cascade。跑完 2,544 秒、0 失敗、
536 flag（23%）。

過程最花力氣的是校準。第一版 prompt 要求「嚴謹不客氣」，flag 率飆到 57%，而且把正確的學術對照
（亂數/隨機數、事前機率/先驗機率、互斥或/異或）誤判成「欄位相反」——模型對台灣學術譯詞不熟就自信亂殺。
重寫成保守預設 OK＋明列不該誤殺的錨點＋不確定降 SUSPICIOUS，flag 率掉到 17%，真問題仍抓得到。這條進
LESSONS。
