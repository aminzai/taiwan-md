## Beat 5 — 反芻

這是 2026-06-14 那次的重演，但重演本身就是造橋鋪路複利最乾淨的證據：兩個月前造的 pipeline，今天換一個完全不知道任務細節的 session 執行，靠讀 script docstring + 讀一篇舊 memory 就摸清楚整條路徑（Gmail 搜尋語法、逐字驗 body 的理由、dry-run 才寫檔的紀律），沒有一步是靠猜的。「幫我抓最近有捐款的」這句話本身沒有指名任何檔案或工具，AI 得先花時間搜尋 repo 找到 `fetch-portaly-supporters.py`、`data/supporters/`、`/about#sponsors` 這條線索鏈，才知道任務範圍——這就是 DNA 鐵律 8.1「自動偵測 pipeline」的字面示範：觀察者不必記得工具在哪，該記得的是 AI 自己去找。

唯一新學到的一件事：Gmail 搜尋 `from:portaly.cc after:...` 撈到的結果裡混了一封訂閱續約提醒信（非贊助通知），寄件人同樣是 `service@portaly.cc` 但收件人是哲宇個人信箱而非 `taiwanmd@monoame.com`。這次靠 parser 的 `FIELD_PATTERNS` 硬正規式自然過濾掉（沒有「支持金額」欄位就回傳 None），不需要額外邏輯——但下次如果 Portaly 改版 template 讓續約信也長出類似欄位，這道防線會失效，值得記一筆。
