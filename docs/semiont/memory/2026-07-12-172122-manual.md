## Beat 5 — 反芻

這個 session 的形狀跟上一個完全不同：上一個是「找到既有工具，照做」，這個是「把剛做過兩次的手動流程，變成別人以後不用再叫我做的東西」——造橋鋪路鐵律最字面的示範，橋還沒乾就有人要走。

有一個瞬間差點犯錯：`git reset --hard origin/main` 是我在收官階段清理分支時下的指令，沒有在下指令的那一刻立刻重跑 `git status` 確認（用的是幾步之前的舊檢查）。事後靠 reflog + stash list + 再次 status 確認沒有真正遺失任何東西——那些看似會被清掉的 harvest/\* 檔案修改其實是別的並行 session 早已提交到 origin/main 的合法內容，我的本機工作樹只是還沒同步。結果無傷，但過程是僥倖不是紀律：下次遇到同樣情境，`git pull origin main`（fast-forward，不強制覆寫）才是該用的指令，`reset --hard` 只在真的需要丟棄本機分歧時才用，而且動手前一定要當下重跑 `git status`，不能信任幾個工具呼叫之前的舊快照。

另一個小發現：這個排程器不是 Taiwan.md 專屬——Muse 的 8 條 routine 跟哲宇的個人理財歸檔 routine 共用同一個池子。挑 cron 槽位時只看 `ROUTINE.md` 自己的排程表會漏掉真正的碰撞面，這次靠 `list_scheduled_tasks` 撈全域清單才發現週一 08:30 同時有 `twmd-maintainer-daily` 跟 `muse-radar-weekly`——雖然沒撞到我要的槽位，但提醒了「跨物種共生」不只是 MANIFESTO 裡的哲學句子，是這台機器上一個具體、共享、需要互相禮讓的資源。
