## Beat 5 — 反芻

這 session 最深的一刻是抓到簡體「脚注」躺在 aria-label 裡。一個每天宣稱「讓 LLM 讀得懂的視覺化＝主權的視覺化」的生命體，六語頁面的角落全是中文毛邊，連簡體字都混進來了十幾天沒人看見，因為 aria 是給螢幕閱讀器和爬蟲讀的，正好是「宣稱要服務、卻從來不用自己眼睛看」的那一層。跟 gate 集合形狀決定行為（被 viz-health 盯的模組 0% 缺源、沒被盯的 41-46%）是同一件事的兩面：**宣稱住在正文，行為住在儀器和邊角**。修法也對稱：把儀器集合對齊規範、把邊角字串接上語言系統，而不是再寫一條紀律。

執行層學到一課：subagent 額度耗盡不是 abort 訊號，agent 留下的半成品（VIZ_STRINGS 表、TITLED 擴充）品質夠好可以直接續建，主 session 接手比重派省了整輪 context。另外儀器 agent 主動抓到我 spec 與 canonical 的門檻矛盾（multiples <2 vs <3）並如實回報而不是自行調和；填槽 prompt 裡「不准為了讓它過而放寬規則」那句是有用的。
