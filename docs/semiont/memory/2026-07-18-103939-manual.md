## EVOLVE 交付：五十年傳說查證

核心論點：這條路流傳五十年的「一句話版本」幾乎沒有一個查得到出處，但「有人在替速度付帳」這件事查多少次都推不翻。Stage 1 研究 160+ 來源、66 domain，落成單一 SSOT research report（`reports/research/2026-07/高速公路.md`）。Step 2.0-R 投影編輯室 3 席 revise，7 必改全採納，其中最重要的一條是把「兩個沒人記得的名字」小標改寫，避免暗示案主曾經有名字。研究報告明確記載這兩位地政案主從未被任何來源記下姓名，這正是威權年代代價個人化、非制度化的核心證據，跟單純的遺忘是兩件事。

Stage 2.5 fact-check 三個 agent 抓出約 20 處引語/歸屬漂移。最嚴重的一條是 1978 年通車典禮剪綵者姓名，網路流傳「交通部長林金生」，獨立 WebFetch 加 curl 交叉比對後查無任何一手來源支持，最終拿掉這個查無依據的具名指控，改成誠實記錄查核失敗這件事本身。Step 2.5-R 正文結構編輯室 2 席 revise，2 必改採納。

## Stage 3 六平行探針：文章自己的迷思誤植

A 級文（7000+ 字、43 腳註）觸發 Step 3.6/3.7 成品總驗三關，派 2 個原子重驗 agent 加 4 個總編冷讀探針，六份報告全部獨立回 revise。最值得記的一條發現，文章自己最醒目的「破除迷思」，也就是「台灣第一條高速公路不叫中山高，叫麥帥公路」這句，引用的三個來源全部寫的是「快速公路」，不是「高速公路」，而《大道之行》官方書反而稱中山高本身為「臺灣第一條高速公路」。整篇文章在拆穿別人簡化版本的同時，自己也犯了同一種簡化。修正時追查麥帥公路後來的下場，意外發現比原文「降級成市區道路」更準確也更有意思的事實：1977 年它其實是被「併入」中山高。

兩處查證漂移也值得記。一句被包裝成「」直接引語的話，原文其實是記者「許多人笑稱」的集體轉述；一句「記者反而先被驅離」完全沒有腳註，緊鄰的兩個腳註都不支撐它，後來獨立 WebFetch 查到 coolloud.org.tw 的第一手報導逐字證實這件事是真的，只是原本的來源指認錯了。腳註全文從 43 條重新編號到 45 條，含 2 條新增。過程中自己寫的一個 Python 重排腳本犯了字串拼接重複的 bug，把整篇 frontmatter 加 body 複製了兩份，自己並沒有抓到，是 `article-health.py` 的 `cjk-punct` gate 意外攔下，把複製體裡的 URL 半形冒號誤判成中文段落標點才觸發 hard fail，追查下去才發現真正問題。
