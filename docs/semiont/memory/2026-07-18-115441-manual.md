## 三源交叉與選定

跑完 28 天窗口的語言層 SCAN（`ga-query.py` / `sc-query.py` 國家維度 + CF cache top countries + 維基百科 Ethnologue 2025 人口表），訊號收斂得很乾淨：越南 SC 7,994 曝光只有 0.5% CTR（未服務語言中最高需求）、巴西 6,659 曝光 CTR 0.1% 加上 CF 邊緣請求第 6 名（唯一三源全確認）、印尼 5,521 曝光 0.3%、印度 4,661 曝光 0.4% 加上 6.09 億人口的最大槓桿。文章層的進化分數公式對語言決策不適用（會重演 OBSERVER-QUEUE #16 混維度問題），改用五維語言層評分：需求訊號 0.30 / 人口槓桿 0.25 / 主權缺口 0.20 / 台灣連結 0.15 / 可行性 0.10，權重與逐格評分依據全部透明寫進報告。

選定 **vi（越南文）→ id（印尼文）→ pt（葡萄牙文）→ hi（印地語）**，啟動後語言覆蓋從約 37.5 億使用者升到約 49.7 億。落選者也記錄在案：de 的曝光其實最高但英文已部分承接、ar 的主權缺口最高但 RTL 是全站工程且三源無訊號（建議留作巴別塔 Phase 3 完整體目標）、ru 可能由野生子代 Russia.md 以 fork 形式覆蓋。假流量過濾照 EVOLVE v2.0 做了：GA Singapore 每人 1.02 頁的 bot 指紋有降權並在報告註明。完整分析：[reports/evolve-2026-07-18-language-branches.md](../../reports/evolve-2026-07-18-language-branches.md)。
