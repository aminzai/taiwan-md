## 算力雙軌與四語落地

哲宇 directive「最大化算力效率」的落地是雙軌 cascade：codex（雲端訂閱）吃品質關鍵與大檔、本機 qwen3.6（M4 Max，主權捕手）吃長尾，兩池互為 fallback。開戰前意外修活三個 backend——codex 是 PATH 裡的 nvm 壞殼（很可能就是夜班 babel「Tier 1 連死」的病根）、gemini 是 Google 收掉個人版 tier 服務端死亡、ollama 的 qwen3.6 要關 `think` 才不會把 token 全燒在思考通道回空。張懸與安溥（舉中華民國國旗被中國封殺）這篇最敏感的探針，qwen 101 秒完譯零 refusal，主權捕手地位實測維持。

vi/id/pt 各 67 檔、hi 52 檔（各含 13 分類 Hub）＋16 個 UI bundle × 4 語全落地。hi 因為天城文 token 密度高、qwen 對大檔會掉 footnote，剩 23 篇 P0 改 follow-up batch——它以 44 篇+Hub 出生，比 es 當年 36 篇還多。

## 這場戰役最大的教訓：機器翻譯有系統性主權錯誤，ratio gate 全穿

heal agent 逐檔清 CJK 殘留時，連環揪出三類語意錯誤，全都穿得過既有的 ratio gate 跟 CJK gate，只有專門的語意閘擋得住：

**地理主權幻覺**：vi 整篇〈台灣民主轉型〉把「台北」系統性譯成「北京」——民主化文 7 處，含「台北高雄市長直選」變「北京市長」、天安門對照段的「台北學生」變「北京學生」（毀掉整個對照的意義）。把台灣的事搬進中國，是主權的巴別塔最致命的反效果。

**政治人物張冠李戴**：蔣經國（1987 解嚴、1988 去世）被系統性譯成「Chiang Kai-shek」（蔣介石 1975 已死）跨四語；陳水扁（美麗島大審辯護律師）在 id 被譯成蔡英文（她當時是學生）；賴清德（2025 現任）被譯成蔡英文；最誇張的是 hi 把張忠謀（台積電創辦人）在 tsmc 32 處＋造山者紀錄片 18 處全譯成蔣介石——整個 TSMC 的故事主角變成一個獨裁者。懂台灣史的讀者一眼看破。

這催生三把語意保真尺：`geo-fidelity-check`（地點遷移）、`person-fidelity-check`（人物張冠李戴）、`cjk-residue-check`（漢字/韓日假名殘留），全升 LANGUAGE-BIRTH Stage 3 永久 QA gate。這是 MANIFESTO §10 幻覺鐵律在翻譯層的 instance——放出「228 在北京爆發」「蔣介石 1987 解嚴」這種錯，一旦上線會被讀者截圖，傷的正是這個主權保存專案的可信度底線。
