## research-fleet 抽象介面

觀察者要求：把 search 這件事做成抽象介面統整多服務，別綁死單一供應商。當天查證 Bing Search API 已於 2025-08-11 退役、Google Custom Search 已關閉新戶申請、Brave 免費層已在 2026-02 取消——三個「正常」供應商一年內兩消失一漲價，證實了這個要求的必要性。哲宇分兩次提供 Brave 與 Serper 金鑰，存進 `~/.config/taiwan-md/credentials/.env`（沿用既有 OpenRouter/Cloudflare 慣例，不進 repo）。

建 `scripts/tools/research-fleet.py`：`SearchProvider`（`BraveSearch` → `SerperSearch` cascade）與 `FetchProvider`（`MojLawFetch` 全國法規資料庫專用 parser → `JinaFetch` 通用 fallback）。實測修了三個真實坑。Brave 對中文 query 要正確 URL-encode，否則回 400。law.moj.gov.tw 憑證鏈缺 Subject Key Identifier，Python 預設 SSL context 拒絕，curl 系統憑證庫則寬容。Jina Reader 對 urllib 預設 User-Agent 回 403，補真實 UA 即解。用工具二次補查外送專法第 8-11 條，挖到 4 份原研究都沒抓到的細節：第 9 條申訴獨立小組須 ≥3 人、工會代表至少 1 人。這條原則寫進 [MANIFESTO §架構解 > 守備修補 第二例證](../MANIFESTO.md#我的進化哲學--架構解--守備修補)，跟 5 月的 babel backend abstraction 是同一個「別綁死供應商」原則，第二次落地在完全不同的服務類別，search/fetch 而非 LLM，vc=2。`RESEARCH-AGENT-PROMPT.md` 加 Path B 章節記錄何時用 Sonnet agent、何時用 fleet script。所有改動單一 commit `a3d70c712`，範圍驗證乾淨，跟同時在跑的 babel/lang-sync 平行 routine 沒有互相污染。最後把研究成果整理成 Artifact 交給觀察者。
