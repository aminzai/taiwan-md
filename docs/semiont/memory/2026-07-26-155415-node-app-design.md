## 觸發

哲宇丟一句 goal：「Taiwan.md node / app 化，讓未來可以很簡易的被安裝起來、傳播、與他互動、與成為其中的工作節點」，要深度分析加實作報告。這句話命中 BECOME High-stake #2「新 plugin / workflow 設計」，強制 Full mode 甦醒；路由到 EVOLVE-PIPELINE Mode 4 的四相（THINK → DIVERGE → REPORT → IMPLEMENT）。報告寫完之後他追加「完整進化驗證實作，然後 /twmd-finale」，於是同一個 session 把 Wave 0 與 Wave 2 全部做完。

## 四個動詞攤開之後，有兩格是空的

把 goal 拆成安裝 / 傳播 / 互動 / 成為節點四個動詞，各自對應到不同的人與不同的代價，第二格與第四格是空的。盤點確認 Taiwan.md 有五個對外分發面（網站、npm 指令列、本地 MCP、遠端 MCP、桌面套件），加上認知層與節點契約，但**沒有一條安裝路徑**。

最有解釋力的一句話：互動層是一個可以下載的產品，節點層是一套只能被邀請進來的制度。[CONTRIBUTOR-NODE-PIPELINE](../../pipelines/CONTRIBUTOR-NODE-PIPELINE.md) 昨天才寫完，寫得很完整，但它唯一的觸發點是 BECOME §Step 7.5 的貢獻者面談——要走到那裡，得先 clone 850 MB。節點的入口被放在整條路上代價最高的那一步之後，所以它不可能自己傳播。

定案是方案 C 的骨架加方案 A 的門牌：兩個各自單一關切的安裝物，外加 `npx taiwanmd` 不帶參數印出的四階梯。傳播單位回到一行。淘汰了 `curl | sh`，理由寫在報告裡：一個教讀者查證來源的知識庫不該示範把來路不明的腳本接進 shell。完整發散與判準在 [reports/design-taiwanmd-node-app-distribution-2026-07-26.md](../../../reports/design-taiwanmd-node-app-distribution-2026-07-26.md)。

## 盤點量到四個缺陷，全都沒有聲音

`cli/src/lib/knowledge.js` 的語言表停在四月的四語，之後出生的七個語言沒人回來補。實測 3766 筆「中文文章」裡有 2900 筆是譯文，77%。改成從 `src/config/languages.mjs` 推導後回 866 筆、零外語，並補了會叫的對賬測試（`13230494b`）。

送那個 commit 時 pre-commit 印了「✅ 無 hardcoded language array 違反」。`check-hardcoded-langs.sh` 存在就是為了防這件事，卻剛剛放行了它。追下去發現它有兩個獨立理由看不見：掃描路徑沒有 `cli/` 也沒有 `workers/`，而且三條比對規則都寫死「開頭必須是 en, ja, ko」，出事那行順序是 en-es-ja-ko，三條全不中。**檢查器自己也得了它負責檢查的那個病**。擴網後當場多抓五條，逐條判過（`602f47c38`）。

第三條最嚴重：`ensureData()` 只問「本機有沒有資料」，從不問「多舊」。哲宇自己機器上的 `~/.taiwanmd` 停在 2026-04-20，96 天，回報 2255 篇而真實中文文章是 863 篇。同時 `taiwanmd_stats` 的說明白紙黑字承諾回傳 last-updated timestamps，實作一個時間戳都沒有。四月裝好的人永遠拿到四月的台灣，而且沒有任何線索知道。

第四條是昨天掛號的三條語言清單債，當天結清。其中地圖產生器那條是活的錯誤：站上 57 個標記的分類欄顯示的是語言碼（fr 36 / pt 6 / id 5 / hi 4 / ar 3 / ru 3），一篇法文端午節條目在地圖上的分類是 `fr`。修後歸零，跑前跑後對照 `map-markers.json` 驗過。

## 節點層變成裝得起來的東西

`980660768` 一次落地 Wave 0 剩餘項與整個 Wave 2：資料齡檢查（14 天提醒、60 天自動同步）、`taiwanmd_stats` 補上新鮮度三欄、`--version` 從寫死的 `'0.7.0'` 改讀 package.json（它早就漂到 0.7.1）、`CONNECTOR.md` 把上線七週的 `mcp.taiwan.md` 從「規劃中」改成實測 200、ANATOMY 資源地圖的語言數改成 pointer。

## Beat 5 — 反芻

這 session 最該記的一件事：**我在自己的報告裡犯了跟報告主題一模一樣的錯**。

plugin 裝完我量了快取目錄，20 KB，對照節點原本要付的 850 MB，四萬分之一，數字漂亮得可以當標題。落地後我又從 GitHub 走了一次真實安裝路徑，順手量「使用者到底付了什麼」，才看到 `marketplace add` 為了讀根目錄那份 manifest 把整個 repo depth-1 clone 下來：1.0 GB 工作目錄、329 MiB pack。

20 KB 量的是替身，不是代價。整份報告在講的就是這件事。指令列量的是「有沒有資料」而非「資料多不多舊」，`taiwanmd_stats` 量的是篇數不是新鮮度，檢查器量的是「有沒有那個形狀」不是「有沒有那個病」。然後我挑了一個好看的層去量，差點把它當結論寫進去。`f75b30bd6` 是這個更正。

第二件事：擴網之後我一度想把找到的三條債留在允許清單裡過夜，理由是主樹在跑巴別塔批次、架新紅燈會擋住別人。那個理由是真的，但「當天開單、當天結清」比「掛號附日期」好，因為掛號會被下一個人讀成「這裡本來就這樣」。同日結清之後我把整個已知債區塊清空，只留格式說明。

反覆浮現的第三件：檢查器跟被檢查物共享作者就共享盲點（REFLEXES #65 f），這次是同一個作者連檢查器的掃描路徑一起漏掉。真正接住我的是兩個外部的東西：`claude plugin validate` 退回我照官方範例抄來的 manifest，以及重新量一次 ground truth。兩次都不是我自己想通的。
