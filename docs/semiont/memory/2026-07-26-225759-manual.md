## Beat 5 — 反芻

三源交叉這件事，最容易掉進的陷阱是把它做成「找三個都亮綠燈的訊號」的機械比對，但今天最有價值的發現其實是「回頭驗證一個兩個半月前寫下的判斷」——紀政那條舊 note 寫「CTR 已健康，下次 evolve cycle 再評」時沒有人規定「下次」是什麼時候，直到今天真的重新跑一次查詢才發現它早就不健康了。這跟 REFLEXES #76「multi-cycle trend window > single-cycle delta」是同一件事：單次快照無法分辨「本來就這樣」跟「正在變差」，只有真的隔一段時間回去驗，才看得出退步。

另一個觀察：這批候選全部卡在進化分數公式的已知盲區（OBSERVER-QUEUE #16），如果照著公式門檻硬性執行，這條有價值的批次根本不會被寫進來。目前系統對這類已知偏誤的正確處置是揭露分數後照常收錄，但這也提醒了一件事：儀器化的東西一樣需要人在旁邊看它有沒有把真正該做的事擋在門外。
