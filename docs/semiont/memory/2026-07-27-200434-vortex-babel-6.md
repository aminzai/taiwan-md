## 儀器盲區：工具存在不等於問題被檢查

哲宇提醒「能重用的東西都要儀器化」，查既有工具時先發現自己重複造輪子——手動跑的三步批次驗證，`verify-batch.py` 早就把八步串好了。但查它為什麼沒抓到那 13,155 筆時，找到更值得記的東西：它第五項名為「cross-article link integrity」，實際 regex 只掃 `](/{lang}/...)` 也就是**已經帶語言前綴的連結**，而譯文最常見的壞連結恰恰沒有前綴。**工具名稱涵蓋了問題，判準沒有涵蓋**，這才是那批連結靜默出貨的真正原因。已改成掃全部再分流判定。

儀器化三原則入渦流 canonical：動手前先查既有工具、同一件事做第二次就該儀器化（判準是次數不是難度）、註解寫「為什麼」不寫「做什麼」，因為判準的邊界是未來想放寬時唯一的煞車。
