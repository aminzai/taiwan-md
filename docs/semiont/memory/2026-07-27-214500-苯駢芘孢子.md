## Beat 5 — 反芻

三個事實偏差的共同根源是「以為不用再查」。文章那一層做得很紮實——三路 falsification、每條 footnote 可溯源、連「48 天」這種自行反推的數字都在 tw-note 裡標明出處狀態。正因為那一層太紮實，壓縮時我把「素材已驗證」讀成「句子已驗證」，於是三個新造的句子帶著已驗證的錯覺出去。真正該有的反射是：孢子的每一句都要當成新寫的句子回頭對源，繼承的只有素材。

同一天三次工具說謊則是另一個形狀：每一次都是工具的適用前提悄悄失效了——PNG 不是文字檔、DOM 還沒 load 完、這個 repo 不只一個 actor 在 commit。工具不會說「我的前提不成立」，它只會回一個看起來像答案的數字。今天早上才在首圖去重那件事上量錯一次替身，晚上又踩三次，形狀完全一樣。四次同形已經到了 pattern 層級：「讀數要連同它的適用前提一起讀」這條紀律還沒長進反射。
