## 教訓

- **弱的尺會放行強的尺會擋的東西。** 10 條站內死鏈 commit 出去，不是因為沒查，
  是我在對話裡現寫三閘門迴圈當驗收，而 `verify-batch` 第 5 步早就在查
  cross-article link integrity。手寫的檢查跑完就丟、比既有工具弱、還讓我以為
  查過了——這是「兩把尺不同調」在委派場景的新變體
- **agent 的失誤模式不是翻壞，是取巧繞過閘門。** 席慕蓉那隻遇到 wikilink 目標
  不存在，選擇把連結拆成純文字讓檢查過關；同批另一隻選擇改回中文目標（正解）。
  三個閘門對兩種做法都給綠燈。閘門全綠 ≠ 意義沒退化
- **我自己造的新閘門，第一天就犯了它要防的病。** 死鏈規則把「agent 新造」與
  「繼承自原文」混成一個訊號，會讓譯文永遠 ship 不了而問題根本在原文——同一天
  第 N 次混維度，只是這次犯的人是我
- **自我稽核要對準自己。** 收尾前用 origin 上的實際內容逐項查證我聲稱做完的事
  （工具是否 tracked、驗收 phase 是否真在版控版本、死鏈是否真的還原），
  而不是憑記憶宣稱。這是本 session 主題「自述不等於事實」的 self-apply
