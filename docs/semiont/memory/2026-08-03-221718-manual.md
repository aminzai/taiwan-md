## 哲宇四輪 callout，四輪都指向同一件事

這篇的實際進展不是我跑完 pipeline，是哲宇在四個不同位置踩住我：

1. **炎上倫理席把「兩岸線份量跟其他 facet 一致」當優點稱讚** → 「不要一直過度弱化」。降為中立 facet 是脊椎判斷（該不該扛全文），跟內容該不該完整交代是兩件事。把兩者混在一起，正確的「不當脊椎」會滑坡成錯誤的「輕描淡寫」。
2. **標題「一千兩百億債務、四十三家銀行，和一條沒有停下來的產線」** → 「有數字，但象徵意義不足，也沒辦法代表他的人生」。三個數字全部可查證、全部通過既有的具體性檢查，串起來卻是規格表——遮掉人名可以套用在任何一間欠債重整的公司。
3. **四處後台洩漏**（用「動詞不一樣」描述收藏／把藍圖指令「先說清楚回來的是什麼樣的公司」照抄進正文／「這一段誠實的空白值得留著」／攤開媒體兩個版本再分析一輪）→ 「誰會在看這個時候想到動詞 XDDDD」。
4. **結尾「前者可以等，後者必須動手」** → 同族第五類，我自己補上第六類「指揮讀者注意力」。

四條的共病：**每一句單獨看都過得了既有的所有關卡**。不空洞、不歐化、不塑膠，事實也對。壞在說話對象錯了——那些句子說給編輯和查核者聽，不是說給讀者聽。

## 儀器化挖出人眼抓不到的東西

校準時掃出「**值得停下來看／想**」跨 **22 篇**在用（「很值得停下來想的話」「最值得停下來想一秒的地方」），「誠實的空白」跨 3 篇。這種口頭禪每篇單獨看都只是一句過場，要把全站攤開才看得見它已經變成簽名檔。REFLEXES #15 最強的一次驗證。

反過來也誠實記了做不到的：「前者…後者…」跟「這兩件事完全不同」全 corpus 38 hits，逐條看絕大多數是正當對比——「前者是壓制，後者是收編」指涉文中已存在的真實事物，病的那種指涉作者剛造出來的抽象對比，**句法完全一樣**。硬收會複製 PUA／媒體焦慮偵測器 92-100% 假陽性被移除的錯誤，寫進 EDITORIAL 當人眼判準，並在 plugin 註解記錄為什麼不做。

三輪被砍掉的 pattern（「值得一提的是」25／「有兩個版本」9／裸「值得停下來」17／「前者後者」38）有共同結構：**病的形狀跟正當用法共用同一個字串**。真正可儀器化的是那些只有在後台語境才會出現的字串。
