早上那個 session 已經把海關報關與 EZ WAY 的文章跟孢子 blueprint 都寫完了，孢子卡在 prod 還沒上線。這次接手要發。發之前哲宇補了一句：這個主題正在被網路操作勢力惡意炒作與污名化、刻意做成爭議話題，要我想怎麼寫才能幫助大家立體地認識、成熟地理解。整則孢子因此從 v5 重排到 v12。

## 同一組事實，換個排序就是兩則不同的貼文

v5 逐字無誤，過了所有閘門。但它把「四千多讚」「原來我買 iHerb 要跟一家私人公司報關」這兩個情緒放大器放在第三段，而文章花整節查證推翻的兩個說法（政府欽點獨家、個資已外洩）只用一句平衡句帶過、擺在最後一段。孢子是 300 字的高密度載體，**哪個事實放在讀者最先讀到的位置，就是這則孢子實際在做的事**。在一個正被操作的爭議裡，那個排序讓它容易被當成立場素材轉發。

v12 做四件事。第一，把兩個已被推翻的框架提到第二段正面回答（「它不是政府欽點的，當年另一家有資格的公司評估後沒接」＋「也沒查到過外洩紀錄」）。第二，補進 v5 沒有的替代路徑（自然人憑證與紙本），這是對「你被強迫」這個憤怒點最有用的事實，歸屬寫成「官方說」而非我方保證，因為文章明載新制後官方沒再發同等級操作說明。第三，拿掉煽動素材。第四，保留真正的問責，八年沒編過預算跟十月底那份要交差的報告都留著。降溫不等於噤聲。

判準寫進 blueprint 了：**這則孢子被截圖轉發時，替讀者省下的是查證的力氣，還是憤怒的力氣？**

哲宇第二輪 callout「結尾寫得不夠好，不知道要表達什麼」。原收尾寫「這件事正在被好好地問，不是被嚇著問」——那是在評論討論的方式，是口號不是畫面，讀者帶不走東西。改成回扣開場那個手勢，並把十月底的報告從中段移到收尾當實錨：讀者帶走一個具體日期跟一個具體問題。

## 三平台 ship 與 FB 通道開通

三平台在 commit `b5c14e015` 一次落地：[X](https://x.com/taiwandotmd/status/2084520918441951650)、[Threads](https://www.threads.com/@taiwandotmd/post/Dbm5PdXE181)、[FB 粉專](https://www.facebook.com/61576525376323/posts/pfbid0BG8mE9DJ9JBrryDXSSnXDDLJZUVZmycvsMAzea6MuVcK2gMhUCtF9Bx9x9iXtHNAl)。FB 是哲宇當場登入好粉專並要求同步發、成功就納入未來流程的新通道。發的過程撞到三件事。剪貼簿在 Threads 那一步被別的內容取代，貼出來是一個 Facebook 個人檔案網址而不是圖——pipeline v0.7 早寫過 clipboard 跨 turn 不穩定，這次是實例。修法是每次 Cmd+V 前重寫剪貼簿並用 `clipboard info` 驗型別（PNG 599KB vs utf8 880 bytes 一眼可辨），這比事後看畫面早一步。

另外兩件是 pipeline 自己的尺量錯層。SOCIAL-POSTING 的 pre-ship check 7 用 ProseMirror 的 `:scope > div` 數段落，但 X 是 DraftJS（段落在 `[data-block="true"]`）、Threads 是 Lexical（單一 `<p>` 內用 `<br><br>` 分隔）。兩邊都回報 block_count=1，照 pipeline 字面就該判定 collapse 並 abort 重貼。實際逐塊讀出來是 6 塊與 5 段、字數 7/97/90/59/57 跟 blueprint 逐段吻合。**選擇器寫死一種編輯器，換平台就變成假陽性**，跟 7/24 那批假陽性家族同型。

## 第三個平台開通時，兩個下游器官沒跟上

`spore-db.py` 的 PLATFORMS 白名單四個平台早就有 facebook，收得下。但 `sync-spore-links.py:170` 寫死 `("threads", "x")`，#169 被靜默丟掉：資料庫有、spore-log 有、文章 frontmatter 沒有、讀者看不到。`SporeFootprint.astro` 的顯示名也只映射兩個，第三平台會渲染成小寫原字串。兩處都在 `e4b911e95` 改成具名常數補齊四個平台，註解寫清楚改動時要同步查另一頭。

還有一個沒改的：spore-db 的 URL 乾淨化閘擋掉所有帶 query string 的網址，但 FB permalink 的 `story_fbid` 是身分不是追蹤參數。這次繞過的方式是改用 FB 的 `/{page_id}/posts/{pfbid}` 無 query 正規形式，並實際 navigate 驗證它解析到同一則才登錄。閘門本身仍把「追蹤參數」跟「身分參數」混為一談。

## Beat 5 — 反芻

這次最該記住的是**閘門全過不等於這則貼文在做對的事**。v5 過了 spore-writing、prose-health、事實查核表、紀實煽情閘全部五層，逐字無誤。真正的問題在資訊排序，而排序這件事沒有任何一把尺在量——它是策展判斷，只有在有人告訴我「外面正在發生什麼」的時候才浮得出來。這跟 8/3 黃崇仁那次「十一個關卡全綠、四十個事實原子零漂移，哲宇讀完指出六個地方，沒有一個是事實錯誤」是同一件事的第二次。

第二層是**尺量錯層會兩個方向都出錯**。同一天裡，pipeline 的段落閘門對我報假陽性（兩個平台都說 collapse，實際完整），而 sync-spore-links 的平台白名單對我報假陰性（靜默丟掉一整筆，什麼都沒說）。前者我因為停下來看 DOM 才沒誤判，後者我因為順手驗了 frontmatter 才發現，兩次都不是儀器自己叫的。教訓候選寫進 [LESSONS-INBOX](../LESSONS-INBOX.md)，明細見 footer。
