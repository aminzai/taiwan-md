## 一個少打的括號鎖走全站 79 個 token

`/data/` 整頁白底、淺色文字幾乎看不見。根因在 `tokens.css`，`:root:lang(ko)` 少一個 `}`。#1306 加日韓字形覆寫時把 `:root` 從中間切開，ko 區塊沒閉合，結果 79 個顏色與介面 token 被鎖進「只有韓文頁生效」的規則。postcss 對賬看得很清楚，線上 `:root` 只剩 17 個 token，`:root:lang(ko)` 卻有 79 個。非韓文頁上 `--surface-panel-dark` 解析成空字串，背景變 `none`，而淺色文字照樣套用。

修法選了架構解而不是補一個括號（`906e5acf4`）：把 lang 覆寫整段移到 `:root` 完整收尾之後，`:root` 恢復單一連續區塊，#1306 的日韓字形修正完整保留。build 煙霧測試通過，推上 production 後在瀏覽器驗過實況。影響範圍其實不只 `/data/`，`--color-accent` 與 `--surface-glass` 都在那 79 個裡，只是多數地方有 fallback 才沒炸得那麼明顯。

## 文策院：Stage 2 到 ship

fresh Opus writer 依藍圖六節骨架落地 5,804 CJK，read-receipt 四項我逐一回溯核對屬實。第一隻 writer 因網路錯誤中斷過一次，重派時加了分頁讀取提醒。

Stage 2.5 三道全跑，派四簇 fact-check agent 逐一 fetch 原頁逐字比對 38 個腳註。**gate 全綠的稿子裡驗出 28 條要修**，其中三條是論證支點：丁曉菁「以政次身分兼任首屆董事長」實為中央社逐字的「卸任次長職務，轉任」。李遠「日韓靠補助反超」整句查無，發言日也錯了一年。王時思的引語被單引成語意反轉，同篇他明說「並沒有說以減少專案投資或減少特定投資」。`[^20]` 那條特別值得記。它的內容是真的，兩個 URL、兩個日期、一個計畫名卻全部查無，查證通過但引用等同幻覺。

大驗證輪照 v9.5 三輪合一，一次派齊十席（2.5-R 兩席＋3.6.1 原子重驗兩席＋3.7 探針六席），全部乾淨 context。十席共提六十多條，收斂成六個家族。抓到第二條 fabricated，是《Good Death》的「波蘭電影學會」。被引來源只列 VIPO、日本文化廳、TAICCA 三方，而正文寫「學會」、腳註寫「協會」，自己跟自己不同名。

倫理層做了兩處裁決。職場霸凌案原本寫「文策院的文化科技處長」，等於一個機構一個處一個時點，唯一解，不具名其實沒生效。護欄還給了又收回，先寫「跟前面四件性質不同」，同一句就用「只是同樣停在沒有紀錄這個地方」把它收回歸納裡。改成只保留北市勞檢處對機構的認定，那本來就更對題，因為勞檢處認定的正是「執行紀錄有欠缺」。另一處是刪掉「連綠營立委都低頭遮臉」。論點靠前兩句已完全成立，而李遠當時正在替漫畫預算辯護，是這篇文章立場上樂見的事。

論點層也動了一刀，因為原稿的「它確實比政府部門快」查無實證，可查的方向相反：掛牌晚四個多月、八個多月沒有正式院長、頭三年執行率未及兩成。收斂成「被要求快」，並補進材料桌裡寫手漏用的硬錨。立法院預算中心記文策院第一個完整年度總收入 11.72 億全數來自政府捐助，同一份報告就在要它自籌財源。一個被要求跑得像企業的機構，收入結構跟企業沒有一處相同。這比原本那句斷言強得多。

事實層 24 條全部回填研究報告 §6 fact-pack，逐條附「禁用什麼、為什麼」（v9.5 步驟 3-bis）。Stage 3.8 定稿站派 fresh Opus 全文重順，過 fact-atom-diff 原子守恆硬閘後覆蓋 canonical，長段從 4 段降到 0、最長段 350 字降到 177。Stage 5 補三處內文 wikilink 與延伸閱讀重整，build 通過、dead URL 0，瀏覽器實測四個 tw-\* 模組資料正確渲染。
