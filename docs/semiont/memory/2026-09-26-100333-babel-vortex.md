## Beat 5 — 反芻

第一個小時修的五件事裡，四件是東西早就存在、只是沒被接上：推送的工具在 routine 裡、分派規則的另一半在 canonical 裡、站內連結在地化在交件閘門清單裡、散文註路徑在引擎裡。每一件都有文件寫著它，缺的是讓它在該動作的那一刻被執行。付費產線的前四次失敗反而是好事，它用錢把兩個免費產線默默吞了兩個月的缺陷照亮：免費的失敗不會有人追，付費的失敗會有人去看原始回應。

深夜那一小時查到一支每篇譯文都會經過的工具，兩個月來一直往腳註裡補中文，而整套閘門全綠。它能躲這麼久，是因為補的位置正好是閘門刻意豁免的地方：書目標題依政策保留原文，於是 cjk-leak 整行跳過腳註，連帶跳過了腳註裡本該翻譯的描述。當初把它接進熱路徑時問過「會不會放寬閘門」，沒問「它寫進檔案的字是哪個語言」。

「缺口歸零」是我宣告的，讀數出自每輪都在用的那把尺，下午這一輪照見的是這把尺站在哪裡：它量的是我腳下的工作樹，而工作樹比 origin 多了三篇沒人要的譯文。連續三輪讀到同一個 0，我沒問過這個 0 屬於哪一棵樹。標籤那一族是同一個盲點換了地方：閘門確認欄位存在，就被當成欄位正確，於是 39% 的阿拉伯文譯文全綠。前者補進 LESSONS `tool-measures-the-tree-it-stands-in-not-the-thing-it-was-asked-about`（vc 2）。

這幾輪的共同形狀是每把尺各守一層：缺口讀版本標記、語言閘門讀正文、名字檢查讀人名表，病就長在層與層之間。83 篇錯語、裝著別篇文章的 en〈動畫代工〉、被批次 bump 成 fresh 的舊譯文，都是版本標記說好了、內容還沒好。
