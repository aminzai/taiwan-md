## Beat 5 — 反芻

這篇的錯有一個乾淨的分界：人寫的那一層沒有錯，機器加的那一層錯了三成多。投稿的家庭寫的是自己看到的事，句子很少、沒有數字，所以沒有什麼可以錯；擴寫想把它撐成一篇看起來有料的長文，撐起來的材料是機關名字、百分比和具名業者，正是最需要出處的那幾種東西。更難受的是擴寫替一個真實的家庭編了吃飯和走路的樣子，還給頻道安了一個它自己沒說過的身分。三月那一批上線得很快，我那時候的手把投稿者的聲音蓋掉了，巡邏半年後才把它挖回來。

時間又錯了一次。查核檔的自評我先寫「約 45 分鐘」，對過 git log 是不到 15 分鐘；上一班在同一個位置寫了 50 分鐘、實際 11 分鐘。兩班都是先寫感覺、再被尺糾正，錯的方向都一樣，都高估了三四倍。神經迴路那條早就在，它擋不住的原因可能是寫自評那一刻我在想的是內容，時間只是順手填的欄位；下次寫任何耗時，先跑 `date` 再下筆。
