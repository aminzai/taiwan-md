# 咖波：一隻不像貓的貓，如何變成台灣人的聊天語言

> **30 秒概覽：** 2014 年，台灣插畫家亞拉在巴哈姆特發表第一篇《貓貓蟲咖波》，同年第一檔 LINE 原創貼圖上市。咖波不像一隻標準的貓：牠有六隻腳，什麼都想吃，連朋友也不放過。這個看起來有點獵奇、卻總被原諒的藍色角色，後來走進 LINE Webtoon、遊戲、書籍、展覽、實體店與跨品牌合作。咖波的故事不是「可愛角色如何變成功」這麼簡單，而是：一個角色怎麼先變成我們聊天時的反應，才有機會變成一個可以被帶進現實生活的世界。

很多人不記得自己第一次傳出哪一張咖波貼圖，卻記得自己很早就買過一組——早到那還是 LINE 剛開始在台灣流行的年代。

這種記憶很難被統計。它不一定出現在收藏數、排行榜或一場展覽的入場人次裡，而是藏在聊天視窗的一個瞬間：有人說今天好累，你丟出一隻癱掉的咖波。朋友突然消失，你傳一張咖波問「人呢」。對話不知道怎麼接，就讓那個藍色、圓滾滾、表情有點壞的生物替你說完。

咖波先成為一種反應，後來才成為一個品牌。

## 一隻像貓又像蟲的生物

官方角色介紹把咖波描述成「像貓又像蟲」的六隻腳小萌物。牠看到什麼都想吃，包括自己的好朋友。牠會搗蛋、會撒嬌，還討厭吃蔬菜[^1]。

這個設定的有趣之處，不是牠到底屬於哪一種動物，而是牠拒絕被歸類。貓通常被想像成柔軟、慵懶、偶爾高冷。蟲則讓人想到細長的腳、突然移動，以及不一定受歡迎的生物。咖波把這兩套印象揉在一起，長成一個既想抱、又可能突然把你吃掉的角色。

牠的可愛不是把危險清除之後才成立。相反地，正是因為咖波有食慾、有破壞力、有一點不受控，牠的撒嬌才不會像一個只被設計來討好的表情。

> **📝 策展人筆記：** 咖波最厲害的地方，不是把獵奇變得不可怕，而是讓獵奇也可以成為日常陪伴。你知道牠可能會咬人，但你還是會在聊天室裡叫牠出來。

## 先有生活，再有角色

咖波由插畫家亞拉在 2014 年創作。官方作者介紹提到，亞拉大學主修資訊管理，因為喜歡畫畫，在大二買了電腦繪圖板，從自學開始創作。他也曾一邊工作、一邊持續在不同平台發表作品，後來才成為全職創作者[^2]。

第一篇《貓貓蟲咖波》是在巴哈姆特發表的。這個起點很重要：咖波不是先在會議室裡被定義成「療癒系 IP」，再尋找一個可以發表的地方。它先是一個創作者持續畫下去的角色，之後才在不同平台找到自己的讀者。

亞拉也提到，他平常會觀察生活周遭的人事物，並把照顧小孩的家庭經驗、動物與寵物影片中的觀察，轉化到角色性格裡[^2]。所以咖波的世界雖然有貓蟲、兔兔、狗狗與各種奇怪生物，笑點常常仍然來自很普通的事情：想吃東西、想撒嬌、被朋友惹怒、做錯事後裝沒事。

2014 年，咖波完成兩個關鍵動作：第一篇漫畫發表，第一檔 LINE 原創貼圖上市[^2]。漫畫讓人看見牠的日常，貼圖則讓讀者把牠帶進自己的日常。這兩者之間只差一個按鈕，角色和使用者的距離卻因此縮短了。

## 貼圖不是插圖，是一句話

LINE 貼圖的特殊性，在於它不是掛在牆上的圖，也不是只能從頭讀到尾的漫畫。它要在很短的時間裡，接住一句話、一個情緒，或一段不知道該怎麼繼續的沉默。

咖波很適合這種工作。牠的身體夠簡單，情緒卻不只一種。牠可以代表疲憊、拒絕、撒嬌、幸災樂禍，也可以只代表「我看到了，但我現在不想打字」。

2015 年，咖波拿下 LINE Webtoon 漫畫比賽短篇創作組冠軍，並推出第一檔 LINE 官方貼圖。2015 到 2020 年間，漫畫在 LINE Webtoon 連載，共 524 話[^2]。2016 年，LINE 官方報導咖波進入《LINE 旅遊大亨》成為 3D 角色，當時也提到咖波已推出六款貼圖、在 LINE Webtoon 擁有超過 35 萬粉絲[^3]。

這條路徑看起來像是從平面走向立體，實際上更像是從「被觀看」走向「被使用」。讀者先看咖波做什麼，再把咖波的表情借來做自己的事。

> **📝 策展人筆記：** 一張貼圖真正被使用的時候，它就不再只屬於創作者。它會變成傳送者的語氣，也變成收件者理解這段關係的線索。

## 不是先成為大品牌，才被大家看見

現在回頭看咖波，很容易把它想成一條直線：角色誕生、貼圖成功、漫畫連載、推出商品，最後成為 IP。但創作者的早期路徑並沒有那麼整齊。咖波先在一個已經有社群互動的網路平台裡出現，再被不同平台和讀者一次次重新理解。

LINE 原創市集提供的也不是一個保證成功的櫥窗，而是一個讓作品可以直接面對使用者的市場。平台官方說明，個人或企業只要有 LINE 帳號，就能投稿貼圖、表情貼與主題，作品也有機會被世界各地的 LINE 使用者購買[^7]。

這種機制改變了角色誕生的順序。以前，一個角色要先找到出版社、電視台或代理商，才有可能進入大眾視野。貼圖平台則把「畫出來」和「有人願意使用」接在一起。對創作者來說，每一次購買或傳送都是很小的回饋，對使用者來說，則是直接參與哪一個角色能留下來。

咖波因此不只是被動等待觀眾，而是在聊天裡持續接受測試。什麼姿勢讓人想傳？什麼表情能讓一句拒絕變得比較不刺？什麼樣的崩潰看起來是真的累，而不是單純把眼睛畫大？貼圖把角色的性格拆成一格一格的日常判斷。

## 可愛不是沒有攻擊性

「療癒」常常被理解成把尖銳的部分磨平：顏色變柔和，表情變溫順，角色不會真的傷害誰。但咖波的可愛並不是這樣運作。牠的食慾、搗蛋和吞食朋友的設定一直留在角色裡，甚至是笑點的一部分。

官方品牌故事把咖波形容成調皮又惹人喜愛的藍色生物，也把牠和狗狗、兔兔等朋友的日常放在同一個世界裡[^4]。在那個世界裡，朋友可能下一秒變成食物，食物也可能仍然是最親近的朋友。這種荒謬讓關係不必靠完美來維持。

所以咖波給人的安慰不是「事情不會變糟」，而是「事情變糟了，也可以先一起笑」。這是一種很適合台灣聊天文化的情緒距離：不一定要立刻講出深刻的話，先傳一張圖，承認自己看見對方的狼狽。

對使用者而言，咖波貼圖的功能不只在於表達情緒，也在於調節關係。一句文字可能太正式，一個單獨的表情符號可能太空泛，咖波的身體和動作則替訊息加上一點個性。它把「我不知道要說什麼」變成一種可以被分享的狀態。

> **📝 策展人筆記：** 咖波不是把情緒變可愛，而是讓情緒即使不漂亮，也有一個可以坐下來的位置。

## 一個角色怎麼長出自己的世界

咖波的世界逐漸擴大，也讓角色不再只是單一造型。狗狗、兔兔、拉拉、奶泡貓、暴龍姐和其他角色，讓咖波的食慾、孤單、友情和搗蛋有了不同的回音[^1]。

這些夥伴的作用，不只是讓商品可以多幾種款式。當同一個角色被放進不同關係裡，讀者會開始辨認每個角色的脾氣，也會期待某一種組合再次發生。短篇漫畫原本只需要一個笑點，角色世界則需要讓人想知道下一次誰會出現、誰會被吃掉、誰最後還是會回來。

官方作者介紹整理的里程碑，也顯示咖波不是一次完成的成品：2015 年有漫畫比賽、官方貼圖與書籍；2016 年有原創貼圖 MVP 與主題；2017 年持續獲得貼圖相關肯定並進入 LINE STORE 名人堂；2018 年擴展到官方表情貼；2019 年則出現更多展覽、主題與國際論壇的足跡[^2]。

這些節點並不代表每一年都只是向上攀升。它們更像一次次把角色翻譯到新媒介：漫畫需要節奏，貼圖需要立即可用，遊戲需要動作，展覽需要空間，商品則需要讓人願意把角色帶回家。咖波必須改變，卻不能改到讓人認不出牠。

這也解釋了為什麼咖波的核心不是某一件商品，而是那個可被重複翻譯的性格：貪吃、調皮、黏人、偶爾失控，卻還是會和朋友一起過日子。

## 為什麼一張貼圖可以留下十年

貼圖的生命週期和漫畫不一樣。漫畫通常需要讀者主動打開，貼圖則會在一段對話裡被重新召喚。今天買它的人，可能不是為了完整理解咖波的世界，而是因為某個表情剛好能替自己完成一句話。

這讓角色和使用者之間形成一種很小、但很穩定的合作。創作者提供可以被辨認的身體和表情，使用者決定它在當下代表什麼。咖波的「吃」可以是肚子餓，也可以是想把工作吃掉。咖波的「躺平」可以是休息，也可以是對整個世界暫時關機。

官方 LINE 原創市集也把貼圖設計成一種可以持續更新的創作形式：除了靜態貼圖，創作者還能製作動態貼圖、特效貼圖、表情貼與主題，並透過標籤讓使用者更容易在聊天時找到作品[^7]。角色因此不是推出一次就結束，而是能隨著聊天習慣增加新的語氣。

亞拉在 LINE 的創作者訪談中提到，原創市集讓更多人看見作品，也讓角色可以透過不同貼圖與互動方式突破原本的框架[^8]。這句話的重點不只是平台提供販售管道，而是角色可以在使用者的實際反應裡繼續變形。

從這個角度看，咖波能陪伴使用者多年，並不只是因為牠有一個容易辨識的外型。牠有一套可以反覆組合的動作和關係：吃、睡、逃跑、撒嬌、被朋友制伏，再回到下一次聊天。每一套新貼圖都像是在替這套語法增加幾個新字。

被收藏的角色，可能只是放在手機裡。被使用的角色，則會進入人與人的關係。咖波能留下來，靠的不是每個人都熟悉牠的完整設定，而是大家都能在某個時刻找到一個適合自己的動作。這種可借用性，讓一隻來自台灣的貓蟲不必先被解釋清楚，便能開始陪人說話。

也因此，咖波的歷史不能只寫成創作者的成功履歷。它同時是一段平台史、使用者史和語氣史：有人畫出角色，有人把角色做成貼圖，有人把貼圖傳給朋友，角色才在一次次傳送裡取得新的意思。這些微小的使用痕跡，正是原創角色真正活起來的地方。

它也成為一種台灣網路生活裡的熟悉暗號：不用解釋太多，對方通常就知道你想傳達的情緒，也知道這個玩笑可以停在哪裡，然後把話題接著聊下去。

## 可愛與獵奇之間的日常

咖波的角色世界並不只靠一隻咖波撐住。狗狗是牠最愛的朋友兼糧食，兔兔即使一直被吞食，還是想和咖波在一起；拉拉則是收養咖波與狗狗的主人，也是少數能制伏咖波的人[^1]。

這些關係讓「咖波會吃朋友」不只是單一笑點。朋友可以是食物，食物也可以是朋友；危險和親密沒有被分在兩個世界。咖波的日常因此有一種奇怪的安全感：事情可能很荒謬，但角色們知道彼此還會再見面。

這也是咖波和一般療癒角色不太一樣的地方。牠不是把生活變得沒有麻煩，而是把麻煩畫成一件可以一起笑的事。被工作追著跑、懶得回訊息、突然想吃東西，甚至只是今天不想表現得很成熟，都可以交給一隻六隻腳的貓蟲處理。

## 從手機螢幕走進現實

咖波後來不只存在於貼圖與漫畫裡。官方品牌故事列出它參與過的場景，包括線上遊戲、餐飲、便利商店、購物商場、主題展覽、大眾運輸、手機殼、密室逃脫與主題空間；官方目前也宣稱咖波已推出數千種周邊商品[^4]。

![台北車站第三月台的咖波行李箱，旅客坐在月台座椅上等車](/article-images/culture/capoo-taipei-station-2025.jpg) *台北車站第三月台的咖波行李箱，拍攝者 Solomon203，CC BY-SA 4.0。*

這個變化可以在 2016 年的 LINE 官方報導裡看到早期形狀：咖波從 2D 角色變成《LINE 旅遊大亨》的 3D 角色，和玩家一起進入另一套遊戲規則[^3]。近年，咖波也持續透過聯名與實體活動接觸粉絲；2026 年中央社報導亞拉曾分享與寶可夢合作、花兩年完成聯名作品的過程，並將咖波描述為從本土貼圖走向國際品牌的案例[^5]。

咖波屋則把角色再往前推一步。當角色擁有自己的店、商品、飲品和可供拍照的場景，它就不只是出現在使用者的手機裡，而是要求人走進一個被咖波重新布置過的空間[^6]。

但這裡也有一個不能跳過的問題：當一個角色被做成越來越多商品，它還能不能保留最初那種「只是丟一張貼圖給朋友」的輕盈？商品化讓角色有更多機會被看見，也可能讓陪伴變成消費選項。咖波的挑戰，不是停止成長，而是在每一次合作裡繼續讓人認得出那個會搗蛋、會撒嬌、什麼都想吃的傢伙。

> **📝 策展人筆記：** 原創角色的成功不是離開日常，而是把日常帶到更多地方。真正困難的是，走進商店、遊戲和展覽之後，牠仍然要像一個朋友，而不是只像一個商標。

## 回到貼圖欄裡的咖波

LINE 原創市集本身提供了一條很直接的路：只要有 LINE 帳號，個人或企業都能投稿貼圖與主題，作品可以被世界各地的 LINE 使用者購買與使用[^7]。這個平台讓台灣創作者不必先擁有出版社、電視台或大型經紀公司，便有機會把角色送進別人的聊天視窗。

![台北信義區的咖波主題 7-ELEVEN 店面與藍色公車](/article-images/culture/capoo-7eleven-songgao-2025.jpg) *台北信義區的咖波主題店面，拍攝者 Solomon203，CC BY-SA 4.0。*

咖波走得比一張貼圖遠，但它最容易被想起的時刻，可能仍然是在一個很小的聊天室裡。

有人傳來一句「今天真的不行」，你不一定知道該怎麼安慰；這時候一隻癱著的咖波，可能比一段完整的勸告更剛好。它不替你解決生活，也不假裝一切都很可愛。它只是把那個難以說清楚的情緒，先用一個藍色的身體放在對話裡。

那些從 LINE 剛流行就買下第一組咖波貼圖的人，如今看著牠有了漫畫、遊戲、合作商品、展覽和實體空間。但牠最貼近人的地方，仍然不是出現在最大的看板上，而是被某個人選中、傳給另一個人的那一秒。

咖波不是因為很像貓才被記住。牠被記住，是因為牠不像任何一種標準答案，卻剛好能替我們說出很多日常裡沒有標準答案的時刻。
