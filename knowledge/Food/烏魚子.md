冬至前後 ，雲林口湖的加工者會在烏魚仍留在魚塭時先放血。烏魚通常在十一月中下旬至翌年一月下旬游近台灣沿海，主要漁期落在冬至前後約十天。西部沿海漁民因此稱牠為「信魚」：到了時節，牠理當現身。[^1]

> **30 秒概覽：** 烏魚子是成熟雌烏魚的一對卵巢，經去血、鹽漬、壓製與乾燥後留下油脂、鹹香與嚼感。野生魚汛曾讓它成為年節的時間記號；今天，口湖等地兩三年的養殖週期、加工冷鏈，以及野生漁場北移的現實，讓「好烏魚子」成為海況與人手共同完成的結果。[^1] [^3] [^4]

## 冬至前後，海上來了一封信

烏魚的正式中文學名是鯔魚，民間慣稱烏魚。國家文化記憶庫引《臺灣府志》記載，冬至前捕到的「正頭烏」較肥美，冬至後的「回頭烏」較瘦。這條魚早已把海上的時間表帶進沿海人的餐桌與生計。[^2]

荷治以前已有捕烏紀錄，荷治時期的來台捕烏船隻還須納烏魚稅。烏魚子不是後來才被包裝成禮盒的名產，而是把短暫魚汛延長到年節的一種保存方法。[^2]

> 📝 **策展人筆記：** 「信魚」不只是浪漫稱呼。魚汛大致可預期，漁民才有辦法把船、風與一家人的年關排進同一份日曆。

## 鹽把洄游留在岸上

農業部資料將製程拆成成熟母魚、剖取卵巢、水洗、擠血、鹽漬、脫鹽、整形與乾燥。血液未清除會氧化變黑；鹽太多會使卵巢過硬；乾燥不均則影響色澤與口感。[^3]

| 工序           | 處理的關鍵                   | 成品留下的結果           |
| -------------- | ---------------------------- | ------------------------ |
| 去血與清洗     | 清除微血管中的血液與表面雜質 | 降低氧化變黑與雜味       |
| 鹽漬與脫鹽     | 控制鹽分滲入與洗去殘鹽       | 平衡鹹度與質地           |
| 壓製與整形     | 讓兩片卵囊均勻受力           | 形成平整、厚薄相近的外觀 |
| 日曬或冷風乾燥 | 移除水分並持續熟成           | 留下油脂香與富彈性的嚼感 |

鹽量約為卵巢重量的百分之十至十五，鹽漬約四至五小時。傳統日曬與陰乾約三至五日。這些數字是判斷的起點，不是機械配方，因為成熟度、卵巢大小與天候都會改變手上的尺度。[^3]

台南安南的蔡登進談起早年鹹膎時說：「一片蚵仔給就配一碗糜。」烏魚子後來更靠近宴席與送禮，底層邏輯卻相同：用鹽把易腐海產交給更長的時間。[^5]

## 口湖的魚塭，先養兩三年才等一個冬天

莊國顯、莊國勝兄弟的加工現場，讓烏魚子的技術變得具體：烏魚在池中先放血，再低溫運送。取出的魚卵得刮除血液與黏膜，才進入鹽、壓力與乾燥的流程。[^5]

他們以日曬後加冷風乾燥、降低鹽度等方式調整工法。個案不能代表所有業者，但足以看見一片烏魚子的差異，來自魚塭、運送、取卵、鹽分與乾燥環境的一整條鏈。[^5] [^6]

口湖研究指出，養殖烏魚的生命週期通常為兩至三年，魚苗挑選、魚塭環境、加工、評比與行銷彼此相扣。野生或養殖不是兩張互斥的成績單。前者提示魚汛的稀有，後者提醒人們，穩定風味也必須被耐心養成。[^4]

## 一尾烏魚，不只剩下一片烏魚子

農業部將烏魚子、烏魚膘與烏魚胗列為「烏魚三寶」：烏魚子來自雌魚的一對卵巢；烏魚膘或烏魚白是雄魚精巢；烏魚胗亦稱烏魚腱、烏魚肫，指的是胃囊。魚體能煮成米粉湯或入菜，讓烏魚子成為全魚利用中的一個高峰，而非唯一價值。[^7]

一九○九年，日本人延聘長崎的烏魚子製造專家來台，並在高雄與鹿港設立加工廠。這是現代加工產業被系統化的一段歷程。更早以前，沿海社會已經在捕烏與保存海產中累積了自己的時間感。[^8]

在高雄旗后流傳的「烏魚拜媽祖」傳說裡，漁民與烏魚約定冬至後第十五天停止捕撈，漁季結束後舉行海祭。它不是精確的歷史紀錄，而是地方記憶：人們把對魚汛的依賴與對過度捕撈的焦慮，放進一段能被反覆講述的海口故事。[^8]

## 漁場北移，讓「信魚」變得難等

水產試驗所整理一九六六至二○一九年資料發現，野生烏魚主要漁獲位置逐年北移。二○一八與二○一九年，台中以北已占全台漁獲量九成五以上。雲嘉以南的傳統漁場，因而更難等到來游魚群。[^1]

研究沒有把變化簡化成單一氣候敘事。資源量、海況、海氣象、長期氣候變遷與漁撈壓力都可能影響魚群的棲息、洄游與集散，現階段仍難完全預測漁場的後續變動。[^1]

> **數字看烏魚：** 二○一九年台灣烏魚總產量為三千五百九十七公噸，產值約五點一三億元；野生沿近海捕撈產值約占五成九，陸上養殖約占四成一。這是該年度的產業切面，不是今日市場或未來漁況的預報。[^1]

## 產地與加工地，是兩種不同的座標

烏魚子的風味仰賴加工，但「在哪裡加工」與「烏魚卵從哪裡來」並不是同一件事。關務署對涉及多國材料或加工的貨物，原則上以最終實質轉型所在地認定原產地；這是貿易管理的判準。[^9]

因此，面對「台灣烏魚子」，值得再問一層：包裝說的是加工地、主要原料來源，還是兩者都交代？《上下游》以烏魚卵為例討論兩者可能出現的資訊落差。這是制度與知情權的議題，不等同於對任一產品提出違法判定。它提醒消費者可以詢問原料產地、野生或養殖、加工地與保存條件。[^10]

## 切成薄片以前，冷鏈仍在接手

農業部資料指出，烏魚子宜冷凍或冷藏保存。存放超過四個月，脂肪氧化可能使色澤轉為暗紅。切開後若不立即食用，仍應密封並維持低溫。[^3]

| 看什麼     | 可以讀到什麼                                                                   |
| ---------- | ------------------------------------------------------------------------------ |
| 外觀與觸感 | 兩片腎形卵囊、厚薄相近、帶透明感、卵粒均勻；輕壓不留指痕，通常表示乾燥度適中。 |
| 原料資訊   | 魚卵的產地、野生或養殖，以及加工地，是不同但都重要的資訊。                     |
| 上桌方式   | 炙燒後可配蒜苗、水梨或蘋果；也能進入炒飯與義大利麵。[^5] [^12]                 |

美食研究者徐仲說：「極致是沒有終點的，要一直想辦法去找出它有趣的觀察點。」野生與養殖、日曬與冷風、蒜苗與水果，不必被壓成唯一正統。它們是理解同一份海味的不同入口。[^5]

烏魚子不是只有野生才算珍貴的金黃，也不只是昂貴伴手禮。它把海上的遷徙、魚塭裡的等待與手上反覆翻面的工序，壓成一段可以切開的時間。魚未必照著舊日曆抵達，但人仍用鹽、風與手勢，嘗試把一次來游留在舌頭上。
