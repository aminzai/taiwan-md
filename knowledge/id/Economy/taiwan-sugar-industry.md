> **Ringkasan 30 Detik:** Tahun 1901, pabrik gula modern pertama di Qiaotou mulai dibangun di Kaohsiung. Tahun 1907, pabrik gula memasang rel kereta api berlebar 762 milimeter ke ladang tebu, yang kemudian disebut kereta api kecil (五分車). Awalnya untuk mengangkut tebu ke mesin peras, tapi perlahan ia mengangkut pekerja, pelajar, jamaah, dan warga pedesaan, menjadi sistem transportasi lokal yang lebih besar dari pabrik itu sendiri. [^1] [^2] [^3]

## Lihat Satu Kereta, Lalu Lihat Satu Pabrik Gula

1905, setelah peralatan Pabrik Gula Qiaotou ditingkatkan, volume perasan meningkat drastis. Kereta sapi dan gerobak dorong manual yang tadinya mampu melayani ladang tebu kecil, mulai ketinggalan kecepatan tebu masuk pabrik. Produksi gula bukan menumpuk tebu di gudang lalu memprosesnya pelan-pelan. Setelah tebu dipanen, harus dikirim ke pabrik dalam waktu terbatas, jika tidak kadar gulanya akan turun. [^2]

Manajer pabrik saat itu, Yamamoto Teijiro, pergi ke Hawaii mengamati transportasi tebu, dan di Pulau Maui menemukan kereta api ringan berlebar 762 milimeter. Qiaotou pertama mencoba menggunakan kerbau menarik gerbong, baru kemudian beralih ke lokomotif uap. Ukuran ini lebih kecil dari kereta api umum, kecepatannya lebih lambat, tapi justru cocok menembus bundaran sawah, tepi sungai, dan antar desa. [^2]

15 September 1907, Pabrik Gula Qiaotou resmi mengoperasikan kereta api industri gula pertama di Taiwan. Tugas pertamanya sangat praktis: mengirim tebu ke pabrik. Tapi begitu rel dipasang ke daerah, jalur transportasi yang tadinya hanya melayani pabrik mulai mengatur ulang perpindahan orang dan barang. Mulai 1909, sebagian jalur kereta api gula dibuka untuk angkutan penumpang dan barang, infrastruktur industri dengan demikian menumbuhkan fungsi transportasi umum. [^2]

📝 **Catatan Kurator:** Kereta api kecil (五分車) bukan jadi pemandangan dulu baru diingat orang. Ia dulu jawaban teknik agar pabrik gula tidak kehabisan bahan baku, baru kemudian jadi sarana sehari-hari bersama antar desa.

## Sebelum Pabrik Gula Tradisional Hilang, Produksi Gula Sudah Jadi Kompetisi Sistem

Sebelum pabrik gula modern hadir, Taiwan bukan tanpa gula. Pabrik gula tradisional (糖廍) dulu kebanyakan skala kecil, memproduksi gula dengan tenaga kerja lokal dan peralatan sederhana. Artikel sejarah milik Taiwan Sugar (台糖) sendiri menghubungkan penanaman tebu dan ekspor gula di masa Belanda, Zheng Chenggong, dan Dinasti Qing, serta menunjuk bahwa awal masa pendudukan Jepang seluruh Taiwan masih memiliki banyak pabrik gula konvensional. [^4]

Pemerintah pendudukan Jepang pada 1902 mengeluarkan Peraturan Insentif Industri Gula, mendorong pabrik gula modern dan penanaman tebu. Berdirinya Pabrik Gula Qiaotou bukan sekadar satu mesin yang tiba-tiba mendarat di pedesaan. Ia butuh lahan, bahan baku, pekerja, jalan, rel kereta api, pelabuhan, dan satu sistem yang bisa menjamin pasokan tebu stabil. Tesis Universitas Nasional Cheng Kung memecah proses ini jadi empat bagian: kebijakan industri gula, transportasi darat pulau, transportasi laut, dan Pelabuhan Takao, mengingatkan pembaca bahwa ekspansi industri gula tidak pernah hanya terjadi di dalam pagar pabrik. [^5]

Efisiensi pabrik gula modern baru membuat pabrik gula tradisional (糖廍) menghadapi kompetisi baru. Arsip Taiwan Sugar mencatat, pabrik Qiaotou menyelesaikan peralatan akhir 1901, dan 15 Januari 1902 resmi beroperasi. Data yang disusun Wu Tsung-min dan Yeh Yen-hsün menunjukkan, 1905 pabrik gula modern di Taiwan sudah bertambah jadi 7 buah, 1906 nilai ekspor gula pasir kembali melebihi teh, menjadi salah satu komoditas ekspor terpenting Taiwan. [^4] [^15]

![Foto sejarah kereta api ringan industri gula wilayah Kaohsiung, menampilkan jalur cabang pabrik gula memasuki lanskap lokal](https://upload.wikimedia.org/wikipedia/commons/2/21/Light_railway_of_sugar_industry_in_Takao.jpg)

_Sumber gambar: Kantor Pusat Taiwan Sugar Pingtung〈File:Light railway of sugar industry in Takao.jpg〉，Wikimedia Commons, halaman berkas menandai domain publik Jepang dan AS, menggunakan tautan panas berkas asli._[^18]

Saat pengumpulan bahan baku jadi kunci apakah pabrik bisa beroperasi, antara petani tebu, pemilik pabrik gula tradisional, dan perusahaan (會社) muncul konflik kepentingan. Sejarah ini tidak bisa dilewati hanya dengan empat kata "kemajuan teknologi". Mesin menaikkan produksi, tapi juga menaikkan pertanyaan siapa yang berhak menentukan arah aliran tebu. [^6]

Tesis 〈Pengelolaan Industri Gula dan Konflik Petani di Taiwan Masa Pendudukan Jepang〉 memfokuskan pada sistem pengelolaan dan konflik petani, tepat melengkapi sisi lain yang mudah terlewat sejarah perusahaan. Pabrik gula butuh pasokan bahan baku stabil, petani tebu menghadapi aturan pengambilan, harga, dan pengaturan lahan. Kontrak tanam membuat rantai pasokan jadi terencana, tapi juga membuat petani lebih dalam terikat dalam aturan perusahaan. [^7]

## Kereta Api Gula Membawa Waktu Pabrik ke Desa

Kereta api gula awal menangani masalah "tebu harus cepat ke pabrik", tapi cepat juga menangani waktu orang lain. Data Stasiun Kereta Api Kecil Xihu milik Pabrik Gula Xihu yang disimpan Jaringan Layanan Data Budaya Terbuka Nasional menunjukkan, jaringan kereta api gula berpusat di Xihu, menghubungkan Lukang, Xizhou, Beidou, dan Yuanlin, selain mengangkut bahan produksi gula, juga menanggung fungsi angkutan penumpang. [^1]

Data budaya Jembatan Kereta Api Pabrik Gula Huwei memasukkan pabrik gula, jembatan, dan Kereta Api Lintas (Pulau) ke dalam satu peta transportasi lokal. Pabrik Gula Huwei didirikan 1906, perencanaan jembatan kereta api pabrik dan angkutan kargo, menjadikan pabrik gula sekaligus node perpindahan barang keluar. [^1]

Jalur-jalur ini tidak tentu punya jaringan seluruh pulau seragam seperti kereta api hari ini. Penelitian Universitas Nasional Cheng Kung menunjuk, kereta api industri gula, transportasi laut, dan Pelabuhan Takao membentuk divisi kerja, gula pasir dikumpulkan di pulau, lalu lewat pelabuhan disambung ke pasar luar. [^5] Artikel sejarah Taipei Times menunjuk, akhir masa pendudukan Jepang total panjang kereta api gula mendekati 3.000 kilometer, di antaranya lebih dari 600 kilometer menyediakan layanan komersial. Taruh angka ini kembali ke peta, terlihat banyak jalur cabang industri bagaimana menghubungkan pedesaan di sisi barat Pegunungan Tengah ke pasar lebih besar. [^2]

📝 **Catatan Kurator:** Modernisasi pedesaan Taiwan tidak hanya ditulis oleh Kereta Api Lintas (Pulau). Banyak tempat nunggu kereta angkut tebu dulu, baru nunggu kereta yang bisa bawa orang ke kota.

![Kereta api sejarah mengangkut tebu di barat daya Taiwan, diperkirakan difoto 1900–1945](https://upload.wikimedia.org/wikipedia/commons/0/0c/Sugar_cane_train_in_southern_Taiwan.jpg)

_Sumber gambar: Wikimedia Commons〈File:Sugar cane train in southern Taiwan.jpg〉，penulis tidak diketahui, halaman berkas menandai domain publik Jepang dan AS, menggunakan tautan panas berkas asli._[^13]

Kereta api kecil (五分車) juga masuk ke kegiatan agama dan lokal. Artikel Taipei Times mencatat, jalur kereta api gula Beigang setelah dibuka 1911, pernah menanggung angkutan jamaah ke Mazu Chao Tian Gong. Saat jalur industri diambil warga lokal untuk silaturahmi, sekolah, kerja, dan ziarah, logika ekonomi pabrik gula meresap ke irama kehidupan. [^2]

## Di Balik Rasa Manis, Ada Modal Kolonial dan Tata Tanah

Industri gula modern masa pendudukan Jepang memang membawa mesin, varietas unggul, dan pembangunan transportasi, tapi tujuan dan relasi kekuasaannya juga harus diletakkan di paragraf yang sama. Arsip sejarah perusahaan yang disusun majalah bulanan Taiwan Sugar menunjuk, Perusahaan Gula Taiwan (Kabushiki Kaisha) yang didirikan 1900 mendapatkan dukungan modal Jepang, 1901 memilih Qiaotou membangun pabrik modern pertama. Ini kisah investasi perusahaan, juga kisah pemerintah kolonial ingin Taiwan keuangan mandiri, memasok pasar Jepang. [^4]

Jaringan Aset Budaya Nasional menempatkan Pabrik Gula Qiaotou sebagai pabrik gula modern pertama Taiwan, dan mencatat perjalanannya dari pendirian awal 1901, perluasan pasca 1905, hingga penyempurnaan bertahap sebelum 1945. Simbol "pertama" ini penting, tapi tidak boleh membuat lahan dan buruh di luar pabrik jadi latar belakang. [^6]

Penelitian akademis tentang industri gula dan transportasi awal masa pendudukan Jepang menunjukkan, perkembangan pabrik gula modern bergantung saling kait dengan wilayah pengumpulan bahan baku, pembangunan rel kereta api, rute transportasi laut, dan bangkitnya Pelabuhan Takao. Pabrik gula dengan demikian sekaligus fasilitas industri, pengelola lahan, dan node transportasi. [^5]

Dari sudut petani, sistem kontrak tanam bukan cuma "pasokan stabil" metode manajemen perusahaan. Ia melibatkan siapa tanam apa, tebu kapan dipanen, dikirim ke pabrik mana, dan harga كيف dihitung. Penelitian konflik petani penting karena mengembalikan sejarah industri gula dari tabel produksi perusahaan ke ladang. [^7]

## Penerimaan Pasca Perang Bukan Satu Tanggal

![Tampilan kereta sejarah Pabrik Gula Guangfu Hualien, menampilkan bagaimana transportasi gula jadi kenangan lokal pasca berhenti produksi](https://upload.wikimedia.org/wikipedia/commons/5/53/Taiwan_2009_GuangFu_Sugar_Factory_Historical_Train_Exhibition_RD_6173.jpg)

_Sumber gambar: Fred Hsu〈File:Taiwan 2009 GuangFu Sugar Factory Historical Train Exhibition RD 6173.jpg〉，Wikimedia Commons, CC BY-SA 3.0 Unported, menggunakan tautan panas berkas asli._[^19]

1945 Agustus Jepang menyerah, hak milik pabrik gula berubah, tapi pabrik tidak dengan itu pulih operasi. Komite Sumber Daya akhir Oktober 1945 membentuk tim penerimaan, menguasai pabrik gula utama milik orang Jepang. Penerimaan bersamaan menghadapi kerusakan peralatan, kekurangan material, penyesuaian personel, dan pasokan bahan baku, harus memasukkan kembali pabrik, lahan, rel kereta api, dan sistem perusahaan ke dalam mesin negara pasca perang. [^14]

Ringkasan penelitian Cheng Yu-feng menunjuk, akhir perang sekitar 80% pabrik gula rusak, setelah penerimaan lewat perbaikan, dana masuk, pembelian mesin, dan penempatan tenaga teknis, dalam dua tahun selesai pemulihan, dan 1946–47 pulih produksi. Proses ini membuat "berdirinya Taiwan Sugar" bukan cuma hari pendaftaran perusahaan, tapi rangkaian kerja penerimaan, pemulihan, dan pembangunan ulang tatanan produksi. [^14]

Penelitian Wu Tsung-min dan Yeh Yen-hsün menunjuk, akhir 1905 Taiwan Sugar Company yang baru didirikan menggabungkan empat perusahaan gula besar masa pendudukan Jepang ke satu struktur perusahaan BUMN dan monpolis. Perusahaan baru menerima lahan dan pabrik lama, juga melanjutkan sistem wilayah pengumpulan bahan baku. Manajemen berganti, pasokan tebu tetap terkunci di sekitar setiap pabrik gula. [^15]

## Pasca Perang Taiwan Sugar Menerima Pabrik, Juga Menerima Masalah

1945 setelahnya, perang membuat banyak pabrik gula dan peralatan rusak. Artikel pasca perang Taiwan Sugar mencatat, Perusahaan Gula Taiwan 1 Mei 1946 didirikan, menerima dan mengkoordinasikan aset industri gula warisan masa pendudukan Jepang. Artikel menggambarkan industri gula sebagai tiang pemulihan ekonomi pasca perang, juga menyebut Taiwan Sugar memperbaiki pabrik, mengekspor gula pasir, mengembangkan produk samping, dan mempertahankan sistem pasokan petani tebu. [^8]

Narasi ini punya bobot sejarahnya, tapi juga perlu mempertahankan perspektif sejarah perusahaan. Taiwan Sugar menghubungkan kenaikan harga gula internasional akibat Perang Korea 1950-an, pasar ekspor, dan peralatan bantuan AS jadi era keemasan. Di sisi lain, industri gula bergantung harga internasional, cuaca, varietas, lahan, dan perlindungan pemerintah, perluas penanaman tidak jamin sukses jangka panjang. [^8]

Sistem bagi hasil gula dan harga minimum terjamin pasca perang Taiwan Sugar, mencoba mengikat pabrik gula dan petani tebu di satu rantai produksi yang sama. Sistem ini satu sisi memberikan bahan baku dan pendapatan relatif stabil, sisi lain membuat Taiwan Sugar di pedesaan punya kekuatan organisasi sangat kuat. Pabrik gula selain memberikan kerja, juga bisa jadi pusat lahan, kredit, transportasi, dan kesejahteraan lokal. [^8]

Artikel lain majalah bulanan Taiwan Sugar yang membahas sumber daya industri gula seratus tahun, mengklasifikasikan aset budaya industri gula ke tipe pertanian, industri, transportasi, dan manajemen. Klasifikasi ini justru menjelaskan masalah warisan industri gula: kalau cuma simpan asap dan gedung pabrik, tidak akan tersimpan sistem relasi yang dulu bikin seluruh tempat itu berputar. [^9]

## Harga Tebu Bukan Sekadar Harga

![Kereta di dalam pabrik gula Jiali, menampilkan pabrik gula masih pakai rel mengatur ruang bahan baku dan perpindahan area pabrik](https://upload.wikimedia.org/wikipedia/commons/9/90/Jiali_Sugar_Refinery_Plant_Train.JPG)

_Sumber gambar: Koika〈File:Jiali Sugar Refinery Plant Train.JPG〉，Wikimedia Commons, CC BY-SA 3.0 Unported, menggunakan tautan panas berkas asli._[^20]

Sistem wilayah pengumpulan bahan baku 1905 mengatur, tebu di wilayah kecuali dapat izin Gubernur Jenderal, tidak boleh dikeluarkan atau dipakai produksi gula lain. Pabrik gula dengan demikian memperoleh posisi pembeli tunggal (独買) tebu di wilayah, petani tebu tetap bisa pilih tanaman, tapi harus putus antara harga tebu yang diumumkan pabrik gula dan pendapatan harapan padi dan tanaman kompetitor lain. Tebu dari tanam sampai panen butuh satu sampai setengah tahun, selisih waktu ini membuat harga tebu sebenarnya juga semacam taruhan pada masa depan. [^15]

Undang-undang bagi hasil pasca perang mencoba mengatur ulang hubungan ini. Periode 1946–47, petani tebu dapat 48% gula pasir jadi, Taiwan Sugar ambil 52%. Periode 1947–48 proporsi disesuaikan jadi setengah-setengah. Periode 1950–51 tambah harga minimum terjamin, pemerintah dan Taiwan Sugar harap menstabilkan keinginan petani menanam tebu. Angka kelihatannya petani dapat produk lebih banyak, tapi pendapatan aktual tetap tergantung harga gula, tingkat rendemen gula, harga patokan, dan harga beras. [^15]

Wu Tsung-min dan Yeh Yen-hsün menyebut masalah ini "konflik beras-gula" (米糖相剋): petani bandingkan pendapatan harapan antara padi dan tebu, pabrik gula tapi pembeli utama bahan baku tebu. Kontrak tanam dan harga terjamin memberikan stabilitas, tapi juga mengikat petani lebih kencang ke satu pengolah tunggal. Ini salah satu kontradiksi industri gula yang patut diperhatikan, karena stabilitas rantai pasokan tidak tentu berarti setiap partisipan punya kekuatan tawar yang sama. [^15]

## Siapa yang Kerja di Pabrik Gula

Sejarah industri gula kalau hanya tinggalkan nama perusahaan dan jalur rel kereta api, akan bikin pabrik kelihatannya seperti mesin yang jalan sendiri. Nyatanya, musim gula adalah periode padat kerja. Tebu harus dipanen pasca masak, dipotong, naik gerbong, ditimbang, lalu urut-urut masuk area perasan sesuai jadwal pabrik. Mesin mempercepat produksi gula, tapi tidak bikin kerja di ladang jadi lebih ringan. Sebaliknya, jam pabrik menarik ritme pedesaan ke satu jadwal pengiriman yang lebih presisi.

Petani tebu, pengemudi gerbong (車伕), pekerja rel, pekerja ruang ketel, teknisi perbaikan mesin, dan karyawan kantor, bersama menopang produksi musiman satu pabrik gula. Ada yang di ladang nunggu panen, ada yang di timbangan catat berat, ada yang bikin gerbong saling lewat di jalur cabang sempit. Posisi-posisi ini gaji, keahlian, dan stabilitasnya beda, tapi semuanya ditarik satu musim gula yang sama. Lingkungan hidup yang disediakan pabrik gula dengan demikian punya tingkatan, juga punya kepadanan saling ketergantungan.

Hidup pekerja meluas ke asrama, klinik, koperasi, lapangan, dan serikat buruh. Sistem tiap pabrik gula tidak sama persis, tidak bisa pengalaman kesejahteraan satu pabrik gula langsung diterapkan ke seluruh Taiwan, tapi ruang-ruang ini jelaskan bagaimana perusahaan masuk ke masyarakat lokal. Objek manajemen pabrik selain shift, juga mencakup tempat tinggal keluarga karyawan, kesehatan, rekreasi, dan pendidikan anak. Pabrik gula jadi semacam masyarakat berpayung.

## Dari Tiang Ekspor ke Transformasi Industri

Pentingnya industri gula terlihat dari rasio nilai produksi, juga terlihat bagaimana ia mundur dari posisi pusat. Statistik jangka panjang yang disusun Wu Tsung-min dan Yeh Yen-hsün menunjukkan, nilai produksi gula pasir 1925 sekitar 54,3% dari nilai produksi utama industri Taiwan, 1937 masih 56,4%. Pasca perang 1951 sekitar 20% nilai produk utama manufaktur, 1965 turun jadi 5%, 1978 tinggal 0,8%. Angka-angka ini menunjukkan, industri gula masa pra-perang pernah jadi badan utama nilai produksi industri, pasca perang lalu berangsur mundur jadi sektor industri yang dijaga negara. [^15]

1950-an dan 1960-an industri gula masih punya tugas negara yang kuat. Ekspor gula pasir bisa tukar devisa, pabrik gula bisa kasih kerja, kereta api gula bisa hubungkan pedesaan ke pasar. Tapi sistem yang sama juga terikat harga gula internasional dan biaya transportasi. Saat negara produsen gula lain naikkan efisiensi, gula impor masuk pasar, biaya lahan dan buruh Taiwan naik, keunggulan lama industri gula perlahan longgar. Artikel perusahaan Taiwan Sugar pasca perang menggambarkan periode ini sebagai era keemasan, pengertian ini bisa lihat puncak ekspor dan investasi, tapi harus dibaca bareng penyesuaian industri yang datang kemudian. [^8]

Penurunan industri gula bukan tahun tertentu tiba-tiba tekan tombol stop. Sebagian jalur dulu kurangi jadwal, sebagian pabrik gula sesuaikan musim produksi, sebagian lahan pertanian ganti tanam. Bagi orang yang tinggal dekat pabrik gula, perubahan sering muncul dulu sebagai cara menunggu yang jadi lebih lama: kereta api kecil (五分車) tidak lewat tiap hari, asap pabrik tidak lagi keluar musim tetap, lowongan familiar tidak kembali. Titik belok sejarah industri dengan demikian juga dirasakan sebagai perubahan irama sehari-hari.

## Pabrik Berhenti, Industri Gula Tidak Langsung Pergi

Impor gula pasir, kompetisi internasional, perubahan struktur industri, dan masalah biaya, membuat industri gula Taiwan berangsur mundur dari posisi pusat ekspor dulu. Wu Tsung-min dan Yeh Yen-hsün menunjuk, pasca perang Taiwan Sugar hadapi masalah bukan cuma harga gula internasional, tapi juga pasar ekspor, pengaturan kurs, sistem BUMN monpolis, dan sistem pengambilan tebu yang bersamaan berubah. Kalau mundur hanya dijabarkan "kompetisi internasional jadi sengit", akan kelewatan pengaruh sistem perusahaan dan harga kebijakan ke petani dan pabrik. [^15] Sebagian pabrik gula berhenti produksi, daerah mulai hadapi pertanyaan sulit: kalau satu pabrik tidak lagi produksi gula, apakah ia masih bisa jadi bagian dari daerah?

Materi tema industri gula Kementerian Budaya menempatkan Qiaotou, Dulan, Xihu, Huwei dll di dua paragraf "Industri Gula yang Hilang" dan "Membangun Ulang Budaya Gula". Desa Seni Pabrik Gula Qiaotou mulai 2001 beroperasi, mengubah zona cagar budaya jadi ruang kedudukan seni. Cara ini mengakui fungsi produksi pabrik sudah berubah, baru biarkan pengguna baru dan bangunan lama menghasilkan relasi lain. [^1]

Laporan penelitian aset budaya Pemerintah Kota Kaohsiung mencatat, Pos Keamanan Pabrik Gula Qiaotou dibangun sekitar 1953, kemudian masuk perencanaan restorasi dan pemanfaatan ulang cagar budaya pabrik gula. Laporan sekaligus mencantumkan pendirian, perluasan, urusan keamanan, struktur bangunan, dan manajemen mitigasi bencana pabrik gula, laporan ini mengingatkan kita, pelestarian budaya juga harus jawab siapa pakai, gimana rawat, dan kena bencana gimana. [^10]

📝 **Catatan Kurator:** Kehidupan kedua pabrik gula tidak otomatis sama dengan pelestarian sukses. Pelestarian sejati, adalah bikin orang lihat bagaimana satu pabrik dulu menguasai daerah, dan bikin daerah punya kemampuan menentukan ia mau jadi apa selanjutnya.

## Segmen Terakhir Kereta Api Gula

![Kereta api kecil Taiwan Sugar Huwei, difoto 2007, menampilkan penampilan akhir kereta api gula dari alat produksi jadi kenangan lokal](https://upload.wikimedia.org/wikipedia/commons/5/58/Taiwan_Sugar_Railways_train_02.jpg)

_Sumber gambar: Hung Ju Lu〈File:Taiwan Sugar Railways train 02.jpg〉，Wikimedia Commons, CC BY 2.0 Generic, menggunakan tautan panas berkas asli._[^21]

Penurunan kereta api gula juga bukan semalam. Saat pabrik gula 1970-an akhir menghadapi kompetisi internasional lebih sengit, sebagian pabrik tutup, jalur cabang rel kehilangan tugas angkut tebu asal. Penelitian pelestarian aset budaya industri gula Taiwan menunjuk, Taiwan Sugar bertahap tutup pabrik gula setelahnya, karyawan harus berubah dari produsen dan manajer jadi peneliti aset budaya, pemelihara, perencana pemanfaatan ulang, dan pemandu wisata. [^16]

Transformasi ini mengandung fakta tidak nyaman: orang yang melestarikan industri gula, sering kali adalah orang yang dulu kerja di pabrik gula. Saat ruang ketel, rel, dan gudang jadi objek pameran, teknik kerja asal juga harus diterjemahin jadi cerita yang wisatawan pahami. Penelitian menunjuk, Taiwan Sugar dari 2002 mulai inventarisasi aset budaya industri gula, mendirikan Museum Barang Sejarah Industri Gula, Museum Industri Gula Taiwan, dan Taman Budaya, tapi BUMN serentak menghadapi tarikan untung dan kepentingan umum, peraturan dan birokrasi. [^16]

Terbitan 2026 _Taiwan Panorama_ (台灣光華) khusus menunjuk 1990-an kereta api gula sebagai "tahun-tahun senja penutupan bertahap", menempatkan kereta api gula ke dalam jaringan yang masih meluas, tapi sedang menyusut. Warisan kereta api gula dengan demikian tidak bisa dipahami cuma dari kereta wisata. Ia masih termasuk jalur gimana dibongkar, lahan gimana dipakai ulang, bekas karyawan tua gimana menjelaskan kerja lagi, dan daerah gimana menutus fasilitas mana yang layak disimpan. [^17]

## Satu Rasa Manis, Empat Jenis Kenangan

![Area pabrik gula Qiaotou dan rel industri gula, menampilkan hubungan ruang pabrik gula dan kereta api](https://upload.wikimedia.org/wikipedia/commons/c/c4/Ciaotou_Sugar_Refinery_01.jpg)

_Sumber gambar: SuinegMai〈File:Ciaotou Sugar Refinery 01.jpg〉，Wikimedia Commons, CC BY 3.0 Unported, menggunakan tautan panas berkas asli._[^12]

Bagi pekerja pabrik gula, kenangan mungkin shift musim buka, suara mesin, dan panas di dalam pabrik. Bagi petani tebu, kenangan mungkin cuaca sebelum tebu masak, waktu panen, gerbong angkut tebu, dan penagihan. Bagi yang naik kereta api kecil (五分車), kereta api gula adalah jalan ke pasar, sekolah, pura, dan kota tetangga. Bagi orang hari ini masuk taman pabrik gula, yang tersisa mungkin bata merah, rel, gudang, dan segmen sejarah industri yang ditafsirkan ulang.

Beberapa jenis kenangan ini ada bersamaan, saling tidak bisa saling membatalkan. Industri gula pernah jadi tiang penting ekspor dan industrialisasi Taiwan, juga pernah hubungkan pemerintah kolonial, perusahaan modal, lahan pedesaan, dan buruh ke satu sistem manajemen. Ia ciptakan transportasi, tapi tidak berarti semua orang pakai transportasi itu adil. Ia bawa pabrik, tapi tidak berarti untung dan risiko pabrik ditanggung orang yang sama.

Jadi, yang benar-benar diangkut kereta api kecil (五分車) dari dulu bukan cuma tebu. Ia mengangkut satu tuntutan kecepatan, satu tata lahan, satu tata siapa boleh bergerak. Hari ini ia berhenti di taman pabrik gula, roda tidak lagi kirim bahan baku ke mesin peras, tapi tetap memaksa kita menoleh: modernisasi Taiwan, siapa yang pasang rel, siapa yang kerja di pinggir rel, dan siapa yang setelah pabrik berhenti tinggal menjaga kenangan.
