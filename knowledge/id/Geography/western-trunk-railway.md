**Ringkasan 30 detik:** Pada 20 April 1908, jalur kereta api longitudinal dari Keelung ke Takao selesai dibangun; pada 24 Oktober tahun yang sama, Gubernur Jenderal Taiwan menggelar upacara pembukaan seluruh jalur di Taman Taichung. Satu sisi, jalur ini mengirimkan beras, gula, dan kayu lebih cepat ke pelabuhan; sisi lain, jalur ini memicu pertumbuhan pendapatan pertanian di beberapa kota yang terhubung ke jalur kereta api. Ini bukan sekadar kisah modernisasi, melainkan sebuah garis yang sekaligus memperbesar kontrol kekaisaran, kesempatan lokal, dan perbedaan sosial.

![1908 年臺灣縱貫鐵道通車式典禮建築](https://upload.wikimedia.org/wikipedia/commons/f/fc/Ceremony_building_of_opening_of_the_J%C5%ABkan_Railway_Line_in_Taiwan.png)
_Gambar: Bangunan upacara pembukaan Jalur Kereta Api Longitudinal 1908; Kelompok Pemulihan Sejarah dan Budaya Taichung, Public domain, via Wikimedia Commons._

Pada tahun 1887, Liu Mingchuan mendirikan Kantor Pusat Bisnis Kereta Api Seluruh Taiwan di Dadaocheng, Taipei. Pada 20 April 1908, seluruh jalur Jalur Kereta Api Longitudinal dari Keelung ke Takao (sekarang Kaohsiung) selesai dibangun. Pada 24 Oktober, Gubernur Jenderal Taiwan menggelar upacara pembukaan seluruh jalur di Taman Taichung. Jalur kereta api ini tampak seperti proyek transportasi, tetapi sebenarnya merupakan tiga hal sekaligus: menghubungkan pulau bagian utara dan selatan, mengirimkan hasil pertanian ke pelabuhan, dan menuliskan kecepatan pemerintah kolonial terhadap tanah dan penduduk ke dalam lanskap.[^1] [^2]

Bagian paling kontrintuitif ada di sini: Jalur Kereta Api Longitudinal awalnya dirancang sebagai mesin untuk ekspor kekaisaran, namun justru memudahkan sebagian petani Taiwan mengakses pasar, bahkan meningkatkan pendapatan pertanian mereka. Ini bukan narasi tunggal tentang "kolonialisme membawa modernisasi", juga bukan narasi tunggal tentang "kereta api hanya untuk merampas". Ini adalah sebuah garis yang sekaligus memperluas kontrol dan kesempatan.

## Yang ditinggalkan Liu Ming-chuan, bukanlah sebuah Jalur Trunk yang sudah selesai

Liu Ming-chuan sering ditempatkan di halaman pertama cerita kereta api Taiwan, tetapi yang ditinggalkannya hanyalah sebuah titik awal yang belum selesai. Dinasti Qing memulai pembangunan kereta api dari Taipei ke Keelung pada tahun 1887, dan pada 1891 selesai membangun jalur Taipei—Keelung sepanjang sekitar 28 kilometer. Rencana perpanjangan menuju Taoyuan dan Hsinchu terhenti seiring dengan mundurnya Liu Ming-chuan dari jabatannya.[^3]

Kesulitan kereta api awal ini tidak hanya soal kekurangan dana. Lereng rute terlalu curam, teknologi bergantung pada insinyur asing, dan pihak penerima harus mengatasi masalah bahwa jalur yang sudah ada tidak cocok untuk operasi jangka panjang. Setelah Jepang mengambil alih Taiwan pada 1895, mereka terlebih dahulu mengelola kereta api sebagai transportasi militer, baru kemudian beralih ke transportasi umum yang dikelola oleh lembaga sipil.[^2] [^4]

Oleh karena itu, "Kereta Api Pertama Taiwan" dan "Jalur Trunk Taiwan" bukanlah hal yang sama. Yang pertama adalah segmen pendek di era Liu Ming-chuan, sedangkan yang kedua adalah jalur utama utara-selatan yang didesain ulang dan dibangun bertahap oleh pemerintah kolonial Jepang menggunakan keuangan negara setelah 1899.

> 📝 **Catatan Kurator**: Melihat bersama-sama jalur pendek Liu Ming-chuan dan Jalur Trunk 1908, akan terlihat bahwa "kereta api pertama" dan "menyelesaikan satu sistem kereta api" sebenarnya adalah dua hal yang berbeda; yang pertama adalah sebuah titik awal, sedangkan yang kedua baru menjadi uji apakah sebuah negara mampu memelihara, mengoperasikan, dan mendistribusikan kecepatan dalam jangka panjang.

## Dari Perusahaan Swasta, Kembali ke Proyek Negara

Pada awal masa penjajahan Jepang, Jalur Kereta Api Menembus tidak dibangun sepenuhnya oleh pemerintah sejak awal. Pada 1896, pihak Jepang pernah merencanakan pendirian Perusahaan Kereta Api Taiwan, berencana memperbaiki jalur kereta api yang sudah ada, membangun rute dari Hsinchu ke Takao, bahkan menyiapkan subsidi lahan dan bunga. Namun perusahaan tersebut akhirnya gagal didirikan secara resmi, modal swasta tidak mampu menanggung skala proyek tersebut.[^4]

Goto Shinpei yang tiba di Taiwan pada 1898 menilai, kereta api harus dikembangkan selaras dengan pembangunan pelabuhan Keelung, baru proyek itu dapat menghasilkan pendapatan angkutan. Investasi awal seperti ini, tidak dapat dibebankan hanya pada perusahaan swasta. Parlemen Jepang karena itu mengesahkan 「臺灣事業公債法」, dari total 35 juta yen obligasi, 28,8 juta yen dialokasikan untuk Jalur Kereta Api Menembus.[^4]

Ini adalah titik balik penting: Jalur Kereta Api Menembus tidak tumbuh secara alami dari pasar, melainkan proyek yang didorong bersama oleh negara penjajah menggunakan obligasi, aparatur birokrasi, serta tujuan militer dan ekonomi. Pada 1899, Bagian Pembangunan Kereta Api Sementara Taiwan didirikan. Bulan November tahun yang sama, Biro Kereta Api Gubernur Jenderal Taiwan didirikan, menggabungkan pembangunan, operasi, perawatan, dan kereta api swasta ke dalam satu manajemen terpadu.[^4]

Desain organisasi Biro Kereta Api juga mengungkapkan hakikat proyek ini. Biro ini tidak hanya bertanggung jawab memasang rel, tetapi juga mengelola angkutan kereta, perawatan rute, serta kereta api swasta yang digunakan industri gula, kehutanan, dan pertambangan. Oleh karena itu, Jalur Menembus bukan sekadar jalur penumpang terisolasi, melainkan jaringan angkutan yang menghubungkan pelabuhan, tempat produksi, pabrik, dan jalur cabang.

## "Perpanjangan Cepat" dan Harga di Pegunungan

Mei 1899, Hasegawa Kinsuke memimpin proyek konstruksi dari kedua ujung utara dan selatan. Rute mengadopsi pendekatan di mana setiap segmen yang selesai segera dioperasikan, memungkinkan kereta api memperoleh pendapatan operasional sambil konstruksi berlangsung. Catatan sejarah resmi merangkum kebijakan ini sebagai "Perpanjangan Cepat" (速成延長主義)。[^4]

Namun kecepatan tidak gratis. Jalur pegunungan antara Sanyi dan Fengyuan harus menembus bukit-bukit dan topografi patahan di Miaoli dan Taichung. Segmen yang kemudian menjadi Jalur Pegunungan Lama (舊山線), mencakup jembatan dan terowongan. Jaringan Aset Budaya Nasional mencatat, gempa besar Tengah 1935 menyebabkan kerusakan parah pada jembatan dan terowongan dari Stasiun Shifen (十六份停車場) ke Taichung, kereta api berhenti operasi untuk perbaikan selama tiga tahun, hingga 1938 baru pulih beroperasi.[^5]

Satu terowongan memakan waktu lima tahun dan lebih dari 4,2 juta yen, sekitar seper enam dari keseluruhan anggaran proyek Jalur Menembus (縱貫線). Angka ini menarik "modernisasi" (現代化) dari kata benda abstrak ke dinding batu: setiap kilometer menuntut material, jam kerja, dan risiko, sedangkan tempo proyek ditentukan oleh keuangan dan kebutuhan transportasi kekaisaran.[^6]

20 April 1908, seluruh Jalur Menembus (縱貫鐵路) selesai dibangun. 24 Oktober, pemerintah resmi menggelar upacara penyelesaian (全通式) di Taman Taichung. Upacara ini bukan sekadar perayaan transportasi, melainkan ritual publik pemerintah kolonial untuk menunjukkan "sudah mampu mengelola seluruh pulau". Resmi mengundang keluarga kerajaan, pejabat, dan tokoh masyarakat, serta memaketkan penyelesaian kereta api sebagai bukti Taiwan memasuki era baru.[^2] [^4]

> 📝 **Catatan Kurator**: Upacara resmi meninggalkan gambaran penyelesaian, tetapi pegunungan menyimpan waktu konstruksi, gempa, dan pemulihan; jika hanya melihat hari pembukaan, penantian terlama dalam proyek akan terpotong.

## Bagaimana Satu Garis Mengubah Jarak

Sebelum jalur kereta api longitudinal dibangun, pergerakan utara-selatan di Taiwan dibatasi oleh jalan, sungai, dan musim. Setelah kereta api selesai, perjalanan dari utara ke selatan memakan waktu sekitar 14 jam. Kecepatan ini pada saat itu telah mendefinisikan ulang «perjalanan di pulau», menjadikan kereta api sebagai alat transportasi utama untuk pergerakan lintas wilayah.[^7]

Transportasi tidak hanya mengubah nasib penumpang. Kereta api mengangkut beras, gula, kayu, dan hasil tambang dari pedalaman ke pelabuhan, lalu menghubungkannya dengan jaringan pelayaran Kekaisaran Jepang. Penelitian berbahasa Inggris yang mengolah data statistik Gubernur Jenderal Taiwan menunjukkan, posisi stasiun dan konfigurasi rute jalur longitudinal terutama melayani kebutuhan ekspor pertanian menuju pelabuhan.[^6]

Desain ini juga menjelaskan mengapa kereta api dan cabang-cabang industri gula, kehutanan, dan pertambangan segera terhubung. Pada peta arsip nasional tahun 1930-an, selain jalur utama milik negara, ada juga jalur usaha swasta, jalur khusus perusahaan, serta rel ringan yang didorong oleh tenaga manusia atau hewan. Kepadatan jaringan kereta api mencerminkan bukan sekadar keramaian pariwisata, melainkan bagaimana industri dihubungkan ke node transportasi.[^8]

### Tiga Titik Waktu, Melihat Bagaimana Kereta Api Menjadi Jaringan

| Waktu   | Kejadian                                                        | Arti Angka Ini                                                                               |
| ------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 1908    | Jalur longitudinal selesai sepenuhnya, Taipei–Kaohsiung ~14 jam | Jarak utara-selatan pertama kali terkompresi menjadi jadwal yang dapat direncanakan[^2] [^7] |
| 1922    | Jalur pantai Zhunan–Wangtian dibuka sepenuhnya                  | Terbentuknya pola dua jalur utama gunung dan laut di bagian barat[^2]                        |
| 1930-an | Jalur Wanshin mengangkut >3,64 juta penumpang per tahun         | Jalur cabang swasta juga bisa menjadi transportasi harian kota[^2]                           |

Yang paling mudah terlewat dalam tabel ini adalah tahun 1922. Jalur longitudinal tidak berhenti berkembang setelah pembukaan 1908. Jalur pantai melengkapi jalur alternatif jalur gunung, mengubah kereta api dari satu jalur utama utara-selatan menjadi jaringan yang bisa membagi aliran, menghubungkan tempat produksi, dan menghubungkan pelabuhan.[^2]

Hal yang sama patut diperhatikan, kereta api tahun 1930-an tidak hanya melayani penumpang jarak jauh. Jalur Wanshin dari Wanhua ke Hsintien, meski hanya 10,4 km, pada 1930 mengangkut lebih dari 3,64 juta penumpang. Angka ini mengembalikan «kereta api» dari proyek nasional menjadi alat transportasi yang dikendarai warga kota setiap hari.[^2]

![Peta Jalur Kereta Api Taiwan 1950](https://upload.wikimedia.org/wikipedia/commons/c/c3/1950_map_of_Taiwan_railway.jpg)
_Gambar: Peta jalur kereta api Taiwan 1950 diterbitkan oleh Administrasi Kereta Api Taiwan; Public domain, via Wikimedia Commons._

Peta tahun 1950 ini menampilkan satu titik balik lain di atas kertas: jalur longitudinal tidak lagi sekadar hasil rekayasa pemerintah kolonial, melainkan disusun ulang oleh Administrasi Kereta Api Taiwan pasca-perang menjadi satu imajinasi ruang transportasi publik. Peta ini tidak menghapus kerusakan yang ditinggalkan perang, juga tidak menjelaskan setiap tempat mendapat keuntungan berapa. Ia hanya menampilkan terlebih dahulu «tempat mana yang terhubung».[^12]

Namun, orientasi ekspor tidak berarti daerah sama sekali tidak mendapat keuntungan. Penelitian sejarah ekonomi LSE menggunakan data statistik 1905–1918 membandingkan kota yang terhubung kereta api dan yang tidak, menemukan kota yang terhubung kereta api mengalami peningkatan rata-rata pendapatan lahan irigasi sekitar 60.000 yen. Kereta api menurunkan biaya transportasi, memperluas pasar, dan memberikan insentif bagi sebagian petani untuk berinvestasi pada irigasi dan penyempurnaan tanaman.[^6]

Penelitian sekaligus mengingatkan, keuntungan tidak merata. Di kota dengan kepadatan penduduk meningkat, pendapatan lahan irigasi justru bisa menurun. Kompetisi lahan dan urbanisasi mendistribusikan ulang keuntungan yang dibawa kereta api. Oleh karena itu, jalur longitudinal bukanlah garis di mana «semua orang untung», melainkan garis yang membuat disparitas dipercepat.[^6]

## Jalur Gunung Bukan Latar Belakang, Melainkan Jalur Kereta Api Itu Sendiri

Pada saat gempa bumi wilayah Hsinchu–Taichung tahun 1935, rel Jalur Gunung Vertikal melengkung, dinding terowong retak, stasiun dan jembatan runtuh, dan kereta berhenti beroperasi selama tiga tahun. Bencana ini membuka mata kita: jalur kereta api bukanlah garis lurus yang digambarkan di peta, melainkan sebuah teknik yang menua bersama gempa bumi, kemiringan, dan lapisan batuan.[^5]

Sisa-sisa Stasiun Shengxing dan Jembatan Putus Yutengping (Longteng) memperlihatkan bagaimana Jalur Vertikal menembus pegunungan, dan juga bagaimana bencana alam menulis ulang sebuah jalur utama. Mereka bukan cagar budaya yang terpisah dari sejarah transportasi, melainkan jejak nyata dari teknik kereta api.[^5]

Situs-situs ini juga mengubah fungsi jalur kereta api. Segmen yang dulunya mengangkut batu bara, kayu, dan buah-buahan, setelah berhenti beroperasi menjadi jalur pameran sejarah dan pariwisata. Terowong dan jembatan yang sama, berubah dari infrastruktur transportasi menjadi wadah kenangan lokal.[^5]

Tantangan pelestarian warisan kereta api justru terletak pada: memperlihatkan bagaimana teknik bekerja, bukan hanya mengubahnya menjadi pemandangan nostalgia. Menyelamatkan rel, tiang jembatan, dan stasiun, berarti juga menyelamatkan sebuah bahasa teknis yang pernah mengatur pergerakan.[^5] Inilah alasan Jalur Vertikal tetap layak untuk dibaca kembali.

Yang ia tinggalkan bukan jawaban tunggal, melainkan sebuah jalur yang dapat ditanyakan berulang kali.

Di luar stasiun, kereta api juga menciptakan gaya hidup

Setelah salur melintang mulai beroperasi, Departemen Kereta Api mulai mengelola bukan hanya kereta. Ia meluncurkan tiket diskon, layanan terhubung ke pantai berenang, dan kegiatan perjalanan, serta menghubungkan kereta api ke hotel, restoran, bis, dan rute wisata. Pada 1930-an, kereta api mulai menjual imajinasi "keliling pulau", meskipun jalur kereta api keliling pulau yang benar-benar lengkap saat itu belum ada.[^8]

Kasus tahun 1933 di Arsip Nasional sangat menjelaskan hal ini: siswa Sekolah Normal Taichung naik kereta ke Yilan, lalu melewati Su'ao, Taroko, Hualien, Taitung, dan bagian selatan, menyusun perjalanan keliling pulau dengan mobil, jalan kaki, dan kereta api. Baru pada 1991, setelah Jalur Selatan mulai beroperasi, masyarakat benar-benar bisa keliling pulau sepenuhnya dengan kereta api.[^8]

Kereta api juga membawa perbedaan kelas. Materi pameran Museum Sejarah Nasional Taiwan menyatakan, tiket kereta di era Jepang tidak murah bagi kebanyakan orang Taiwan, penumpang kelas satu terutama adalah orang asing serta golongan atas Taiwan-Jepang.[^7] Orang umum lebih sering naik kereta untuk festival, pantai berenang, atau perjalanan pendek.[^7]

Jadi, kereta api di satu sisi mempersingkat jarak pulau, di sisi lain juga menjadikan "siapa yang bisa bergerak, dengan cara apa" sebagai perbedaan sosial baru. Transportasi modern tidak pernah hanya soal kecepatan, tapi juga harga tiket, stasiun, dan siapa yang ditempatkan di sisi rute.

## Perang, Pemulihan, dan Kehidupan Kedua Sebuah Jalur

Pada akhir Perang Dunia Kedua, jalur kereta api Taiwan dibombardir, jembatan, saluran, dan rel rusak. Setelah Jepang meninggalkan Taiwan, sistem kereta api sempat hanya beroperasi dengan cara yang terpaksa. Setelah 1949, personel baru, material, dan peralatan bantuan AS secara bertahap masuk, baru kemudian kereta api pulih menjadi moda transportasi utama Taiwan pasca-perang. [^3] [^9]

Bengkel Taipei memberikan perspektif lain. Di era Jepang, bengkel ini memperbaiki lokomotif uap; pada 1960-an beralih ke lokomotif diesel-elektrik; setelah rel listrik 1979, kembali memperbaiki lokomotif listrik. Badan Persiapan Museum Kereta Api Nasional oleh karena itu menganggap sejarah perbaikan bengkel ini sebagai cerminan sejarah perkembangan kereta api Taiwan. [^9]

Hal ini juga menunjukkan "Jalur Menembus" tidak boleh berhenti pada 1908. Kehidupan kereta api tidak berakhir pada upacara pembukaan, melainkan berlanjut dalam setiap penggantian rel, perbaikan jembatan, pengalihan ke tenaga listrik, pemindahan bengkel, serta kehidupan sehari-hari penumpang pasca-perang yang menjadikannya jalur pulang kampung.

> 📝 **Catatan Kurator**: Satu jalur yang sama bisa mengangkut hasil pertanian ke pelabuhan, juga bisa mengantarkan orang yang merantau kerja pulang ke rumah; tujuan transportasi berubah, namun rel menyimpan kenangan siapa yang pernah dilayani, dan apa yang diprioritaskan.

## Tetap di Atas Rel: Dua Jenis Modernisasi

Hal paling patut diingat dari Jalur Kereta Api Menembus bukanlah kesimpulan terlalu menyederhanakan yang berbunyi "Jepang membangun Taiwan", melainkan pertanyaan: Siapa yang menentukan rute? Siapa yang membayar biaya? Siapa yang mendapatkan kecepatan? Siapa yang ditinggal di luar stasiun?

Jawabannya tidak hanya satu. Pemerintah kolonial menggunakan kereta api untuk meningkatkan efisiensi administrasi, militer, dan ekspor. Proyek teknik memasukkan tanah, industri, dan populasi ke dalam pengendalian yang lebih ketat. Jaringan yang sama juga menurunkan biaya transportasi di beberapa daerah, menghubungkan kembali produksi pertanian dengan pasar perkotaan. Hasil-hasil ini saling bertentangan, namun tetap bersamaan. [^6] [^8]

Hari ini menaiki Jalur Utama Barat, kota di luar jendela seolah telah menjauhkan era kolonial. Namun terowongan Jalur Gunung Lama, gazebo di tengah danau Taman Taichung, sisa-sisa Departemen Kereta Api di luar Pintu Utara, serta stasiun yang masih beroperasi, semuanya mengingatkan kita: modernisasi bukanlah sebuah tujuan akhir, melainkan lapisan-lapisan pilihan yang diletakkan di atas rel-rel lama.

Pada 1908, secara resmi merayakan penyambungan utara-selatan dengan nada "dalam satu nafas". Bagi generasi berikutnya, rel itu memang memudahkan pulau ini untuk saling menjangkau. Namun rel itu juga meninggalkan pertanyaan lain: ketika sebuah jalur menghubungkan semua tempat ke pasar yang sama, apakah daerah-daerah itu justru memperoleh kebebasan, atau hanya memperoleh kecepatan yang lebih cepat untuk diangkut pergi?
