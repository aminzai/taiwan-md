# Rel Kereta Api Industri Gula Taiwan

> **Ringkasan 30 detik:** Kereta lima persen bukan kereta kecil di depan pabrik gula untuk turis berfoto. Pada 1908, rel kereta api industri gula berlebar 762 milimeter mulai mengangkut tebu ke pabrik; pasca perang, ia pernah menjaring jaringan sepanjang 3.244 kilometer, lebih panjang dari Kereta Api Taiwan (TRA) saat itu, dan mengangkut pelajar, hasil pertanian, surat, serta barang militer. Rute wisata yang tersisa hari ini, yang benar-benar dilestarikan bukanlah perjalanan dengan kecepatan sangat lambat, melainkan sebuah sistem kehidupan yang pernah menghubungkan ladang, pabrik, pelabuhan, dan kota kecil.

## Kereta Sapi Sudah Terlambat

Pada 1902, pabrik gula modern pertama Taiwan didirikan di Qiaotou (橋仔頭), Kaohsiung. Ia mampu memeras sekitar 660 ton tebu per hari. Volume produksi ini begitu besar hingga pengangkutan tebu dari ladang ke pabrik menggunakan kereta sapi sudah tidak cukup cepat. Pabrik gula tidak membutuhkan rel kereta api yang indah, melainkan sebuah metode transportasi yang mampu mengirimkan bahan baku secara stabil ke mesin pemeras sebelum tebu busuk.[^1]

Pada 1905, Yamamato Teijiro (山本悌二郎) dari Taiwan Sugar Co., Ltd. (臺糖株式會社) beserta insinyurnya mengunjungi Hawaii untuk mempelajari rel kereta api industri gula. Mereka pertama kali melihat rute berlebar 914 milimeter, namun karena terlalu mendekati lebar rel Kereta Api Taiwan, tidak cocok untuk kebutuhan pabrik gula skala kecil. Kemudian di Pulau Maui mereka menemukan rel sempit 762 milimeter, dan itulah standar yang dibawa pulang ke Taiwan.[^1]

762 milimeter kira-kira setengah dari lebar rel standar, sehingga "kereta lima persen" bukan sekadar julukan lucu, melainkan spesifikasi teknis yang menjadi bahasa sehari-hari. Ia lebih sempit dari Kereta Api Taiwan, dan mampu belok di antar bundaran ladang, tepi sungai, dan area pabrik; ukurannya yang kecil justru memungkinkannya menjangkau tempat yang tidak terjangkau rel besar.

Pada 5 April 1908, rel kereta api industri gula Pabrik Gula Qiaotou selesai dibangun, pertama-tama mengangkut tebu dan produk gula. Tahun yang sama, perusahaan gula mulai mengajukan izin operasi komersial. Pada 20 Mei 1909, rute Xinying ke Yanshui menjadi jalur komersial pertama. Kereta api gula dari alat pabrik, mulai berubah menjadi transportasi lokal.[^1]

> 📝 **Sudut Pandang Kurator:** Titik awal kereta api gula bukan "orang Taiwan suka naik kereta kecil", melainkan industri gula yang memaksa masalah transportasi pertanian yang terlalu lambat, menjadi infrastruktur publik.

## Dari Ladang Tebu ke Pelabuhan

Kereta api industri gula awalnya memiliki dua jenis tugas. Jalur bahan baku menjalar ke dalam ladang tebu, mengangkut tebu ke pabrik gula saat musim giling; jalur komersial menembus area dengan kepadatan penduduk dan produk yang relatif tinggi, dibuka untuk penumpang dan barang. Kemudian muncul jalur cadangan sejajar utara-selatan yang menghubungkan berbagai pabrik gula, sehingga kereta api gula tidak lagi sekadar "rel cabang pabrik untuk mil terakhir".[^4]

Pasca perang, fasilitas empat perusahaan gula Jepang diambil alih oleh Taiwan Sugar Corporation (台糖). Setelah Taiwan Sugar Corporation didirikan pada 1946, organisasi kereta api, gerbong, seragam, tarif, dan simbol kendaraan harus distandarkan kembali; ini bukan sekadar mengganti lokomotif, melainkan mengubah rel kereta api perusahaan yang terpecah menjadi sistem yang dikelola oleh satu perusahaan yang sama.[^1]

Awal masa Pemulihan (光復), total panjang rel kereta api gula di berbagai pabrik kira-kira 2.964,6 kilometer. Hingga 1952, total panjang meningkat menjadi 3.244 kilometer. Tahun yang sama, total panjang Kereta Api Taiwan adalah 1.685 kilometer. Dengan kata lain, sistem yang terlihat seperti kereta mainan ini, pernah menjaring rel lebih panjang dari kereta api nasional.[^1] [^7]

Angka mudah membuat orang lupa siapa yang dilayani. Jalur komersial kereta api gula mengangkut pelajar berangkat sekolah, petani mengangkut hasil panen; paketnya bisa berisi koran, susu, daging segar, ikan udang, hewan, hingga permata dan bir segar. Ia adalah jalur transportasi industri, sekaligus cara desa berangkat ke kota saat belum ada angkutan umum jalan raya.[^1]

Pada puncak angkutan penumpang 1957–1958, penumpang tahunan mencapai 23 juta orang.[^2] Di era ketika kereta cepat belum ada, dan jadwal bus jauh tidak sepadat hari ini, "kelambatan" kereta lima persen bukan suasana rekreasi, melainkan kecepatan satu-satunya yang memungkinkan banyak orang tiba tepat waktu di sekolah, pasar, atau tempat kerja.

Arsip Nasional menggambarkan: "Dalam pemandangan sehari-hari tengah dan selatan Taiwan pada 1960-an, baik di kota maupun pedesaan, tidak pernah absen kereta lima persen yang mengangkut tebu."[^1] Poin kalimat itu bukan nostalgia, melainkan "tidak pernah absen": kereta api gula pernah menjadi infrastruktur kehidupan lokal, seperti saliran air, kabel listrik, dan pasar, begitu biasa hingga tidak perlu dijelaskan khusus.

## Sebuah Jalur Nasional yang Dibangun untuk Gula

Awal 1950-an, pemerintah berharap menghubungkan rel kereta api pabrik gula menjadi jalur cadangan sejajar utara-selatan. Ada pertimbangan pertahanan, juga kegunaan logistik yang sangat praktis: gula bisa diangkut sendiri ke pelabuhan, batu bara, kapur, pupuk, bibit tebu, dan ampas tebu lalu dialokasikan antar pabrik gula. Setelah Jembatan Xiluo (西螺大橋) diresmikan 1953 dan dilengkapi rel kereta api gula, angkutan penumpang dan barang di kedua sisi Sungai Zhuoshui (濁水溪) pun memiliki jalur baru.[^1]

Kereta api gula dan Kereta Api Taiwan bukan dua sistem terpisah tanpa kaitan. Gula pasir diangkut kereta api gula ke gudang di samping Kereta Api Taiwan, lalu dialihkan ke Pelabuhan Keelung atau Pelabuhan Kaohsiung untuk diekspor. Pelabuhan, pasar, pabrik gula, dan ladang tebu, terhubung lewat alih muatan, bukan lewat satu rel kereta api tunggal.[^1]

Ini juga menjelaskan mengapa kereta api gula tidak bisa hanya ditulis sebagai "peninggalan industri era kolonial Jepang". Ia memang didirikan di bawah kolonialisme Jepang, namun pasca perang Taiwan Sugar Corporation menyatukan standar, memperluas jaringan, dan menjadikannya melayani ekspor nasional serta transportasi pedesaan. Sejarahnya bukan garis tunggal warisan kolonial, melainkan rezim berbeda, perusahaan, dan kehidupan lokal yang bergantian memegang rel yang sama.

Jalur Budaya Industri Gula Kementerian Kebudayaan memasukkan enam aspek — pertanian, teknologi produksi, transportasi, administrasi, penelitian, dan kehidupan hunian — ke dalam satu kerangka, dari pabrik dan stasiun di Huwei (虎尾) dan Suantou (蒜頭) menjalar ke pemandangan lokal. Hanya melestarikan satu pabrik, akan tak terlihat bagaimana industri ini mengorganisir lahan dan populasi.[^9] Nilai sebuah rel kereta api, seringkali tidak ada di rel itu sendiri, melainkan di orang-orang yang pernah dibawanya ke tempat-tempat mana.

> 📝 **Sudut Pandang Kurator:** Nama "kereta lima persen" memampatkannya jadi mainan; kereta api gula yang sebenarnya pernah menjadi jaringan skala nasional. Tempat paling mudah dilupakan, justru karena ia pernah terlalu sehari-hari.

## Jalan Raya Datang, Industri Gula Mundur

Mulai 1960-an, angkutan umum jalan raya dan truk bertahap menggantikan angkutan penumpang dan barang kereta api gula. Catatan Arsip Nasional mencatat, jalur Houjia (后甲) Pabrik Gula Taichung pernah rugi lebih dari delapan ratus ribu per tahun. Pasca 1970-an, jalur komersial menyusut tiap tahun, 1982 jalur Chiayi (嘉義) Pabrik Gula Beigang (北港) berhenti beroperasi, menutup 74 tahun sejarah jalur komersial.[^1]

Titik balik ini tidak bisa hanya disebut "kereta kalah dari mobil". Alasan keberadaan kereta api gula adalah industri gula: selama ladang tebu, pabrik gula, dan ekspor masih membentuk sistem yang menguntungkan, kereta lambat pun memiliki cukup muatan. Saat impor gula dan transformasi industri membuat usaha gula inti surut, rel kereta api bersamaan kehilangan sumber muatan, pendapatan, dan alasan pemeliharaan.[^3]

1990-an masih ada kereta api gula beroperasi, namun sistem sudah memasuki fase penutupan cepat. _Taipei Times_ merangkum sejarah kereta api gula dengan menyebut, kereta api gula pernah memiliki lebih dari 600 kilometer jalur komersial, menghubungkan permukiman kecil yang tidak dijangkau Kereta Api Taiwan ke kota-kota lebih besar; hingga 1990-an, jaringan ini sudah memasuki fase penyusutan cepat.[^7]

Ahli Inggris Dafydd Fell mulai memfoto kereta api gula Taiwan 1994, kemudian bekerja sama dengan peneliti Institut Penelitian Taiwan Sugar Corporation Wang Xiang (王翔), mengumpulkan foto 1990-an dan wawancara pekerja pensiun menjadi buku. Titik waktu ini penting: kereta api gula tidak ditemukan setelah hilang, melainkan dicatat saat masih ada kereta, masih ada pekerja, tapi sudah tahu sistem tidak akan bertahan lama.[^6] [^8]

_Taipei Times_ mencatat kereta api gula 1990-an dengan menyebut, kereta api gula pernah mengangkut batu split membantu pembangunan Jalan Tol Nasional Nomor 1 (中山高速公路); pada akhirnya, rel kereta api yang membantu sistem jalan raya terbentuk, justru dilumpuhkan oleh sistem jalan raya.[^8] Ini bukan cerita sederhana "teknologi tua kalah dari teknologi baru", melainkan paradoks sebuah infrastruktur yang setelah menyelesaikan tugasnya, ikut membesarkan penggantinya sendiri.

## Yang Dilestarikan Bukan Perjalanan Lambat

Taiwan Sugar Corporation kemudian mengubah sebagian rute menjadi kereta lima persen wisata. Pabrik Gula Qiaotou (橋頭糖廠) 2003 membuka rute wisata sekitar 1,5 kilometer; rute Pabrik Gula Suantou (蒜頭糖廠) 2022 diperpanjang ke Stasiun HSR Chiayi (高鐵嘉義站), 2023 diperpanjang lagi ke Museum Nasional Cabang Selatan (故宮南院). Kereta api gula paling lambat dengan demikian menyambung ke HSR tercepat, dan ke museum tingkat nasional.[^5] [^11]

Transformasi ini punya daya tariknya: selama gerbong dicat ulang, ditanami bunga, ditambah pandu, kereta api gula jadi "pengalaman nostalgia" yang mudah dikonsumsi. Tapi aset budaya bukan mengubah barang lama jadi latar foto baru. Rute wisata modern Taiwan Sugar Corporation karenanya harus menangani tiga hal sekaligus: memastikan kereta beroperasi aman, memahami bagi penumpang bagaimana industri gula mengubah daerah, dan memastikan stasiun, gerbong, dan teknis pemeliharaan asli tidak dilandskapkan hingga hanya tersisa kulit luar.[^12] Gerbong penumpang asli, rem, pengemudi, dan teknis pemeliharaan, semuanya butuh orang yang memahami, orang yang mengoperasikan, agar bukan hanya penampilan yang tersisa.[^2]

Pekerja aset budaya Taiwan Sugar Corporation pernah berkata: "Tidak boleh hanya mempertimbangkan uang, manfaat, yang penting adalah membiarkan industri terus hidup."[^2] Kalimat itu juga membuka kesulitan pelestarian: kawasan wisata butuh pendapatan, pelestarian rel belum tentu bisa dibayar dari tiket; jika hanya mengejar jumlah wisatawan, konteks industri jadi latar belakang, jika sama sekali tidak dipakai, teknis dan kenangan justru putus dalam penyimpanan.

Jalur Hijau Nasional Kereta Api Gula yang ditetapkan 2021, memilih segmen sejarah di Changhua (彰化) dan Tainan (臺南), menghubungkan kembali rel, pabrik gula, pemandangan pedesaan, dan jalur sepeda. Segmen Tainan direncanakan dari Pabrik Gula Annei (岸內糖廠) ke Xinying (新營), lalu ke Pabrik Gula Wushulin (烏樹林糖廠). Segmen Changhua berpusat di sekitar Pabrik Gula Xihu (溪湖糖廠).[^10]

Pada interpelasi Legislatif 2025, Ketua Direksi Taiwan Sugar Corporation menjawab saat ini kereta api gula yang beroperasi kira-kira 30 kilometer; isu interpelasi juga menyebut, segmen terkait yang disimpan Tainan kira-kira 132,5 kilometer, tapi yang benar-benar memulihkan penampilan sejarah kereta lima persen dan dikembangkan kira-kira 8,6 kilometer. Angka ini berasal dari interpelasi anggaran saat itu, bukan survei menyeluruh seluruh peninggalan Taiwan, namun jelas menggambarkan kesenjangan pelestarian: menyimpan rel, tidak sama dengan menyimpan kereta api.[^13]

Kereta api gula mulai diperkenalkan di kancah internasional sebagai warisan industri, tapi ujian sebenarnya tetap di Taiwan lokal: apakah ia bisa kembali menjadi bagian dari mobilitas lokal, pendidikan lokal, dan kenangan lokal, bukan hanya satu titik di daftar perjalanan wisatawan?

> 📝 **Sudut Pandang Kurator:** Melestarikan kereta api gula, bukan membekukan masa lalu jadi satu kereta indah, melainkan mengakui sebuah rel kereta api harus dipakai, ditafsirkan, dipelihara, barulah ia terus menjadi rel kereta api.

## Rel Masih Ada, Soal Berubah

Hari ini naik kereta lima persen, kecepatan kira-kira 10 kilometer per jam; di dalam ada pandu, AC, dan gerbong ramah disabilitas, wisatawan bisa dari stasiun HSR masuk ke ladang, lalu tiba di pabrik gula atau Museum Nasional Cabang Selatan. Ini pengalaman transportasi baru, juga penataan ulang rute lama.[^11] [^12]

Ia tidak mungkin memulihkan sepenuhnya kereta api gula 1950-an. Era itu butuh tebu, gula, pelajar, dan surat yang sudah tidak di posisi asal; memasang kembali semua rel lama, juga tidak akan otomatis mengembalikan kehidupan dulu. Pelestarian yang sebenarnya harus menjawab, apakah hari ini masih bisa membiarkan orang melihat "bagaimana industri gula membentuk daerah", bukan hanya melihat sebuah lokomotif.

Jadi, yang paling patut diingat dari kereta lima persen bukan ia jalan lambat, melainkan ia pernah jalan cukup luas: dari ladang ke pabrik, dari pabrik ke pelabuhan, dari kota kecil ke sekolah, lalu dari rel industri jadi jalur budaya. Ia pernah lebih panjang dari Kereta Api Taiwan, kemudian hanya tersisa beberapa rute; proses penyusutan ini, tepat meninggalkan jejak transformasi Taiwan dari negara ekspor gula menuju ekonomi jalan raya, urban, dan teknologi tinggi, di atas satu rel lebar 762 milimeter.
