> **30秒概覧：** 1908年、打狗港で第一期建設が始まりました。そして1970年には高雄港の最初のコンテナターミナルが完成しました。その間に挟まれたのは、自然に起こった年々の羅列ではなく、鉄道、製糖工場、バナナ、税関、倉庫、工場、軍事、そして都市住民がお互いに引き合った時間です。高雄港は南台湾の産物を世界により速く届けた一方で、港湾周辺の土地を何度も再命名させました。蓬萊路を歩くと、レンガ造りの港史館と空になったバナナ棚が今も私たちに問いかけています。港の歴史は、決して船や物資だけのものではないのです[^1]。

## 小さな入り口を持つ港

19世紀の記録において、打狗港は元来、大型船舶に適した良港ではありませんでした。国家公文書館が整理した南北両港の史料によれば、ここは季節的な烏魚（うお）漁や風除けに使われた小規模な漁港として記述されています。入り口には巨石があり、水路は狭く、港内にも浅瀬や堆積の問題がありました[^1]。地方史の研究では、今日の塩埕（シエンティン）一帯がかつて塩田であったこと、旗津（チージン）、哨船頭（シャオチュアンタオ）や湾岸の生活は、近代的な港湾平面図によってあらかじめ決定されたのではなく、漁業、塩干し、小規模な交易によって構成されていたことが補足されています[^4]。

1860年、清朝が戦敗後に打狗などの港を開放して通商を再開すると、砂糖は外国商人が南台湾に注目した重要な輸出品となりました。イギリスは1864年に打狗に副領事館を設置しましたが、それは港が成熟していたからではなく、商人たちがそこにもっと整備される可能性を見出していたからです[^4]。この差異は保持されるべき点です。港の価値は自然条件だけで決まるのではなく、商人、政府、そして未来への賭けをする技術者によっても決定されるのです。

高雄港は後に「台湾初の最大港」として語られることが多くなりましたが、初期の景観を遡って見ると、この結末は当然のものではありませんでした。湾はまず測量され、浚渫（しゅんせつ）され、埋め立てられなければならず、その後鉄道や倉庫と接続される必要がありました。一つ一つの工事業務が、元々の海域、塩田、養殖場、集落を新しい公共的または産業的な空間へと変貌させました。港は海辺で物資を待っているのではなく、制度と工学によって作り出された都市の器官だったのです。

## 鉄道が港を輸出機械に変える

日本統治時代に台湾では、製糖業が植民地経済の重要な柱となりました。問題はすぐに生じました。南台湾の砂糖をどうやって日本へ運ぶのか？もしすべての物資が基隆（キールン）を経由して輸出されるのであれば、時間的にもコスト的にも合理的ではありませんでした。地方史の文献には、1900年頃に総督府が打狗港を調査し、縦貫鉄道の南端と港を結びつけることを解決策として見出した記録があります。1904年から1907年にかけて、埋め立てと鉄道延長が同時に湾岸のスケールを変えていきました[^4]。

1908年、縦貫鉄道全線が開通し、同年、打狗建設計画が開始されました。国家公文書館の整理によれば、第一期建設は1908年から1912年にかけて近代的な高雄港の基礎を築き、鉄道、港湾、米糖輸出という新たな連携関係を生み出しました[^1]。ここでの「連携」は抽象的な名詞ではありません。畑の甘蔗、工場の砂糖、火車上の貨車と埠頭での荷役労働者は、それから一つのスケジュールの中に組み込まれていったのです。

埋め立てもまた都市の居住秩序を変えました。地方史資料では、ハマー星が濱線（ピンシエン）からの日本語読みとして言及され、沿岸鉄道と新興地の関係を示しています。新市街には棋盤状の通り、電力、街灯、下水、公共市場があり、これは日本人による行政活動と商業活動の中心地となりました[^4]。しかし、近代化という光は均等に降り注いだわけではありませんでした。日本人はより多くの政治的・経済的資源を掌握しており、澎湖（ポンフー）や台南沿岸からの移民は主に労働に従事しました。港湾は人口を引きつけましたが、異なる集団を不平等な空間に配置したのです。

| 工事または制度       | 港が獲得した能力                   | 再編された生活                                     |
| -------------------- | ---------------------------------- | -------------------------------------------------- |
| 縦貫鉄道と臨港線     | 砂糖、米、日用品の迅速な埠頭到着   | 物資のルートが旧集落や海岸を通過する               |
| 第一期建設           | 水路の浚渫、船舶出入りの改善       | 海域、塩田、新興地の境界が再画定される             |
| 港務・税関署         | 物資に課税、検査、管理が可能になる | 港湾が国家制度の前線となる                         |
| ハマー星などの新市街 | 商業、行政、交通の集中             | 異なる移民層が資源と職業によって階層化して居住する |

これは、高雄港の物語を単に「日本人が建設し、台湾が近代化した」と書くことができない理由を説明しています。建設は確かに輸送効率をもたらしましたが、同時に土地、労働、意思決定権を新しい港湾市というメカニズムに集中させました。港湾が拡大するにつれて、誰が埠頭に近づけるのか、誰が岸辺で働けるのか、誰の家が新市街に含まれるのか、これらすべてが近代化の一部だったのです。

## レンガ造りの港史館における税と海

蓬萊商港地区の3番埠頭の隣にある高雄港史館は、2階建てのレンガ造りの建物です。高雄市の文化財網によれば、この建物は1916年に創建され、1917年に完成しました。当初は台湾総督府財務局が打狗港に派遣された、砂糖消費税を徴収する官吏の出張所でした。その後、税関、海事、港務など様々な機関を経て、1997年に改修されてから港史館として転用されました[^7] [^8]。国家文化財網は公告資料により、この建物が1916年12月に着工し、1917年に完成したこと、そして西洋古典様式を模したレンガ造りの外観と歴史的建造物としての身分を確認しています[^10]。

この建物の最も興味深い点は、単にレンガやアーチ窓にあるのではなく、港の「見えない」作業を具体的な空間に固定した点です。船が到着する前から、物資の価値は登録され、分類され、評価され、課税される必要がありました。砂糖は産地から海上に直接消えるのではなく、港で国家機関によって再定義されたのです。港史館がかつて官署であったことは、港湾の近代化がクレーンや埠頭だけではなく、帳簿、印鑑、税率、そして人間の判断にも依存していたことを示しています。

学術論文『高雄港港史館の歴史的変遷に関する研究』は、この建物の組織的な変遷をさらに整理しています。打狗出張所から、高雄税関、高雄海事出張所に続き、高雄港務局と合同検査センターへと機能が港湾制度の変化とともに移行していきました[^3]。もしこれを単に「日治時代の古民家」として捉えてしまえば、それがかつて担っていた海事、密輸、貿易行政の歴史を見落としてしまいます。レンガは装飾ではなく、港が流動的な海上活動を国家的な手続きとして固定した証拠なのです。

港史館は、「保存」という概念をも少々ロマンチックではないものにしました。高雄市の文化財網には、この建物が1994年に一度解体計画の危機に瀕したが、その歴史的意義と文化的価値から保存、修復、再利用された記録があります[^7] [^8]。一つの建物が残るかどうかは、単に古くあるかどうかにかかっているわけではありません。それは、都市が税務、海事、港務といった写真映えしにくい作業も高雄の歴史の一部として認めようとする意志にかかっているのです。

## バナナが農村を埠頭へ運んだ

戦後の高雄港で最も記憶に残る物資の一つがバナナです。国家公文書館の『バナナの日系輸出と台湾経済』によれば、1930年代にはバナナは米や砂糖と並ぶ台湾三大輸出品となっていました。戦後初期、台蕉（タイチャオ）は大量に中国大陸へ輸出されましたが、1949年頃に情勢が変化し、政府と民間が日本市場への輸出をより積極的に検討するようになりました[^11]。この転換は単なる市場選択ではなく、両岸間の交通、貿易制度、そして日本の輸入政策の影響も受けていました。

バナナの日本への輸出に真に必要だったのは、品質の安定した果実を生み出す農家だけではありませんでした。公文書には、青果協同組合と輸出協会が輸送比率を巡って競争していた記録があります。バナナが日照や雨にさらされるのを避けるため、業者は車両に防水布を取り付け、政府も冷蔵設備、鉄道支線、竹籠や紙箱の規格などの問題に対処しました[^11]。一つのバナナが畑から日本市場へ至るには、収穫、選別、包装、鉄道輸送、冷蔵、埠頭での積み下ろし、そして船便という一連のプロセスを通過しなければなりませんでした。港はそれゆえ産地の終点ではなく、農業が国際市場によって規格化された場所だったのです。

高雄港3番埠頭のバナナ棚は、このチェーン（連鎖）が残した建築物です。国家文化財網によれば、1950年代末にはバナナの生産量と輸出量は日治時代を上回りましたが、元の露天での保管ではバナナが日照や雨にさらされる危険がありました。1962年に着工し、1963年に完成したバナナ棚は開放型設計を採用し、換気を利用して保管を改善し、機械輸送設備を設置することで最大23,300籠を収容できました[^2]。それは広々とした倉庫のように見えますが、実際には農産物輸出制度の具現化でした。

| バナナが港に到着する前と後 | 必要な技術                   | 誰によって達成されたか           |
| -------------------------- | ---------------------------- | -------------------------------- |
| 産地での収穫と選別         | 成熟度と外観の管理           | 農家、生産販売組織、検査員       |
| 陸上および鉄道輸送         | 衝突、日照、雨を避けること   | 運搬人、鉄道業者、輸送業者       |
| バナナ棚での一時保管       | 換気、積み重ね、埠頭との接続 | 港務局と埠頭労働者               |
| 日本への輸出               | 包装規格、貿易割当、船便     | 政府、協同組合、輸出商、海運会社 |

バナナの繁栄にも期限はありました。国家公文書館によれば、1952年に日本の貿易自由化が進むと、他の生産国が日本市場に参入し、台湾産バナナの優位性は徐々に縮小しました。引用された統計によると、台蕉の最盛期には年間40万トン以上を輸出し日本市場の82%を占めていましたが、2014年にはわずか約4,000トン、1%にまで減少しています[^9]。これらの数字は高雄港という単一ターミナルの取扱量に置き換えられるものではありませんが、一つのことを明確に示しています。輸出港が最も恐れるのは歴史がないことではなく、世界市場の変化によって、既存の輸送、品種、制度が場所を失ってしまうことです。

バナナ棚が文化財として登録された理由は、単に「台湾がかつてバナナをよく輸出した」という事実だけではありません。それは、農業時代がいかに港湾、鉄道、倉庫に頼って組織化されていたかを保存しているからです。コンテナ化と産業構造の変化によりバナナ棚が徐々に遊休化するにつれて、この建物は後世に一つの問いを残しました。輸出を加速するために設計された空間は、その輸出モデルが消えた後も理解されることができるのでしょうか、それとも単なるノスタルジックな背景として消費されてしまうだけなのでしょうか？

## コンテナターミナルから港湾市への分離

戦後の高雄港の二度目の大きな変化は、1958年から始まった12年間の拡張工事によるものです。国家公文書館によれば、この工事は1970年に完了し、水路の浚渫、新土地の埋め立て、埠頭および浅水岸壁の建設が含まれていました。埋め立てられた新土地は約544ヘクタールで、工業用地や後の港湾市に空間を提供しました[^1] [^5]。これは単に港を「大きくした」のではなく、高雄の都市スケールを海岸線と工業地区へと押し出した行為でした。

1970年に高雄港の最初のコンテナターミナルが完成し、台湾は正式にコンテナ輸送の新段階に入りました[^1] [^5]。コンテナの効率性は物資の標準化、転換、国際的な配船を容易にし、旧式のバラ積み倉庫や埠頭作業が徐々に中心的な位置を失わせました。港湾自体にとっては競争力でしたが、旧港湾地区にとっては別の種類の緩やかな退場でした。かつて大量の労働者、鉄道、臨港倉庫を必要としていた作業は、新しい設備、深水埠頭、より広い腹地によって再配置されたのです。

高雄港は1982年には世界第5位のコンテナ港にランクインし、1993年にはロッテルダムを追い抜き世界第3位のコンテナ港となりました。これらの業績は国家公文書に明確な時間軸で記されています[^1]。しかし、これらのランキングをもって港湾市の亀裂を覆い隠すべきではありません。より効率的な港ほど、真の作業エリアを市民の日常から遠ざけがちです。より安全と規制が必要な埠頭ほど、沿岸住民は海を見ることができますが、港の中には入れないという状況になりがちです。

そのため、1990年代以降の高雄港の変遷は、単なる観光開発ではなく、高雄が「港と都市は同じ海岸を共有すべきか」という問いに再挑戦しようとした試みなのです[^10] [^11]。駁二（ボージ）、棧庫群（ジャンクーチュン）、ハマー星鉄道文化園区、そして港史館は、それぞれ異なるレベルの記憶を保存しています。倉庫は物資の体積を、鉄道は移動の方向性を、紅楼（ホンロウ）は国家機関の手続きを、そして岸辺はかつて城壁で隔てられていた都市の視線を保存しているのです。

## 旧港湾地区が自動的に文化地区になるわけではない

高雄市政府都市開発局は2025年の報道発表で、塩埕蓬萊旧港湾地区の変遷を振り返り、1998年の「海洋首都」構想、2005年の港湾壁の解体、2011年の亞灣（ヤーワン）建設、そしてその後の駁二、大港橋、倉庫群の開発を結びつけています[^6]。この資料では、市府がバナナ埠頭をスマート高雄灯台計画の研究開発拠点として計画し、テクノロジー、人文、文化創造観光によって旧港湾地区を再構築していることも言及されています。

これらの内容は「計画」というニュアンスを保持する必要があります。バナナ棚の文化財ページでは、この建物が2024年2月下旬に台湾港務株式会社高雄港務支社によって管理権を取り戻され、閉館計画中であり、見学不可と記されています[^2]。したがって、ウェブ観光ページに書かれている無料入場や宴会レストラン、バナナ物語館を現在の状況としてそのまま受け取ることはできません。港湾地区の変遷は、単に新しい看板を掲げるだけではなく、建物の管理、開放、修復、利用権が現実的な問題なのです。

一方、港史館はより安定した事例を提供しています。それは官署から港史を展示する施設へと変わり、公式文化財資料には依然として開館時間と管理単位が記載されています[^10]。しかし、展示が港務職員、埠頭労働者、税関、移民の生活を人々に理解させられるかどうかは、展示物の選び方にかかっています。もし港湾ランキング、船舶模型、都市のスカイラインだけを展示するなら、港史は再び「成功した高雄」という枠に収まってしまうでしょう。砂糖税、バナナの包装、臨港鉄道、戦時爆撃、戦後復興をまとめて提示できれば、観客は港が実際には人々と物事を分離し、分類し、加速させるためのシステムであったことを見出すはずです。

## 港は誰を世界に連れてきたのか

高雄港の物語は、南台湾の小漁港から国際港へと飛躍した話として語られることがありますが、それは不十分です。小漁港が国際港になったのは、政府の投資、植民地時代の工学、砂糖とバナナの市場、鉄道と埠頭労働者の労働力のおかげでした。同時に、埋め立て、徴税、軍事化、移民の階層化、港湾規制も伴いました。船が港から出ていく姿だけを見ていると、土地がどのように港建設に使われたのか、そして人々がいかにして物資チェーンの異なる位置に配置されたのかが見えてきません。

1908年の建設は打狗を縦貫鉄道に接続させ、1958年の拡張は高雄により大きな工業腹地をもたらし、1970年のコンテナターミナルは都市をグローバルロジスティクスへと押し上げました。これら三つの時点は、互いに無関係な建設ではなく、「流通を速くする」という思考が段階的に加速していった過程です。高雄港の近代性は「速度」の上に築かれています。砂糖はより早く船に積み込まれ、バナナはより早く冷蔵され、コンテナはより迅速に転換され、工業原料はより速く出入りする必要があったのです。

しかし、都市の記憶は必ずしも速度によって保存されるものではありません。それは港史館の一つのレンガ造りのアーチ窓の税務記録の中に、バナナ棚が元々23,300籠のバナナのために設計されていた開放的な階層の中に、そして濱線から来た方言名であるハマー星の中に隠されています。これらの残された物証は、高雄に単に「港がいかに強大であったか」を示すだけでなく、「港が効率を追求するあらゆる時代において、誰の労働が計算に入れられたのか、誰の生活が排除されたのか、そして今日、この海岸線を解釈する権利を再び獲得したのは誰なのか？」という問いを投げかけています。

したがって、高雄港を歩くことは「どこが一番写真映えするか」から始めるべきではありません。3番埠頭のレンガ造りの建物から始め、砂糖消費税がどのように記録されたかを想像してみる。次にバナナ棚を見て、農産物の輸出にどれほどの写真には写らない工程が必要だったかを理解する。最後にハマー星と旧港湾地区を辿り、鉄道、倉庫、城壁、そして新しい文化空間が互いにどのように重なり合っているか観察する。港は都市の背景ではなく、都市が未来を配置するために用いた一つの方法であり、何世代にもわたる労働者が身体的な記憶を残した場所なのです。

今日の高雄港は依然として世界と繋がっていますが、すべての古い倉庫が貨物を運び続ける必要はありません。真に重要な保存とは、港湾地区を復古風景の一枚の写真として凍結させることではなく、これらの建物がなぜ出現したのか、誰がそこで働いたのか、どのような制度によって繁栄し、そしてなぜ次の技術革新で元の場所を失ったのかを知ってもらうことです。ある港が自らの税務、労働、戦争、移民、産業衰退すべてを歴史の中に含めることを望むとき、それは単に台湾を世界へ送り出すだけでなく、世界に「海岸上でいかにして台湾という自己を形成したか」を理解させ始めるのです。

## 港のスケールはどのように測定されたのか

高雄港の空間を単に「旧港湾地区」と「新港湾地区」で二分することはできません。水路、埠頭、鉄道、倉庫から市街地に至るまで、港は実際には相互依存しているが、必ずしも同時に見えないスケール群です。第一港とコンテナターミナルの航空写真は、水域、ヤード（物資置き場）、道路と都市との距離を示しています。しかし、空撮にも盲点があります。それは腹地は見えますが、荷役労働者が地面で時間をどのように配分しているか、規制線が誰を埠頭に入れるかをどう決定しているかは見えないのです。

| 観察スケール | 見ることができること                               | 見過ごされがちなこと                                                 |
| ------------ | -------------------------------------------------- | -------------------------------------------------------------------- |
| 水路と港池   | 船舶の出入り、浚渫と防波堤が形成する工学的スケール | 水深を維持するには継続的な投入が必要であり、一度きりの建設ではない   |
| 埠頭とヤード | コンテナ、バナナ棚、倉庫、転換設備の配置           | 物資が規格化された後、一部の伝統的な運搬作業は設備に置き換えられる   |
| 臨港鉄道     | 港駅、信号機、支線と工業腹地の接続                 | 鉄道が残した空間は、必ずしも元の輸送機能が続いていることを意味しない |
| 都市岸線     | 旧港湾地区、文化施設、住民が海岸を眺める経路       | 開放的な観光と港務の安全の間には依然として管理上の境界線が存在する   |

その中で、信号楼、鉄道、港駅は単なる鉄道マニアの遺跡ではありません。それらは物資がどのように通行を許されたか、列車が船のスケジュールにどう接続したか、そして港務職員がいかにして見えない手続きの中で秩序を維持したかを記録しています。臨港線が元の輸送量を担わなくなったとき、保存作業の難しさは「一つの建物を残すこと」から「すでに機能停止したシステムをいかに解釈するか」へと変わりました。この解釈が単なる撮影スポットだけになってしまうと、労働は再び港史から消されてしまいます。

## 補足資料：港がいかに都市の働き方を変えたか

高雄港の歴史をいくつかの物証に分解することで、それがどのように都市を変えたのかをより明確に見ることができます。最初の物証は鉄道です。それは製糖工場、農産物の集積地、埠頭を一つのスケジュールに結びつけ、輸出が近岸の小舟だけに頼ることをやめさせました。二番目の物証はバナナ棚です。それは単なる倉庫ではなく、日照、衝突、包装、船積み時間を制御する仲介空間でした。三番目の物証は港史館です。それは港務機関が残した制度的記憶を、市民が入って見たり議論したりできる公共建築へと変えたのです[^2][^3][^7][^8][^9]。

| 資料対象             | それが答える問い                                                       | 読む際に保持すべき制約                                                                              |
| -------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 建設公文書           | 港はいつ小漁港から近代的な工学システムになったのか？                   | 公式文書は工学と行政に偏重しており、労働者の声は少ない[^1][^5]                                      |
| バナナ棚とバナナ輸出 | 農産物はどのように選別され、包装され、海外市場に接続されたのか？       | 輸出のピークがすべての農民や運搬業者が平等に利益を得たことを意味するわけではない[^2][^9]            |
| 港史館と文化財資料   | 港務機関はどのように都市の記憶として保存されたのか？                   | 建物の保存は、元の機能が完全に復元されることと同義ではない[^3][^7][^8]                              |
| 旧港湾地区の再利用   | 港が一部の貨物輸送機能を手放した後、都市はいかに岸辺を再利用したのか？ | 新しい文化やテクノロジーの用途は、依然として港務安全、産業記憶、住民の使用権に直面している[^6][^11] |

この一連の資料は、「高雄港は大きい」という一枚の写真で港史を代用できないことを示しています。港のスケールは、法規、税務、鉄道の運行スケジュール、物資規格、そして労働分業によって共同で作り出されたものです。そのうちの一つが変化すると、他の空間も再配置されます。今日のバナナ埠頭、港史館、港駅の遺構が保存される価値があるのは、それらが元の生産能力を維持しているからではなく、それらが「誰のための物資のために都市は拡張したのか」「誰の労働を歴史の影に残したのか」という問いを投げかけてくれるからです。
