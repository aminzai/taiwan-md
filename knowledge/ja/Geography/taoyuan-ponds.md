# 桃園の池塘：台地がいかにして雨水を生活に変えたか

> **30秒概要：** 桃園の池塘は、安定した河川水源が乏しい台地で人々が耕作を行うため、地形に沿って池を掘り、堤防を築き、水路をつなげて形成された分散型貯水システムです。かつて約8,846口もあったものが、桃園大圳、石門水庫、農地の再編、都市開発によって大量に減少しました。今日の池塘は農業時代を記憶するだけでなく、灌漑の調整、生態教育、防災、レクリエーション、そして地域アイデンティティの間で新たな生命を模索しています[^1] [^2] [^3]。

## 池塘は数多くあるのではなく、分散型の貯水システムである

桃園市街地から南や西へ進むと、池塘はしばしば樹木の影、堤防の一部、あるいは囲まれた水面として現れます。これを単に公園の湖と見なしてしまうと、最も重要な側面を見落としてしまいます。それは、元々農地の貯水施設であり、大規模なダムではなく、多くの小型貯水ユニットが連携し合っている点です。

桃園台地は古石門沖積扇（ちゅうせきせん）であり、地面は東南から西北へ緩やかに傾斜しています。この勾配のおかげで、より高い場所にある池の水が下流へと流れることができました。紅土や黄土は粘性が高いため、池を掘り堤防を築いた後も水を保持しやすい性質があります。一方で、台地の渓流は短く急峻であり、降雨時には急激に増水し、無雨時には水不足となり、年間を通じて信頼できる灌漑水源となることは困難でした[^1]。

桃園管理局は、この地理的条件と人為的な工学が織りなす景観を「千塘の郷」と呼んでいます。この名前の重要性は単なる数ではなく、水面、土堤、田畑区画、水路、そして集落が共同で一つの生活スケールを構成している点にあります。水は遠くにある公共事業ではなく、農家が日々配分し、待ち、維持管理する身近な資源だったのです[^2]。

| 条件                         | 池塘形成への影響                           | 生活上の結果                       |
| :--------------------------- | :----------------------------------------- | :--------------------------------- |
| 古石門沖積扇の緩斜面         | 上流から下流へと水路を繋ぐ条件が形成された | 池塘は標高によって連動可能である   |
| 紅土、黄土の粘性土壌         | 浸透を防ぎ、池の建設に適している           | 小規模な掘削でも水を貯留できる     |
| 短く急峻な渓流と季節的な降雨 | 河川の水供給が不安定であった               | 台地内に雨水を保持する必要があった |
| 水田耕作の需要               | 水不足時に補給が必要であった               | 池塘は農業生産の基盤となった       |

## 断頭河が残した水不足への答え

桃園の池塘の物語は、「先民の勤勉さ」からだけを語ることはできません。より深い原因は、水系そのものが変化したことにあります。淡水川流域での遡源侵食（そげんしんしょく）により、古石門沖積扇の一部の渓流は本来の上流を失い、水利史で言われる「断頭河」を形成しました。渓流自体は存在しても、広大な農地に安定的に水を供給できなくなったのです。

そこで開拓民たちは、信頼できない降雨を制御可能な多くの断片に分解しました。田畑の高い場所に池の本体を掘り、掘った土を堤防として積み上げました。雨が降れば径流（けいりゅう）を池に集め、干ばつ時には田畑に放水しました。この手法は大規模なダムほど高い技術的ハードルはありませんでしたが、一つの池の水位が下流の別の池の収穫に影響するため、長期的な協働が必要でした。

農田水利署桃園管理局が地方史料を引用しているところによれば、1741年に霄里社（シャオリーしゃ）の頭目である知母六（ちぼろく）が佃農を開拓し、「霄裡大圳」と四つの池塘を掘削して、今日の八徳一帯の農地に水を貯水灌漑したと記されています。この記録は単なる「起源年」に単純化されるべきではありません。それは、水利、開墾、そして地域の社会がいかにして共に形成されていったかを見せてくれる、目に見える時間点のようなものです[^2]。

## 小さな池群から桃園大圳へ

桃園大圳が出現する前は、池塘の数は多くありましたが、水供給が必ずしも安定していたわけではありません。公的記録によれば、桃園台地には約8,846口の池塘が存在したとされています。また、日治初期の調査記録では、桃園廳（タオユエンチョン）の公共池塘と外来の水路を合わせて6,685箇所と報告されています。両方の数値は統計範囲や時点が異なるため、単純に足し合わせたり同一の普查（ふちゃ）として扱うことはできませんが、初期の水利施設がいかに分散していたかを示しています[^1] [^2]。

1913年の大干ばつにより、水不足の問題はさらに深刻化しました。日本の統治当局はその後、桃園大圳を推進し、1917年に着工しました。これは大嵙崁溪（タイカンケイ）――現在の大漢渓上流の石門一帯から水を引き、導水路、幹線、支線、分線を通じて桃園台地に水を運びました。1924年に導水と幹線が完成し、1925年に開通式が行われ、1928年に全体システムが完成しました[^2] [^3]。

桃園大圳はすべての池塘を置き換えたわけではありません。それはそれらの位置を再配置したのです。小さな池は統合されたり合併されたり廃止されたりし、水路はより安定した外来水源を池に運び、そこから池が配水を行いました。桃園管理局の時間軸によれば、2,326口の小規模な池塘が231口の比較的大きな池塘に統合されました。これは、「近代化」が単なる泥土からコンクリートへの線形的な進歩ではなく、分散したネットワークの再編成であったことを示しています[^3]。

## 水路が池塘を繋ぐ「見えない文章」

今日の桃園の池塘を理解するには、水面だけを見るのではなく、水路を読む必要があります。桃園大圳システムは主に石門水庫から水を供給しており、導水路は約18km、幹線は約25km、支線と分線が合計約141kmあり、これらは12の灌漑区に分けられています。これらの数字は、池塘が孤立した名所ではなく、巨大な管網の中の調整ノードであることを示しています[^3]。

| 水利階層         | 主な機能               | 想像できるもの     |
| :--------------- | :--------------------- | :----------------- |
| 水庫、河川取水口 | より安定した水源の提供 | システムの上流     |
| 導水路と幹線     | 長距離輸送             | 主幹動脈           |
| 支線、分線       | 各区への水の供給       | 分枝血管           |
| 池塘             | 一時貯留、調整、再配水 | 分散型貯水システム |
| 田間水路         | 作物の根元への水の送付 | ラストマイル       |

このシステムは、池塘の「小ささ」が重要でないことを説明しています。単一の池の容量は限られているかもしれませんが、多くの池が繋がることで、雨季に余った水を一時的に貯留し、乾季の灌漑を現在の降雨だけに頼る必要がなくなります。管理局の資料によれば、池間の連絡水路は石門水庫と農地との調整緩衝として機能し、さらには排水からの還流水も再利用されています[^1]。

## 石門水庫がもたらした転換点

1953年の大干ばつを契機に石門水庫の建設が進められました。1964年に水庫が完成すると、桃園大圳はより安定した水源を得て、石門大圳も段階的に整備されました。水利条件が改善し、農業生産は支えられました。しかし、同じ変化が多くの小規模な池塘の本来的な需要を低下させてしまったのです[^1] [^3]。

これが桃園の池塘において最も理解すべき歴史的転換点です。供給が近代化するほど、一部の古い水利施設は余分なものと見なされやすくなりました。農地の再編は田畑区画を直線化し、都市計画や空港、工業団地、道路などの建設が土地利用を変え、元々貯水灌漑に使われていた池塘は埋め立てられたり縮小されたり他の用途に転用されたりしました。水利システムの成功は、ある意味で、かつて不可欠であった仲介ノードを目立たなくさせてしまったのです[^1] [^2]。

したがって、池塘の消失を語る際には、「開発による破壊」だけで括ってしまうことはできません。そこには灌漑技術の高度化、農業構造の転換、土地価格の上昇、そして公共建設の需要といった要素が複合しています。真に困難な問題は、「池がもはや稲作のためだけに使われなくなったとき、私たちはそれを都市にとって代替不可能な価値があると言い切れるのか？」ということです。

## 一つの池塘は集落の記憶装置でもある

池塘の堤防は、巡水、汲水、放水、そして往来する道でした。池の周りには田畑、樹木、廟（みょう）、住居があり、水位の変化は日常に季節を書き込んでいました。桃園管理局の資料には、新福圳一号池と埤崙土地公（チーリントゥーディン）が記録されています。水利施設に隣接する信仰空間は、工学が単なる技術ではなく、地域の住民が願望、リスク、そして相互扶助を語る場であったことを示しています[^2]。

大溪灌漑区では、白石池（バイシーチ）、前慈湖（チェンツーフー）、後慈湖（ホウツーフー）、牛角湳池（ニウチャオナンチ）などの池塘が三層圳（サンツォンヂェン）、新福圳と組み合わさって、別の水利景観を形成しています。桃園管理局が整理した三層圳と新福圳のシステムを見ると、水は白石池から順に三層圳、龍過脈池（ロングオミャイチ）、慈湖、牛角南池へと流れています。もう一つの系統は、新福圳トンネル、南仔渓（ナンツァイケイ）と水路を経て新福圳池に到達します。これらの地名が繋がっていることは、水の流れによって書かれた地域の地図のようなものです[^3]。

客家委員会による池塘の調査研究は、桃園の池塘を歴史、文化、社会、生態、技術といった多面的な視点から捉え直し、保存とは単に水面を残すことではないと私たちに警鐘を鳴らしています。もし外観だけを残し、水路、使用記憶、地域の物語を見失ってしまえば、残るのは文脈のない景観標本になってしまうかもしれません[^5]。

## 灌漑施設から生態公園へ

池塘の公共性は水位からも読み取れます。それは永遠に固定された鏡面ではなく、灌漑の季節、降雨、排水、そして維持管理によって調整される作業場です。観光客にとっては水位の変化は単なる景色の違いかもしれません。しかし、管理者や近隣の農民にとっては、給水、放水、堤防の安全、下流の田畑が適切な時期に水を確保できるかどうかに直結しています。この差異は、池塘の再利用を岸辺の施設だけでは判断できず、水利運用のリズムも保持しなければならないことを教えてくれます。

## 生態公園への転換

池塘は現在、レクリエーション公園のような形で再登場することが多くあります。八徳池塘自然生態公園は約5平方キロメートルで、景観、休憩、生態教育の機能を兼ね備えています。これにより、住民は都市の中で水辺に再び触れることができ、池塘は「農業内部の施設」から公共環境の一部へと変化しました[^11]。

このような転換には価値がありますが、すべての池塘を同じ種類の公園に変えてしまうことだけは避けるべきです。灌漑用の池の水位、堤防、取水点、維持管理のニーズは、景観湖とは異なります。親水性を追求するあまり安全を無視したり、均一化のために岸辺を完全に護岸化してしまったりすると、かえって生態機能が損なわれる可能性があります。農田水利署の初期の維持管理記録には、堆積物、堤防の浸食、動物による掘削、取水ゲートの巡回といった管理上の現実的な問題が指摘されています[^1]。

工学的な観点から見ると、池塘の護岸にもある種の概念的転換が見られます。初期は主に土堤や乾積み石材が使われていましたが、次第にコンクリート格子が導入されました。2000年代初頭の記録には、空隙レンガ、植生袋、大きな石、プラットフォームといった生態工法の試行が見られます。これらの手法は、「工学」と「自然」を二者択一にするのではなく、安全、貯水、生息地の間で維持可能な妥協点を見つけ出そうとするものです[^1]。

## 保存とは池塘を凍結させることではない

一つの池が名前だけになってしまえば、保存は平面的な展示になってしまいます。逆に、取水点、堤頂道路、周辺の田畑区画、廟宇、そして住民の記憶を一つにまとめることができれば、池塘は本来のスケールを取り戻します。これにより、保存活動はロマンチックではないが重要な問題にも向き合わなければなりません。例えば、泥の処理はどうするか、護岸は補修すべきか、水質は誰が監視するのか、生態池の植物は灌漑水路に蔓延してしまうのではないか、そして公共開放と堤防の安全をいかに両立させるか、といった問題です。

桃園市では、自治条例を用いて池塘と水路の保存および新規利用の奨励を行っており、その政策目的には、特殊な人文景観の維持に加え、灌漑、景観、文化、レクリエーション、生態保全、防災といった機能を兼ね備えることが含まれています。この多機能的な言語が重要であるのは、池塘が農業時代に留まるのではなく、「継続的な灌漑」と「完全な観光化」のどちらかを選ぶ必要はない、という認識があるからです[^7]。

しかし、法規上の名称が保存の完了を意味するわけではありません。公視（GTV）の番組『私たちの島』では、桃園の池塘が都市開発に直面した選択が報道されています。一部の池塘は世界文化遺産の可能性を秘めていると見なされているにもかかわらず、文化景観として公示されていないために文化財法の完全な保護を受けられないケースがあります。中路（ヂンルー）の都市計画では、一部の池塘も埋め立てや縮小の危機に瀕しました[^9]。

住民の関与は、装飾的なガイドツアーではなく、「何を残す価値があるのか」を判断する核心的な作業です。国立政治大学機構典蔵の研究によれば、水利システムの健全性と産業構造の変化により、池塘は減少したり放棄されたり埋め立てられたりしており、それゆえに住民の池塘に対する認識と再利用の方向性を理解することが必要とされています[^10]。

## 今日真に保存すべきは「関係性」である

桃園の池塘が最も希望を見出せる未来の方向性は、一つ一つの池を観光名所としてパッケージ化することではなく、それらを再び一つの「関係性」の中に位置づけることです。どの池が灌漑機能を持っているのか、どれが生態系復元に適しているのか、どの水路が教育的な経路として利用できるのか、どの堤防に優先的に補強が必要なのか、そしてどの場所の物語を住民自身が語るべきなのか、という点です。

2024年、桃園管理局は「百年圳脈、世代継承」という専門書で桃園大圳と新福圳を取り上げ、デジタルファイル、歴史資料、高齢者へのインタビューを通じて水利記憶を保存しています。この資料では、池塘間の相互接続性、IoT（モノのインターネット）、AIモデルといった今後の方向性も言及されています[^3]。これは、水利文化が単なる郷愁によって維持されるのではなく、新しい管理ツールによって継承され得ることを示しています。

生態学的側面も、単点からネットワークへと移行する必要があります。林業及び自然保育署による近年の桃園の池塘に関する活動には、種保全基地の設置、希少な水生植物の復元、公的・私的部門の協力、公園での生態池展示などが含まれます。これらの行動は、池塘が水生植物と都市住民が共同で利用するグリーンネットワークのノードとなり得ることを示しています[^12]。

| 保存階層 | 単に何を保存するのか                         | 誰と協力する必要があるか         |
| :------- | :------------------------------------------- | :------------------------------- |
| 水体     | 水面と貯水容量                               | 農田水利管理者、工学チーム       |
| 水路     | 取水点、水路、標高                           | 水利部門、地方自治体             |

## 水を流し続けるために、物語を過去に留めてはならない

桃園の池塘が最も感動的であるのは、「水不足」という状況を集合的な空間知恵へと転換させた点にあります。人々は完璧な川が現れるのを待つのではなく、台地の勾配、土壌、季節風に従い、雨水を分散して貯留し、水路と社会規範を通じて必要な場所へ流すことを実現しました。

今日、池塘が直面する問題は単なる「水があるか否か」から、「誰が水の用途を決定できるのか」へと変化しています。農業には安定した供給が必要であり、都市には洪水調節と開放空間が必要であり、生態系には過度な整備されていない岸線が必要であり、住民には依然として地域性を認識できる景観が必要です。これらのニーズは自動的に調和することはありませんが、水路調査、公開資料、コミュニティの参加、長期的な維持管理を通じて一つの図上に配置することができます。

したがって、桃園の池塘を保存することは、過去をガラスケースに封じ込めることではなく、かつて機能していた地域の水利関係性を、都市化や気候変動に対応するための新しい用途に見出すことです。次に池のほとりで風が水面を渡っていくのを見たとき、私たちが真に目撃すべきは単なる風景ではなく、何世代にもわたって共同で完成させ、今もなお適切に管理され続ける「生きている水のシステム」なのです。
