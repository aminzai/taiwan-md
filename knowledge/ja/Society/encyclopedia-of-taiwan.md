> **30秒概要：**
> 2004年に開始された「台湾大百科全書」は、台湾が文化的主体性を確立しようとするマイルストーンであり、総予算は5,200万元に上した。この事業は出版人王榮文が最初に構想した14億元の壮大なブループリント（30巻、10万項目、英語版を含む）から始まったが、実際の実行においては専門家審査による「権威性」とウェブ協働による「自由度」の間で反覆しながら進められた。3回のシステム反復（自社開発、MediaWiki、独立システム）、ライセンスの変遷（GFDLからCCへ）、そして印刷版計画の縮小を経て、2014年7月15日に独立サイトを閉鎖し、「国家文化データベース」に統合された。この実験は、デジタル時代における国家の役割の転換を証明した：「定本の解釈を独占しようとする」から「開放素材を提供する」へと移行したのである。

「阿扁は常に、私たちは『台湾大百科全書』を持つべきだと考えていた。台湾の民情と時代の潮流を忠実に凝縮した百科全書である。」[^1] 2004年5月13日、当時の大統領陳水扁は第135号の「阿扁電子報」で、百科全書の編纂を国家戦略的な重要性まで引き上げ、「台湾を研究するための完全な検索エンジン」および「台湾文化の知識集」としての重要性を強調した[^1][^2]。

この5億元規模の事業は「台湾主体的な解釈権」に関する大胆な賭けであった。「デジタル蔵国家型プロジェクト」のサブプロジェクトとして、国家がデジタル化、文化的創造産業、オープンデータ政策を推進していた時期と密接に関連していた[^2]。

### ビジョン：出版大王の14億元の壮大なブループリント

この巨大な事業の魂は、遠流出版の社長王榮文であった。彼にとって、百科全書は出版人にとっての最高の栄誉であった。王榮文が計画初期に提唱したビジョンは非常に野心的であった：彼は**4年以内にオンライン中国語版を完成**、**5年以内にオンライン英語版を完成**、**6年以内に印刷版を出版**（少なくとも**30巻**、**5,000万文字**、10,000部を学校や国際社会に贈る）[^2]。

コンテンツ目標には明確な**知識のツリー構造（Propedia）**と**10万以上の項目**が含まれていた。彼は『大英百科全書』第16版の修正予算を参考にし、6年間の総予算は**14億元**が必要だと見積もり、財団法人を設立して長期的に維持することを提案した[^2]。権威性を確保するために、計画はノーベル賞受賞者李遠哲を2007年5月に「監修編集委員会総監修長」に任命した[^1][^3]。

しかしながら、現実と理想の間には顕著な乖離が存在した。実際に実行された総予算は約**5.2億元**[^1]。元々2008年に**20冊の印刷版**を出版する予定であったが、実行過程で予算と重点がデジタルへと移行し、最終的には遠流の子会社「知慧蔵学習科技」が第1期6冊の編纂を完了するにとどまり、大規模な印刷版出版計画は最終的に実現されなかった[^1][^2][^4]。

📝 策展人のメモ：出版の夢想が国家予算と出会うとき、この大胆な賭けは最強の後ろ盾を得たように見えたが、官僚制度、技術の変化、そしてコミュニティ文化と10年間の交渉を強いられることになった。

### 転換点：3回のシステム反復とライセンスの争い

計画初期は「大衆版」を優先する戦略を採り、3回の主要な技術システム反復とライセンスの進化を経た：

1. **自社開発システム（2005年1月稼動）**：台湾21世紀議定書協会が受託。このシステムでは登録時に氏名、電話番号、さらには**身分証番号**の提供が必要であり、深刻なプライバシー問題を引き起こした[^1][^2]。初期には「審査を通過した投稿に対して報酬を支払う」制度を採り、大量の項目が投稿され、審査の進行が大幅に遅れた[^5]。
2. **MediaWikiシステム（2007年改版）**：ウェブサイトはMediaWikiシステムを採用し、ライセンスは**GNU Free Documentation License（GFDL）**を採用した[^2]。この時期、システムの開放性が高かったため、「ユーザーのコンテンツはほとんど検査されていない」、**著作権侵害の記事が溢れていた**、これが計画最大の品質危機となった[^1][^2]。
3. **独立システム（2009年10月改版）**：著作権侵害と品質の問題を解決するために、ウェブサイトは再び独立システム（taiwanpedia.culture.tw）に改版し、ライセンスは**CC BY-NC-SA 2.5 Creative Commons**に調整され、「開放だが営利目的ではない」立場が明確にされた[^1][^2]。

「インターネットを愛用する人々は、政府主導の知識の執筆と審査に反発する傾向がある。」[^5] これは2006年、文建会（現在の文化部）が専門家や学者に協議を求めた後の共感であった。専門家たちは「審査の取消し」に対する懸念は権威性だけでなく、「台湾の主体性」がノイズによって希釈されてしまうことも心配していた[^2]。

### 成果：金字塔の筆調による知識の生産

困難な過程であったにもかかわらず、『台湾大百科全書』は貴重な学術的遺産を残した。専門版は「金字塔の筆調」を強調する：最初の3文には具体的な事実を含め、その後はわかりやすく深入りし、最後に延伸読書を提供する[^6]。この計画は2000年代後半、台湾の歴史、地理、民俗、文学など16の分野について体系的な整理を行った[^5][^7]。

| カテゴリー             | データ内容                                                             |
| :--------------------- | :--------------------------------------------------------------------- |
| **大衆版計画**         | 15,036件の用語                                                         |
| **大衆版投稿**         | 11,793件（早期審査者約10,648件）[^2]                                   |
| **累積データ**         | 2011年末まで累積約**50,008件の用語**（厳密な審査を含まない累積量）[^2] |
| **専門版産出**         | 13,000件を超える専門家による校閲を受けた高品質の用語[^5]               |
| **マルチメディア資源** | 8,929枚の画像および一部の動画ファイル[^2]                              |

📝 策展人のメモ：この百科全書が最も貴重なのは、5億元という金額だけではない。それは、各分野の専門家たちにデジタル変革の初期段階で台湾について徹底的な知識検証を行わせ、ウェブコミュニティと対話を試みさせたことである。

### 結末：2014年のデジタル撤退とパラダイムシフト

2014年6月、文化部は正式に『台湾大百科全書』の用語を「国家文化データベース」（nrch.culture.tw）に統合し、コミュニティの協働を中止した[^1][^2]。**2014年7月15日**、独立サイトは正式に閉鎖された[^1][^2]。

これは重要な転換点であった：国家はWeb 2.0時代の「定本百科」の限界を認め、コンテンツを「オープンデータ」の一部として提供することを選択した。今日、これらの項目は「国家文化記憶庫2.0」に統合されており、「専門家の定本」から「全民の素材庫」へと移行し、NLPやAIの応用が導入されており、「文化的DNA」の共有と再創作が強調されている[^8][^9]。

### 課題と論争：知識主権の新戦場

この知識戦争は終わっていない。2025年末、中国大百科全書出版社は96万字の『台湾百科全書・歴史』を発刊し、「一つの中国原則」を強調した[^10]。これは、私たちが自分自身を定義しなければ、誰かが代わりに定義してしまうことを証明している。

台湾の知識主権の将来は、「国家級の定本」ではなく、本土のコンテンツがグローバルプラットフォーム（例えば、WikipediaやAI大規模モデル）で効果的に見られ、維持される方法にある。5億元を投じたこの実験は深い教訓を残した：国家が最も適している役割は、基礎的な蔵とオープンデータの守護者であり、知識の解釈を独占する定本の所有者ではない。

📝 策展人のメモ：この実験は証明した：国家が最も適している役割は基礎的な蔵とオープンデータの守護者であり、知識の解釈を独占する定本の所有者ではない。分散的な協働の時代において、知識の生命力は開放から来るのであり、控制からではない。
