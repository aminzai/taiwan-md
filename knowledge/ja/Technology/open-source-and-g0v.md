# オープンソースコミュニティとg0v

> **30秒概覧：** 2012年、政府が莫大な予算を投じて制作した中身のない広告に腹を立てたエンジニアたちが「fork政府」を決意しました――gov.twをg0v.twに変更し、あるべき政府の姿を再設計するというものです。8年後、COVID-19パンデミックが勃発すると、この「アマチュア」プログラマーたちは72時間でマスク地図を構築し、台湾全土の人々が13,000軒の薬局のマスク在庫をリアルタイムで検索できるようにしました。これは政府の実績ではなく、市民の勝利です。

2012年10月のある夜、高嘉良（こう・かりょう）はコンピュータの前で政府の「経済動能推升方案」広告を眺めていました。見れば見るほど腹立たしくなってきました。政府は4,000万元以上を投じて宣伝動画を制作していながら、内容が空虚で、この金を下水道に捨てた方がまだましなのではないかと疑わせるほどでした。

その夜、彼は台湾を変える決断をしました：**もし政府がうまくやれないなら、私たちが自分でやる。**

彼は政府のドメイン名gov.twの「o」を「0」に変更し、g0v.twにしました。この単純な言葉遊びは、全く新しい概念を象徴しています：**fork the government（政府をフォークする）**。オープンソースソフトウェアと同様に、オリジナル版に問題があれば、ブランチをフォークして自分でより良いバージョンを書き直すというものです。

## Fork政府：デジタル時代の公民実験

g0vは政府を転覆させるのではなく、政府と「並行」することを目指しています――オープンソース協力の手法を用いて、あるべき政府サービスの姿を再想像するのです。

**2012年12月**、第0回g0vハッカソン（hackathon）が中央研究院で開催され、40人以上が参与しました。最初のプロジェクトは、政府の『中央政府総予算』をPDF地獄から解放し、インタラクティブな可視化サイトに変えることでした。

元々政府の予算書は500ページ以上のPDFで、びっしりと並んだ数字と表があり、一般市民には到底理解できないものでした。g0vのボランティアたちはこれらのデータを再整理し、インタラクティブな図表を作成しました――**クリック一つで、政府があなたの税金をどこに使っているかがわかるように。**

> **📝 キュレーターのメモ**
> g0vの最初のプロジェクトが政府予算の可視化を選んだのは偶然ではありません。予算は民主主義の核心です――政府が国民の税金を何に使うか、国民は知る権利があります。しかし伝統的な予算書は、理解できないように意図的に作られています。g0vはテクノロジーを用いて、この「意図的な不透明性」を打ち破りました。

この小さな実験は一つのことを証明しました：**政府がやらないからといって、できないわけではない。ただ誰もやらないだけなのです。**

## 318学生運動：シビックテックの火力展示

2014年3月18日夜、学生たちが立法院を占拠しました。翌朝には、g0vのボランティアたちが現場に現れました。抗議をするためではなく、「インフラ整備」をするためでした。

**誰も組織せず、誰も指揮しません。**g0vコミュニティの参加者たちは自発的に以下のことを行いました：

- **リアルタイム配信**：マルチアングル直播システムを構築し、世界中が議場内の状況を視聴できるようにしました
- **情報統合**：hackfoldrフォルダを作成し、インターネット上の様々な情報をリアルタイムで収集・整理・検証しました
- **群衆協力**：共筆システムを構築し、現場にいない市民もデータ収集やファクトチェックに参加できるようにしました
- **対外連携**：多言語リアルタイム翻訳を提供し、国際メディアが抗議の訴えを即座に理解できるようにしました

**24日間の占拠、全期間高画質直播で、一度も切断されることはありませんでした。**これは2014年当時、信じがたい技術的成果でした。当時はFacebook Liveも存在せず、YouTubeライブも普及していませんでしたが、g0vのボランティアたちはオープンソースツールを用いて、プロフェッショナルメディアよりも安定した直播システムを自ら構築したのです。

さらに重要なのは、「透明性」の力を証明したことです。リアルタイム配信があったおかげで、誰もが議場内で何が起きているかを視聴でき、政府が事実を歪曲することは不可能になりました。この「テクノロジーで政府を監督する」モデルは、その後世界中の公民運動に学ばれ、模倣されることになります。

## マスク地図：72時間の奇跡

2020年2月初頭、COVID-19パンデミックが台湾で勃発しました。政府はマスク実名制政策を発表し、一人当たり週2枚のマスク購入を認めました。問題は、どこで買えるのか、どの薬局に在庫があるのか、ということでした。

**2月6日**、デジタル政策委員の唐鳳（とう・ほう／オードリー・タン）が発表しました――政府は台湾全土13,000軒の特約薬局のマスク在庫データを開放し、30分ごとに更新すると。唐鳳は彼女自身がg0vの創設メンバーです。

**2月8日**、最初のマスク地図がオンラインで公開されました。**2月9日**には、100以上の異なるバージョンのマスク地図が登場していました。

これは政府が情報会社に発注したプロジェクトではなく、台湾全土のプログラマーたちが「自主的に残業」した結果です。**誰もが防疫のために力を尽くしたいと考え、プログラマーができることはコードを書くことだけでした。**

最も人気のあるバージョンは以下の通りです：

- **台湾マスク地図** by Howard Wu：簡潔で明瞭な地図インターフェース
- **まだマスクはありますか** by ネットユーザーkiang：薬局の評価と営業情報を統合
- **どこでマスクを買う？** by Finjon Kiang：音声検索機能をサポート

72時間以内に、台湾は世界で最も充実したマスク在庫検索システムを構築しました。**他国の市民がまだ行列でマスクを買い占めている間に、台湾の人々はスマートフォンで最寄りの薬局に残っているマスクの数を検索できるようになったのです。**

> **⚠️ 論争的な見解**
> 政府が「責任をボランティアに外注している」と批判する声もあります。民間が無料で政府のシステムを作らされているというものです。しかしg0vコミュニティの回答は明快です：私たちは政府に利用されているのではなく、自らの専門性を社会に還元することを選択したのです。さらに、オープンソースのマスク地図は、政府が自作したシステムよりも使いやすく、革新的で、ユーザーのニーズに合致しています。

## オープンソース協力の魔法

g0vの運営モデルは非常にシンプルです：**上司も従業員も予算もオフィスもありません。**あるのは、テクノロジーで社会問題を解決したいと願う人々と、オープンソース協力の文化だけです。

### ハッカソン文化

2ヶ月ごとに大規模ハッカソン（大松）を開催し、参加者は現場で提案・チーム結成・実装を行います。流れは以下の通りです：

1. **3分間の提案**：誰でもステージに上がってアイデアを提案できます
2. **自由なチーム結成**：興味のある人はプロジェクトに加入できます
3. **現場実装**：当日から作業を開始します
4. **成果発表**：午後に本日の進捗を共有します

**誰も拒否されることはなく、どんなアイデアも否定されません。**唯一の要求は、プロジェクトをオープンソースにし、他の人が改修・継続できるようにすることです。

### 協力ツール

- **Slackチャンネル**：日常的な議論と情報共有
- **GitHub**：コード管理とバージョン管理
- **HackMD**：共筆ドキュメントと会議記録
- **Trello**：プロジェクト管理と進捗追跡

### 3つの核心精神

1. **オープンソース**：すべてのプロジェクトのコード・データ・ドキュメントを公開します
2. **分散化**：指導層がなく、誰でもプロジェクトを立ち上げられます
3. **実装至上**：「Talk is cheap, show me the code（口先だけではなく、コードを見せろ）」

> **💡 ご存知ですか**
> g0vコミュニティには伝統があります：毎回ハッカソンで「小松鼠（リス）」のステッカーを用意します。初参加の方には小松鼠ステッカーが配られます。このデザインには、初心者であっても小さな力を貢献することを歓迎するという意味が込められています。リスがドングリを集めるように、小さな貢献が積み重なることが重要です。

## 重要プロジェクトと社会的影響

8年間でg0vコミュニティは数百のプロジェクトを生み出し、その多くは政府政策や社会運営に直接影響を与えました。

### 立法院議事透明化

**立法院議事録**は過去に文字版しかなく、一般市民が立法委員が立法院で何をしているかを知ることは困難でした。g0vのボランティアたちは「立法院議事透明化」プラットフォームを構築し、以下の機能を提供しました：

- **リアルタイム配信**：立法院会議の現場直播
- **発言記録**：各立法委員の発言統計と内容検索
- **投票記録**：重要法案の投票結果
- **提案追跡**：法案の提出から三読（可決）までの全過程

結果はこうです：**立法委員たちは自らの「データ」を気にするようになりました。**出席率、質問回数、提案数――これら過去に誰も気にしなかった数字を、今ではサイトが統計してくれます。民意代表は自らの一挙一動が監視されていることに気づき、行動を変え始めました。

### vTaiwan：デジタル民主主義の実験

2014年、g0vは政府と協力してvTaiwanプラットフォームを立ち上げ、市民が政策策定プロセスに参加できるようにしました。最も有名な事例はUberをめぐる論争です：

**2015年**、Uberの台湾での営業がタクシー業界の抗議を引き起こしました。伝統的な処理方式は政府の一方的な決定でしたが、vTaiwanは第三の道を提供しました：すべての利害関係者がオンラインプラットフォームで対話し、ウィンウィンの解決策を見つけるというものです。

数ヶ月のオンライン討論と対面ワークショップを経て、最終的に「多元タクシー」政策が形成されました。

**これは台湾が初めて「デジタル民主主義」で政策の争議を解決した事例でした。**

### オープン政府への牽引力

g0vの倡議は政府政策に直接影響を与えました：

- **2012年**：政府予算視覚化専案が政府のオープンデータ推進を促進
- **2013年**：立法院透明化専案が立法院議事直播を実現
- **2014年**：318学生運動後、政府が『政府情報公開法』修正を約束
- **2015年**：vTaiwanプラットフォームが政府の正式な政策参加窓口に
- **2016年**：唐鳳がデジタル政委に就任し、g0v経験を政府に導入

## 国際的な影響と連携

g0vの経験は台湾にとどまらず、世界中の公民科技運動を啓発しました。

### Code for All 国際ネットワーク

g0vは**Code for All**国際ネットワークの創始メンバーであり、日本の Code for Japan、韓国の Code for Korea、アメリカの Code for America などの組織と密接に協力しています。

**2019年**、g0v summit が台北で開催され、30以上の国の公民科技コミュニティが一堂に集まり、経験と技術を共有しました。

### パンデミック期間の国際協力

2020年疫情期間中、g0vのマスク地図経験は他国に学ばれました：

- **イタリア**：ローマ版マスク地図
- **ドイツ**：ベルリン版マスク地図
- **アメリカ**：PPE地図（個人防護用品地図）
- **韓国**：마스크맵（mask map）

g0vのボランティアたちも主動的に他国への協力を行い、台湾の感染症対策科技経験を世界中に分かち合いました。

## 課題と未来

g0vが「上司のない組織」として、あらゆるオープンソースコミュニティが直面する課題に取り組んでいます。

### プロジェクトの持続性

多くのg0vプロジェクトは「一時的な興味」の産物であり、長期的な保守が欠けています。マスク地図はパンデミック期間中は非常に活発でしたが、疫情が終わった後は次第に保守されなくなりました。**良いプロジェクトが持続的に運営されるにはどうすればいいのか、これはg0vが最大限に取り組むべき課題です。**

### 参加者の疲労

8年間の高強度志工参加により、初期の貢献者の中には疲労感を覚える人も出てきました。新しい人員をどう引き入れるか、参加をどう持続可能にするか、これはコミュニティが直面する問題です。

### 政府との関係

g0vと政府の関係は微妙です：協力しながらも監督しています。政府がオープンソースとデジタル民主主義を積極的に受け入れると、g0vの「対抗」的役割は曖昧になります。協力の中で独立性と批判精神を保つ方法は、継続的な課題です。

### フェイクニュースと情報戦

情報戦の時代、開放透明の原則も悪用される可能性があります。開放性を保ちながら、フェイクニュースの伝播手段にならないようするにはどうするか、これが新たな課題です。

## まだ続いている実験

2012年、高嘉良がgov.twをg0v.twに変更したその時、彼はただ政府への不満を表現したかったのです。12年後、g0vは台湾民主主義の一部となり、世界中の公民科技運動の重要な力になりました。

この実験が証明したことは幾つかあります：

1. **テクノロジーは市民参加の道具になれます**。商業利益の手段だけではなく
2. **開放透明は政府効率より重要です**。なぜなら透明性が効率をもたらすから
3. **小さな憤怒は世界を変えられます**。自分の手で行動する限り
4. **政府をforkすることは政府を転覆させることではなく**、より良い可能性があることを証明するのです

この民主主義が衰退する時代に、g0vは私たちに思い出させます：**市民は政府のユーザーではなく、共同創造者です。**政府がうまくやれないことは、私たちが自分でやれます。政府がうまくやることは、私たちがさらに良くするのを手伝えます。

これは終わりのある革命ではなく、続く実験です。毎回のハッカソン、毎つのプロジェクト、毎行のコードは、同じ一つの問いに答えています：デジタル時代、民主主義はどんな形をしているのか？

答えはまだ書かれている途中であり、貢献することを願う全ての人が、この答えの作者です。
