# Mini Taiwan Pulse — 台湾交通リアルタイム3D可視化 🌐

> 📖 **詳細版記事**：本リソースは市民科技の詳細研究記事にアップグレードされました。全文は [Mini Taiwan Pulse：データアナリストが台湾の交通の鼓動を呼吸する3D光跡に描き出す方法](/ja/technology/mini-taiwan-pulse-civic-tech)（2026-04-19）をご覧ください。本ページはリソース一覧の索引項目として保持されています。

> **30秒概要：** 台湾の交通運輸のリアルタイム動態を3D光球と光跡に変換するオープンソースプロジェクトです。航空便が空に弧を描き、船舶が海面に尾を残し、列車が軌道を駆け抜けます――23の切り替え可能なレイヤーで、台湾の鼓動を「視覚化」できます。

## 注目すべき理由

大多数の人が台湾の地図を見ると、静的な輪郭しか見えません。Mini Taiwan Pulse を使えば、**呼吸する島**を見ることができます。

本プロジェクトの野心は小さくありません。各政府機関に散らばるオープンデータ――航空便、船舶AIS、台鉄・高鉄の時刻表、地下鉄路線、人口統計、気象観測――をすべて同一の3D地図に統合します。単なる点のマーキングではなく、光球、光跡、彗星の尾のような視覚言語を用いて、データを動く風景に変換します。

> **📝 キュレーターノート**
> 台湾のオープンデータ基盤整備はアジアでトップクラスです（[世界オープンデータ指数](https://index.okfn.org/)で度々トップ10に入選）。しかし、「データの公開」と「データが見える」の間には大きな溝があります。Mini Taiwan Pulse はこの溝を埋めています。

## 三層の鼓動

### 空 — 航空便光跡 ✈️

台湾全土14の空港、1,500便以上の航空便のリアルタイム動態をカバーしています。各航空機は発光する球体で表され、後ろには彗星の尾のようなグラデーション光跡が引かれます。高度の誇張倍率は調整可能（1x～5x）で、低空路線と高空路線の差を一目で把握できます。

データソース：FlightRadar24 API。

### 海 — 船舶追跡 🚢

台湾周辺海域の船舶位置は青藍色の光球で標示され、各船舶は30分間の尾の軌跡を残します。システムはGPSの異常ジャンプや無効なMMSIを自動的にフィルタリングし、表示されるすべての光点が実際の船舶であることを保証します。

データソース：AIS（自動識別システム）船舶位置データ。

### 陸 — 6大軌道システム 🚄

これが最も驚くべき部分かもしれません。6つの軌道システムが同期して運行されています：

| システム         | 規模                                |
| ---------------- | ----------------------------------- |
| 台鉄（TRA）      | 265路線、333列車、車種ごとに6色分類 |
| 高鉄（THSR）     | 南北主線 + 支線                     |
| 台北捷運（TRTC） | 8路線                               |
| 高雄捷運（KRTC） | 紅線 + 橘線                         |
| 高雄軽軌（KLRT） | 環状軽軌                            |
| 台中捷運（TMRT） | 緑線 + 青線                         |

台鉄の処理は特に複雑です――OD軌道マッチング、彰化三角線のような分岐路線には、専用のエンジンが使用されています。

データソース：公開時刻表 + [OpenStreetMap](https://www.openstreetmap.org/) 軌道データ。

## 交通だけではない

移動中の輸送機関に加え、本プロジェクトは複数の静的・分析レイヤーを重ね合わせています：

- **インフラ**：14の空港境界、535の車両停車駅の光柱（高さ = 停車回数）、36の灯台の3D回転光ビーム
- **路網**：高速道路（赤）、省道（橙）、自転車道（緑）、ズーム時に幅が自動調整される
- **人口分析**：H3六角格人口ヒートマップ、昼間/夜間人流切り替え対応、9項目の人口指標
- **気象**：観測地点のリアルタイムデータ + 気温波面の3D曲面（0.03° グリッド解析度）
- **ニュース**：中央通訊社CNA RSS + Gemini APIの地理エンコード、地図上にニュース事件をマッピング
- **高速道路の混雑**：リアルタイム混雑程度の色分けエンコード

全部で **23の独立して切り替え可能なレイヤー**、10のカテゴリー。

## 技術亮点

- **TypeScript + Mapbox GL + Three.js**：2D地図はMapbox のネイティブレンダリングを使用し、3D要素（光球、光跡、光柱、気温曲面）はThree.jsで重ね合わせます
- **パフォーマンス考慮**：船舶はInstancedMeshバッチレンダリング、ビューポート除去（viewport culling）を使用して見えない物体のレンダリングを回避
- **色科学**：人口レイヤーはPlasma / Viridis / Inferno などの知覚均等色スケールを使用、log1p + gamma正規化で重尾分布を処理、色盲対応
- **MIT ライセンス**：完全オープンソース、forkと貢献を歓迎

> **📝 キュレーターノート**
> 加算合成（additive blending）を使用して光跡を重ね合わせるのはスマートな選択です――複数の航路が重なる領域は自然と明るくなり、視覚的に航路の混雑度が分かります。追加の統計グラフは不要です。

## オープンデータ生態系

本プロジェクトが接続しているデータソースは、それ自体が台湾のオープンデータのガイドリスト：

| データ                       | ソース                                              |
| ---------------------------- | --------------------------------------------------- |
| 航空便のリアルタイム位置情報 | FlightRadar24 API                                   |
| 船舶AIS                      | 国際船舶自動識別システム                            |
| 鉄道時刻表                   | 公開時刻表 + OSM                                    |
| バス/長距離バス/自転車       | [TDX 公共交通データ](https://tdx.transportdata.tw/) |
| 人口統計                     | [SEGIS 統計地理情報](https://segis.moi.gov.tw/)     |
| 気象観測                     | [中央気象庁](https://www.cwa.gov.tw/)               |
| 洋上風場                     | 経済部エネルギー局                                  |
| ニュース事件                 | 中央通訊社CNA RSS                                   |
| 空港/港湾/駅の境界           | [OSM Overpass API](https://overpass-turbo.eu/)      |

⚠️ **注目すべき点：** 台湾の [TDX 公共交通データ流通サービス](https://tdx.transportdata.tw/) は、全国の公共交通データを統一的に標準化した数少ない政府プラットフォームで、バス、長距離バス、鉄道、自転車などをカバーしており、APIドキュメントは完全で無料で使用できます。これは世界規模ではまれなことです。
