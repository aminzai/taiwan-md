# Mini Taiwan Pulse — Тайвань: транспорт в реальном времени, 3D-визуализация 🌐

> 📖 **Глубокая статья**: этот ресурс вырос в глубокую исследовательскую статью по гражданским технологиям, полная версия — [Mini Taiwan Pulse: как аналитик данных превратил транспортный пульс Тайваня в дышащие 3D-световые траектории](/ru/technology/mini-taiwan-pulse-civic-tech) (2026-04-19). Данная страница сохранена как индексная запись в списке ресурсов.

> **Обзор за 30 секунд:** открытый проект, превращающий динамику тайваньского транспорта в 3D-световые шары и траектории в реальном времени. Рейсы описывают дуги в небе, корабли оставляют следы на море, поезда мчатся по рельсам — 23 переключаемых слоя позволяют «увидеть» пульс Тайваня.

## Почему это стоит внимания

Большинство людей, глядя на карту Тайваня, видят статичный контур. Mini Taiwan Pulse показывает **остров, который дышит**.

Амбиции проекта велики: собрать на одной 3D-карте разрозненные открытые данные различных правительственных ведомств — рейсы, AIS судов, расписания ТРА (台鐵) и ГЖД (高鐵), маршруты метро, статистику населения, метеонаблюдения. Не просто точки-маркеры, а визуальный язык световых шаров, траекторий, кометных хвостов — данные становятся оживающим пейзажем.

> **📝 Заметка куратора**
> Открытая данные Тайваня в Азии входят в топ (Global Open Data Index многократно попадал в десятку лидеров), но между «данные открыты» и «данные видны» лежит огромная пропасть. Mini Taiwan Pulse именно её и заполняет.

## Три слоя пульса

### Небо — траектории рейсов ✈️

Охватывает 14 аэропортов Тайваня, 1500+ рейсов в реальном времени. Каждый самолёт — светящийся шар с градиентным кометным хвостом. Коэффициент преувеличения высоты регулируется (1x–5x), различия между низкими и высокими маршрутами сразу бросаются в глаза.

Источник данных: FlightRadar24 API.

### Океан — слежение за суднами 🚢

Позиции судов в акватории вокруг Тайваня, обозначены бирюзовыми световыми шарами, у каждого — 30-минутный хвостовой след. Система автоматически фильтрует аномальные прыжки GPS и недействительные MMSI, гарантируя, что каждая видимая точка — реальное судно.

Источник данных: AIS (автоматическая идентификационная система) позиций судов.

### Суша — шесть железнодорожных систем 🚄

Возможно, самая впечатляющая часть. Шесть систем работают синхронно:

| Система              | Масштаб                                              |
| -------------------- | ---------------------------------------------------- |
| ТРА (台鐵)           | 265 маршрутов, 333 поезда, 6 цветов по типам вагонов |
| ГЖД (高鐵)           | Главная север-юг + ветви                             |
| Метро Тайбэя (TRTC)  | 8 линий                                              |
| Метро Каосюн (KRTC)  | Красная + оранжевая линии                            |
| ЛРТ Каосюн (KLRT)    | Кольцевая ЛРТ                                        |
| Метро Тайчжун (TMRT) | Зелёная + синяя линии                                |

Обработка ТРА особенно сложна — OD-сопоставление путей, разветвлённые маршруты вроде «Чжаньхуа-треугольника» имеют выделенные движки.

Источник данных: публичные расписания + данные путей [OpenStreetMap](https://www.openstreetmap.org/).

## Не только транспорт

Помимо движущегося транспорта, проект накладывает множество статических и аналитических слоёв:

- **Инфраструктура**: границы 14 аэропортов, 535 световых столбов станций (высота = частота остановок), 36 3D-вращающихся лучей маяков
- **Дорожная сеть**: нацтрассы (красные), провинциальные трассы (оранжевые), велодорожки (зелёные), адаптивная ширина при зуме
- **Население**: H3-гексагональные тепловые карты, переключение дневного/ночного потоков, 9 демографических показателей
- **Метео**: данные станций в реальном времени + 3D-поверхность температурных волн (разрешение 0.03°)
- **Новости**: RSS ЦНА (中央通訊社) + Gemini API геокодирование, события наносятся на карту
- **Пробки на нацтрассах**: цветовое кодирование затора в реальном времени

Всего **23 независимо переключаемых слоя**, десять категорий.

## Технические особенности

- **TypeScript + Mapbox GL + Three.js**: 2D-карта — нативный рендеринг Mapbox, 3D-элементы (световые шары, траектории, столбы, температурная поверхность) — наложены через Three.js
- **Производительность**: суда — InstancedMesh для пакетного рендеринга, отсечение по вьюпорту (viewport culling) исключает невидимые объекты
- **Цветовая наука**: слои населения используют перцептуально-равномерные градиенты Plasma / Viridis / Inferno, log1p + гамма-нормализация для тяжёлых хвостов распределений, дружественно к дальтоникам
- **Лицензия MIT**: полностью открыт, форки и контрибьюты приветствуются

> **📝 Заметка куратора**
> Аддитивное смешивание (additive blending) для наложения траекторий — умный выбор: в зонах пересечения множества маршрутов яркость естественно нарастает, визуально показывая загруженность авиамагистралей без дополнительных статистических графиков.

## Экосистема открытых данных

Источники, которые проект интегрирует, сами по себе — навигатор по тайваньским открытым данным:

| Данные                            | Источник                                                            |
| --------------------------------- | ------------------------------------------------------------------- |
| Позиции рейсов в реальном времени | FlightRadar24 API                                                   |
| AIS судов                         | Международная автоматическая идентификационная система судов        |
| Железнодорожные расписания        | Публичные расписания + OSM                                          |
| Автобусы/межгородние/велодорожки  | [TDX платформа транспортных данных](https://tdx.transportdata.tw/)  |
| Статистика населения              | [SEGIS статистическая геоинформация](https://segis.moi.gov.tw/)     |
| Метеонаблюдения                   | [Центральное метеорологическое управление](https://www.cwa.gov.tw/) |
| Оффшорные ветропарки              | Бюро энергетики МЭПР                                                |
| Новостные события                 | RSS ЦНА (CNA)                                                       |
| Границы аэропортов/портов/станций | [OSM Overpass API](https://overpass-turbo.eu/)                      |

⚠️ **Важно:** тайваньская [платформа обмена транспортными данными TDX](https://tdx.transportdata.tw/) — одна из немногих государственных платформ, унифицировавших данные всего общественного транспорта страны: автобусы, межгородние рейсы, железные дороги, велодорожки. API документирован полностью и бесплатен. В глобальном масштабе это редкость.
