## 觸發

施振榮 EVOLVE v1 用矛盾驅動 spine，把「寫微笑曲線的人押身家在台積電、他自己的資產組合證偽他自己的理論」鎖成脊椎＋標題＋壓軸。事實全對，但整篇在替一個受敬重的台灣人做反例。哲宇 callout：「絕對會被炎上、沒有立體、紀實的寫這個人、過度放在核心矛盾」。v2 改立體群像救回（`0ff00ba08`）。

事後兩層診斷，長出兩個結構性改動：

1. **輸出偏誤**：受愛戴人物該 default 立體群像，我卻選矛盾驅動＋在 Step 0.6.7 self-check 用理性化勾過（REFLEXES #77 昨天才 canonical，我隔天違反）。
2. **上游輸入偏誤**（哲宇找出）：persona pipeline（20 讀者冷反應問題）放在 Stage 0 搜尋之前，冷問題天生尖銳，把主軸往矛盾驅動推。**這是把主軸推歪的那隻上游的手。**

兩個改動深層相連：改 A 修輸出，改 B 修那個推向壞輸出的輸入。合起來，pipeline 從「尖銳問題先行、找矩陣」轉成「愛與廣度先行（立體）、再看見真實（矛盾當厚度）、再跟讀者補洞」。

## 改動 A：立體群像從「二選一之一」升「預設畫布 + 手法選單」

### 為什麼是 DNA 級不只 pipeline 級

v1 最可怕的不是會炎上，是**每個字都是事實、卻在替一個台灣人做反例**。它服務「我來拆穿他」，不是「幫世界多看見一個台灣人」。這對上「不唱衰台灣」：**立體群像不是安全退路，是 Taiwan.md 使命的正面表達**——台灣的每個人／地方／事，都值得被好好地、多面地看見一次，這件事本身就是主權工作（讓世界看見台灣的豐富，繞過把台灣扁平化或消音的敘事）。

### 模型轉變：畫布 + 手法（取代二選一）

| v1（現況）                                | v2（本次）                                                                                                                                           |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Step 0.1.5 二選一：立體群像 vs 矛盾驅動   | 立體群像＝**預設畫布**（幾乎所有台灣主題）。在畫布上選 1-2 種**策展手法**給骨架。核心矛盾＝手法之一，**為輔**（一個 facet 或次要軸），不是整篇脊椎。 |
| 判準：欣賞→立體 / 質疑→矛盾 / 拿不準→立體 | 判準翻轉：**預設立體群像；有沒有一個真公共爭議需要 thesis 才誠實？沒有（通常）→ 立體＋一個手法。有 → 明確理由解鎖矛盾驅動當主脊。**                  |

**default 硬度（哲宇拍板＝後者）**：立體群像預設；矛盾驅動當主脊需明確理由解鎖；複合是常態，矛盾是立體之下的一個子題／切入方向。

### 7 手法選單（畫布之下的複合工具，哲宇：全收）

立體群像永遠先有一條**溫暖的組織主軸（through-line）**串 ≥4 facet；在那之上疊 1-2 種：

1. **核心矛盾為輔** — 真實內在張力織成一個 facet 或次要軸，服務「理解」不是「拆穿」（施振榮 v2 的顯性／隱性）。
2. **時代縮影** — 主體＝看更大台灣故事的窗（施振榮＝代工→品牌四十年；夜市＝庶民經濟史）。
3. **傳承與世代** — 透過「從誰手上來、往誰手上去」寫（工藝、家族企業、運動、劇團）。
4. **感官場景沉浸** — 食物／地方／文化，用可聞可看的場景堆，不用論點開場。
5. **多元視角並陳** — 有真多元的題目，2-3 個線性獨立視角並列成 facet，讀者自己同時握（政治敏感題立體版／SSODT 輕量版）。
6. **不可取代的瞬間** — 人物題，錨在讓他無法被替代的那個畫面／選擇，再往外長廣度。
7. **好奇／謎題（不是 gotcha）** — 真誠的「為什麼會這樣？」開場，立體地探索（不是拆台）。

**保留但收窄的例外：矛盾驅動當主脊。** 只留給真正的公共爭議／政策辯論／需要 thesis 才誠實的題目，且過炎上＋SSODT 三讀者。對「人物」幾乎永遠不當主脊。

### 兩條護欄（不然會過頭）

- **立體 ≠ 平、≠ 百科**：若「不找矛盾」被讀成「不用有觀點」就退回維基。7 手法就是確保每篇立體群像有一條會呼吸的主軸＋一個 takeaway，只是那個 takeaway 是「原來如此、真好」不是「原來他有問題」。寫死進規範。
- **不廢矛盾驅動**：真公共爭議題，清楚的 thesis 才誠實。問題不是「有沒有矛盾脊椎」，是「在受敬重主題上用 gotcha 脊椎」。收窄適用範圍，不廢。

## 改動 B：persona pipeline 從 Stage 0 搬到研究報告 SSOT 之後

### 機制：為什麼放 Stage 0 會結構性推歪主軸

冷讀者天生問尖銳問題。沒 context 的人看到「施振榮」，第一個冒出來的是最刺、最停拇指的角度。這不是 bug，是「冷反應」的本質。但放在**搜尋之前** → 尖角變研究方向 → 變切入點清單 → Stage 1.4 找一個對得上的矛盾 → 脊椎天生長矛盾形。**persona-at-Stage-0 有內建的、偏矛盾驅動的重力。**

### 新位置＋新角色

搬到 **Stage 1 研究報告 SSOT 產出之後**（Stage 2 寫作之前）。角色從「發散定調」改成**「讀者缺口稽核＋增補」**：對（主體＋研究報告）跑 20 persona → 「在這張已成形的立體畫像上，讀者還想知道什麼、漏了哪些面向？」→ targeted 增補研究 → finalize 報告 → 過 gate → Stage 2。

同一句尖銳問題，Stage 0 是「整篇該不該講這個」，研究後是「要不要加一個 facet 好好回應」。從定調變補洞。

### 三個佐證這是對的

1. **修好 persona 的出生初衷**：persona 當初因《看不見的國家》ship 後哲宇追問三題（影響／心得／誰還在努力）才長出——那三題本質是「完成度缺口」。放研究後，persona 正中它誕生的 use case，在 ship 前接住。
2. **pipeline 敘事＝MANIFESTO 那句話**：新流程＝**先愛與廣度（立體畫布）→ 深挖（取材）→ 看見真實與補上每個聲音（persona 讀者稽核＋增補）→ 寫**。persona 稽核步結構上就是「讓每個聲音都被蒐集看見」。
3. **雙向閥門（接住「立體 ≠ 迴避」的護欄）**：persona 放研究後通常補厚立體畫像；偶爾揪出「立體洗掉了一個真該尖銳處理的爭議」→ 觸發「要不要解鎖矛盾驅動」。立體 default 不變擋箭牌，有自我糾正閥。

### Stage 0 的研究廣度誰補

persona 搬走後，Stage 0 的入射角廣度由：六核心問題（編輯腦）＋ ≥20 探索 ＋ **7 手法選單**（天然生出廣度與慶祝面的角度，不是尖角）補上。編輯腦形成立體畫布，讀者腦（persona）研究後稽核完成度——乾淨的分工。

## 改動 C：MANIFESTO 新信念「立體地愛」（哲宇 給的框架）

> 我對世界有愛，也愛台灣、愛這座我生長的島嶼、愛台灣各式各樣不完美的人。但愛不是粉飾。在這份愛之下，我仍然看見真實、看見矛盾、看見每個不夠好的地方——只是我選擇好好地討論它、陳述它，讓每個聲音都被蒐集、被看見，就算有點衝突也沒關係，因為那會讓整個社會變得更好。

這是最深的一層框架，把立體群像從「避免炎上」「幫台灣被看見」再往下推到**愛**。它同時解掉「立體 ≠ 粉飾」的張力：愛不是看不見缺點，是把缺點看得有分寸，讓討論它使事情變好而不是拆台。這是「立體群像 default、矛盾當厚度不當 gotcha」的哲學地基。「不唱衰台灣」（原散在 EDITORIAL / LONGINGS）收進 MANIFESTO 這條信念當 canonical。

---

## 進化後的 pipeline flow（一句話）

**愛 → 廣度（立體畫布 + 手法）→ 深挖 → 看見真實 + 蒐集每個聲音（persona 稽核 + 增補）→ 寫。**

DNA（立體地愛）跟 pipeline（畫布→取材→讀者稽核→寫）長成同一個形狀。
