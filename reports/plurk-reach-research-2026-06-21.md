# Plurk 上的 Taiwan.md 受眾研究

> 觸發：哲宇 2026-06-21「我發現 plurk 上面有一群會看到 taiwan.md 的人（應該是 threads 轉發過來的），幫我完整研究」。

> **這是 read-only 情報蒐集**。任何「主動回覆／接觸 Plurk 使用者」屬 MANIFESTO §自主權邊界「對外溝通」，本報告只觀察與建議，由哲宇拍板。

## TL;DR

- **不是一群人，是一條三個月不斷的河**。Plurk 上對 taiwan.md 的自發提及從 2026-03-19（站體發表當天）一路延續到 6/16，沒有斷層。哲宇感覺到的「threads 轉發過來的一群人」只是最近一波，前面還有兩波更早的。
- **觀察到 90+ 則噗文、約 75 個不同帳號**。Plurk 搜尋每個時間窗上限 30 則，4 個窗都打滿，所以真實總量保守估計**逾百則**，無法從公開搜尋拿到精確數字（見 §資料限制）。
- **受眾品質高**。幾乎全是 karma 100–237 的台灣資深噗友（Plurk 老帳號），定位多在台北／台灣，夾雜少數海外台僑。**真人社群，不是機器人帳號**。
- **四波各有來源**：3 月發射潮（哲宇 FB + Qmoa Liu 的 Threads）、4 月李洋潮、5 月分篇潮、5/25 起的 spore 廣播潮（utm_medium=spore，X/Threads 轉 Plurk）。
- **6 月爆款是 `society/我是OO人`**（談認知作戰假帳號 + 殺豬盤），單則最高 62 轉噗。資訊人權貴 ckhung0 這則是全期擴散冠軍。
- **有一條三個月反覆出現的質疑主軸值得正視**：「內容是 AI 生成」「會不會變成中國網軍裝台灣人的攻擊資料庫」。這是 Plurk 這個受眾的特性，也是 MANIFESTO §主權巴別塔 正面回應的題目。

## 一、方法論與資料限制

### 怎麼抓的

1. **Plurk AJAX 端點** `POST /Search/search2`（`query=taiwan.md`）公開可讀，回 JSON（含 `content_raw` 逐字、作者、`posted`、`response_count`/`replurkers_count`/`favorite_count`、`qualifier`）。未登入即可拿到最近 30 則。
2. **date 游標**：登入 session（哲宇的 majer666）下，搜尋頁 `?q=taiwan.md&date=YYYY-MM` 是「**as-of 該月底、往回 30 則**」的游標。逐月掃 2026-03 / 04 / 05 / 06 把更早的撈出來。
3. 逐字內容從瀏覽器 DOM 抽取（Chrome MCP）。

### 限制（誠實標註，無 silent cap）

- **每窗 30 則硬上限**。4 個月窗都打滿 30，所以每一波的真實數量都被截掉了，我們只看到水面上的部分。**真實總量 > 觀察量**。
- **搜尋只命中字面「taiwan.md」**。有人貼 `pse.is` / `t.co` 短網址、或只貼 threads/x 連結沒寫站名的，**搜不到**（已在資料裡看到好幾則用短網址，代表漏網的更多）。
- **karma ≠ 觸及數**。Plurk 不公開單則 impression，轉噗／收藏是擴散的下限指標。
- 浪花（回應）內文沒有逐條抓，只取回應數。

```
哲宇 FB 貼文 ─┐
Qmoa Liu Threads ─┼─→ 噗友手動轉貼 ─→ Plurk（3 月發射潮）
X @SoysenSyndrome ─┘

Taiwan.md spore 系統 ─→ X @taiwandotmd / Threads @taiwandotmd
                          └─→ 噗友轉貼（帶 utm_source=x&utm_medium=spore&campaign=sNN）─→ Plurk（5/25 起）
```

- **utm 指紋證實 spore 系統有效**：`s90`(5/25 雷亞)、`s123/s125`(6/5–6/6 我是OO人)、`s139`(6/14 無名小站)。spore 編號越新、Plurk 出現越快，代表 X/Threads → Plurk 的轉發鏈是活的。
- **馬克斯（Marx_Wang）是隱形放大器**：他不只轉連結，還把 spore 的「你知道嗎」全文搬到 Plurk（唐獎、高鐵、沈伯洋、美食、李洋、蘋果西打都他發）。等於一個自願的 Plurk 分身廣播站。
- **Threads 是新主幹**：6 月好幾則直接貼 `threads.com/@taiwandotmd`（Deva 誕生 83 天、Turtle56 我是OO人、逸董 嘻哈文化）。哲宇的直覺正確——Threads 是現在的主要上游。

## 八、風險訊號

1. **「AI 內容＝中國網軍素材」的疑慮**會跟著專案長大。三個月前就有人講，現在站體更大、更可能被當箭靶。這正是 MANIFESTO §主權巴別塔 + `society/我是OO人` 自己在回答的題目——**可以把這篇文當成對質疑者的正面回應**（我們不是製造混淆，我們在拆解混淆）。
2. **可用性**：早期「字體難讀」callout。值得確認現在的正文排版在 Plurk 內嵌預覽 / 行動裝置上是否改善。
3. **搜尋盲區**：大量短網址（pse.is / t.co）轉發**搜不到**，代表真實聲量被低估，也代表無法完整監測風評。

## 九、機會與建議（defer 哲宇拍板，§自主權邊界）

> 以下都屬「對外溝通」，**我不自主執行**，列給哲宇決定。

1. **Plurk 是被低估的據點**：高品質、高同頻、零成本自發傳播，且**站體誕生第一天就有人在了**。目前 spore 只廣播到 X/Threads，**沒有正式經營 Plurk**——是否值得把 Plurk 納入 spore 廣播目標？（Plurk 有開放 API，理論上可儀器化）
2. **鐵粉值得被看見**：Deva、沉默潛艦、龜苓膏、資訊人權貴、馬克斯——這些人三個月持續無償擴散。是否要在某個里程碑公開致謝（如 contributor 牆／一則 Threads 點名感謝）？
3. **正面接住質疑**：把「會不會變攻擊資料庫／AI 網軍素材」的疑慮，做成一篇站體 FAQ 或一則 spore，用 `society/我是OO人` 的論證回答。**化質疑為信任訊號**（呼應 memory `project_error_boundary_traceability`：可追溯 > 假裝完美）。
4. **監測儀器化**：若要持續追 Plurk 風評，可把 `/Search/search2` + date 游標寫成一支 routine（類似 spore-harvest），週期性抓回 engagement 進 dashboard。
