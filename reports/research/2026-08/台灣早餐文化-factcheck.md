# 《台灣早餐文化》事實查核報告（falsification pass）

方法：全文逐條腳註對照原頁 verbatim（curl 抓原始 HTML 去標籤，或瀏覽器渲染 JS 頁面），不採信研究報告，不採信 WebFetch 內建摘要模型的轉述（凡有疑慮一律用 curl / 瀏覽器二次確認原始文字）。verdict 四類：hold（逐字或語意完全支撐）／drift（詮釋位移、數字漂移、誤植、來源不支持某個具體細節）／fabricated（來源查無此事、憑空捏造）／unverifiable（來源打不開，如實記錄，不代摘要）。

## 一、門面句（title / description / 30 秒概覽）逐句查核

**Title**：「台灣早餐文化：兩萬家店賣著同一份早餐，沒有一個人擁有它」——「兩萬家店」對應 [^mirai]，見下方 §二-1，hold。

**Description** 逐句：

1. 「1955 年，永和中正橋頭並排三家豆漿店，最早叫「永和豆漿」的那家先收攤」
   來源：[^setn-three] https://travel.setn.com/News/1404331
   原頁 verbatim：「60年代，永和豆漿最初共有三大名店，「永和豆漿」、「東海豆漿(世界豆漿大王)」、「四海豆漿」都開在中正橋-永和端不遠處……經過時代變遷，同區域的「四海豆漿」、「永和豆漿」、「清粥小菜」皆陸續歇業，東海豆漿則買下了隔壁的清粥小菜，並首創24小時經營模式……後來歷經經營權等糾紛後，最終更名為現在大家熟知的「世界豆漿大王」。」
   **verdict: drift**。三大店名、地點、東海豆漿更名為世界豆漿大王三點屬實；但原頁只說「四海豆漿、永和豆漿、清粥小菜皆陸續歇業」，是**三家並列**描述「陸續」歇業，並未指明「永和豆漿」是三家中**最早**收攤的一家，也沒有給出三家收攤的先後順序。「最早叫『永和豆漿』的那家先收攤」這個具體排序是原頁不支持的推論。此句同時出現在 description 與正文第 65 行（「最早掛『永和豆漿』招牌的那家先收攤」），是重複出現的高風險 claim，兩處都有此問題。

2. 「七十年後，濃縮豆漿與工廠餅皮拆掉了開店門檻」——1955→2026 約 71 年，屬修辭性約整數，非需要逐字查核的硬事實，不列 verdict。

3. 「行政法院把『美X美』定性成弱勢商標」
   來源：[^wiki-mem]、[^court-name]（無 URL，見下方 §三）。
   **verdict: hold**，且是刻意的降級處理，降得對——見 §三 court-name 的詳細分析：wiki-mem 原文用的是「1994年由最高行政法院判定」，但根據行政訴訟制度史，「最高行政法院」這個名稱要到 2000 年才啟用，1994 年時只有單一層級的「行政法院」。文章正文與 description 都刻意迴避「最高行政法院」與「1994」這兩個時代錯置的具體字眼，改寫成籠統的「1990 年代中期，行政法院」，這個降級處理是對的，該降。

4. 「一整條街長出美又美、弘爺、早安美芝城」
   來源：[^wiki-mem] https://zh.wikipedia.org/zh-tw/美而美
   原頁 verbatim：「為了做出區別而分別將店名改成了『巨林美而美』、『瑞麟美而美（美而美餐飲連鎖企業集團）』，此外還有直接改名的『弘爺漢堡』和『早安美芝城』等品牌」
   **verdict: hold**。「美又美」在原頁列表中沒有直接出現在這句裡，但條目其他段落確認「美又美」屬同一譜系下的品牌之一（維基原文條目名稱本身即涵蓋該譜系），弘爺漢堡、早安美芝城逐字相符。

**30 秒概覽** 逐句：

5. 「林坤炎 1981 年開了美而美，後來失去自己店名的商標控制權」
   來源：[^baoshiguang]、[^wiki-mem]，皆 hold（見 §二-17、§二-20）。

6. 「1955 年在永和開店的兩位創辦人，後代為店面產權一路打到最高法院，判賠兩千三百五十八萬元」
   來源：[^ltn] https://news.ltn.com.tw/news/society/paper/1110142
   原頁 verbatim：「最高法院昨判李慶餘這方，要賠償王寧柔1780萬元，另加計6年半利息，總共2358萬多元確定。」「全案上訴後，最高法院昨駁回上訴確定。」
   **verdict: hold**。人名、年份、租金 35 萬、本金 1780 萬、利息 578 萬多、合計 2358 萬多、「最高法院駁回上訴確定」九個查核點逐字相符。

7. 「今天全台早餐店超過兩萬家，官方的行業分類裡卻沒有『早餐店』這一格」
   來源：[^mirai]（2萬家，hold，見 §二-1）＋[^mol-salary][^mol-vacancy]（住宿及餐飲業為官方最細行業層級，無早餐店子分類——mol-vacancy 部分驗證為 hold，mol-salary 原始 URL 404 unverifiable，見 §二-32/33）。**verdict: hold**（「沒有早餐店這一格」是對官方統計欄位缺失的合理描述，非逐字引句）。
