## 1. 馬祖國際藝術島——三輪投影的完整病歷

### 1-1 實際文體形狀（自定名稱）：**錨定物普查型立體群像（anchor-generative inventory portrait）**

現存檔案（對應 v4）的骨架是「一個可機械生成的隱喻錨」＋「逐節兌現這個錨在不同材料層上的變形」。錨是「借」：空間借（256 座防空設施、停映的軍中電影院）、時間借（開放時間配合店家與船班、展期押在東北季風）、名字借（島嶼釀／生紅過夏／拍楸三屆主題取自閩東語老話）。每一節不是獨立主題，而是同一個「借」字在不同材料層的重現。這與典型立體群像（多個並列 facet 匯聚到一個統合式洞見）不同：這裡的洞見不是「匯聚」出來的，是**同一個詞逐層代入不同名詞**生出來的。

### 1-2 論點形態與骨架動作序列

v4 定案論點：「馬祖國際藝術島沒有為自己蓋一座展館——它把打過仗的坑道與軍中電影院、雜貨店、養雞場、餐廳，甚至往返基隆的那艘船，直接借來當展場……但借來的展場都附帶一件事：那些空間裡早就有人在說話——而在最沉重的那一間房裡，藝術島接手的敘事，不是當事人自己的話。」

骨架七步：①把讀者放進展場同時給座標 → ②問空間哪來（256 座防空設施） → ③時間與名字也是借的 → ④借來的東西長出了什麼（31 件常設、走到佐渡） → ⑤借得到場地借不到人（在地知曉度低） → ⑥走進最難的那間房（特約茶室敘事歸屬問題） → ⑦收在借與還之間（竹編拆除、31 件留下、第四屆待名）。v4 blueprint 逐一寫出真依賴：「2→3 真依賴：空間是接手的這個結論，才讓「時間與名字也是借的」構成同一方法的延伸；反過來讀不通」——這是可過 shuffle test 的證據。

### 1-3 型別擠壓痕跡：立體群像哪裡不合身

三處擠壓最明顯：

**(a) 論點主詞被抽象名詞偷走。** v3 §0 診斷第一條寫得極直白：「v2 論點主詞是「這套語言」，整篇在論證「一套自我敘事的完成度」。讀者拿到的是完成度論證，不是這座藝術島」。立體群像要求「有推進的統合式洞見」，但當研究材料本身充滿策展論述、媒體框架分析這類「關於論述的論述」時，容易滑成論證「敘事完成度」而不是論證「這個東西是什麼」——後設層吃掉了具象層。

**(b) 座標軸消失在質感堆疊裡。** 這是比 (a) 更隱蔽、也更晚才被抓到的病：v3 已經修好了現場感（開場放進展場），卻仍被編輯室三席全部打回，理由是：「**座標軸為零**：質感給滿了，但誰辦的、多大量級、哪幾座島、跟一萬四千人什麼關係，八節讀完全部答不出來」。也就是說，立體群像預設讀者已經知道「這是什麼規模的活動、誰辦的」，只需要被帶入細節與洞見；但對一個公眾認知度極低的地方性文化計畫，這個預設本身就不成立。

**(c) 隱喻錨滑向雙關而非論證。** v4 §0-A 記下 v3 的第二個病：「**錨靠雙關撐開**：「沒有牆，所以沒有自己的時鐘」「沒有牆的另一面是沒有門」——因果是假的，facet 從這個縫回流」。立體群像的骨架動作序列要求「真依賴」，但「沒有牆」這個詞在物理義（真的沒有蓋建築物）之外被延伸到「沒有時鐘」「沒有門」這類修辭義時，看起來像同一條邏輯鏈，其實只是同一個詞的諧音跳躍，面向巡禮從這個縫隙重新滲入——這是一種更隱蔽的偽 shuffle-test-pass。

### 1-4 可複製的投影策略（寫成規則）

- **R1／座標前置規則**：機構、地方、活動類主題，若讀者對「這是什麼規模、誰辦的、跟多少人有關」零認知，第一節（把讀者放進現場）必須把座標數字（主辦單位、屆數、地理範圍、人口基數）**縫進物質細節本身**，不能只寫質感、留給後段或側欄。v4 對 section 1 的寫手指令示範了這個縫法：「§一店家／民生＋交通載具兩類…**座標四件**（連江縣政府＋中華文化總會主辦、十年五屆、四鄉五島、設籍約 1.4 萬人）」。
- **R2／錨字動詞測試**：選定隱喻錨之後，逐節做「拿掉這個詞，這句話還有沒有邏輯」的測試。若某節只有靠雙關才能接上錨（如「沒有牆」→「沒有時鐘」），該錨需要換一個「可機械生成、不必靠諧音」的動詞（v4 換成「借」：借空間、借時間、借名字，三者不必靠雙關，只需要靠「借」本身的及物動詞性）。
- **R3／減法的證據標準要跟著論點換**：v3 §0 第 4 條把這句寫成本任務的核心引句：「這批材料升為**核心證據**。**錯的論點會砍掉對的材料**——換論點後減法整份重寫」。操作規則：任何被貼上「導覽層級／旅遊指南層級」而準備砍掉的材料，砍之前先問一次「這是不是讀者用來確認『這個東西長什麼樣』的材料」；是的話，material 的位階應該從「減法候選」直接升到「核心證據」，而不是被論點的高階抽象需求犧牲掉。
- **R4／敏感批判材料退出因果鏈，改列查證缺口。** v4 §0-B 改動 3：「財務退出論點，降為一個誠實標注的查證缺口。**不得以「必然後果」語法出現，不得寫成隱匿或不透明**」。這條可以泛化：任何無法查到一手來源、卻很想寫成「這證明了 XX 有問題」的材料，一律降級為「本文查證時未能取得」的事實陳述，不用因果句式把它焊進主論點——這正是 MANIFESTO §13「聰明的 gotcha」的具體防呆規則。
- **R5／責任主體核實先於敘事張力。** v4 §0-A 標記出 v3「最嚴重」的錯：「特約茶室展示館 2021/11 完成，屬大梅石計畫／文化部再造歷史現場，主導者江柏煒；藝術島首屆是 2022。**「第一人稱」文案不是藝術島做的**」。規則化：涉及「誰做了這件被批評的事」時，動筆前先核對時間軸與主辦主體，敘事張力（「這個機構自己寫的文案有問題」）絕不能建立在尚未核實的歸屬假設上。

### 1-5 失敗／勉強點；v3→v4 的根本差異；認識型文體是否能救 v1

**v3→v4 的根本差異，一句話**：v3 修好了「有沒有畫面」，沒修好「讀者知不知道自己在看什麼」；v4 才把「讀者知道自己在看什麼」升格為與畫面同等重要的必答題，而且把它縫進第一節的物質細節裡，不是加一個獨立的「background」段落。v4 §0-A 的診斷用詞極精確：「三席共同指出的病：**座標軸為零**」，而不是「畫面不夠」——這代表失敗的層級已經從「寫得好不好」升到「這個投影藍圖有沒有先確認讀者的起點」。

**認識型／導覽型文體會不會救回 v1？** 會，而且救的機制精準對上 v1 的病根。v1/v2 的論點主詞是「這套自我敘事的語言」，代表寫作團隊在讀者根本不知道「馬祖國際藝術島長什麼樣」之前，就急著給一個關於「這個活動怎麼講自己故事」的統合式洞見——這正是題目背景所說「錯的論點會砍掉對的材料」的根源：因為論點已經抽象化到「敘事完成度」層級，據點轉譯手法、開放時間細則這類「這是什麼」層級的材料，自然被判定為不服務論點的「導覽層級」而被砍。如果第一版被要求先過一道「認識型」關卡——不下統合洞見，只把讀者放進展場、給座標、列出具體展點與開放時間——那麼「該砍什麼」的判準會完全不同：具象材料是認識型的骨幹而非陰影，不會被砍。

但要誠實補一句：v4 證明了**這道關卡不必是獨立文體，也可以是立體群像內部的強制前置動作**——v4 仍然是立體群像（`spine_type: 立體群像`），只是把「認識」這個職責搬進了 section 1 的雙重職責裡，跟論點種子一起種下。這對 §6 的新文體提案很關鍵：馬祖案例本身沒有證明「認識型」必須獨立成一種文體，它證明的是「立體群像對零認知主題，必須內建一道認識型的前置關卡」——這兩個結論的邊界判準留到 §6 細講。

## 2. 金曲獎——矛盾驅動炎上、立體群像救回的案例

### 2-1 實際文體形狀：**首尾呼應情感錨的多軸群像（bookended multi-axis portrait）**

現存檔（v2/救回版）用同一個情感片刻（2024 年草東二度封神、經紀人代領、「謝謝凡凡」）開場與收尾：「回到那個靜默的幾秒鐘。2024 年的小巨蛋，草東二度封神，經紀人代領，說了「謝謝凡凡」」——結尾與開場同一句話幾乎逐字重現，只是這次帶著中段全部材料的重量回收。中段用五個並列軸展開：起源（蔡琴的信）、機制（閉門評審）、天王天后（紀錄保持人）、語言（四種語言四個舞台）、批評者（拒領、爭議並陳）、時代縮影（政治敏感時刻，紀實不評斷）。

### 2-2 論點形態與骨架動作序列

論點不是摘要句，是機構功能定義：「它不是一張「誰最紅誰得獎」的排行榜，它是台灣替自己的音樂頒獎、決定什麼聲音值得被好好記住的地方」。骨架動作序列：①用一個高情感片刻立起「這不只是排行榜」的懸念 → ②回溯起源（一封信如何變成國家級典禮） → ③解釋機制為何有公信力（關門投票擋掉市場） → ④兌現「加冕」功能（天王天后紀錄） → ⑤兌現「不只一種聲音」（四語言四舞台，含陳建年、阿爆的具體高峰時刻） → ⑥兌現「容得下批評」（林生祥拒領、郭力昕批評、珂拉琪的分類難題） → ⑦如實記錄「金曲也是台灣的鏡子」（政治敏感時刻，紀實不評斷） → ⑧回到最近一屆的現在進行式 → ⑨收尾回收開場片刻。

### 2-3 型別擠壓痕跡：立體群像哪裡不合身

**核心擠壓點：語言分類與兩岸政治材料天然具備 Type 2（矛盾驅動）與 Type 3（多觀點立場議題）的引力，但被刻意留在 Type 1 的框架內。** `rationale.why_this_hook` 自陳處置動機：「用一個情感重量最高的時刻，帶讀者立體認識「金曲獎是台灣怎麼決定什麼聲音值得被記住」，**而非押一個論戰式論點**（spine_type 立體群像）」——這句話直接證實 v1 走的是論戰式（矛盾驅動）路線並炎上，v2 的補救動作是把論戰材料（語言分類是否邊緣化弱勢語言、混語作品卡在分類縫隙、政治致詞事件）全部**降級為「核心矛盾為輔」的並列 facet**，不讓任何一條材料升格成統馭全篇的單軸命題。文中對政治材料有明顯的自我克制語句：「這些時刻就放在這裡，不多做評斷」、「這部分，把事情記下來就好」——這兩句是刻意壓低敘事溫度的操作標記，跟一般立體群像的行文密度不同，讀起來像是作者在提醒自己別滑進評論。

這代表：立體群像處理具強烈公共議題屬性的材料時，不是「自然合身」，而是要主動施加克制才不會被材料的政治重量拖走，型別本身沒有內建「怎麼壓住這股引力」的機制，得靠寫手自覺。

### 2-4 可複製的投影策略（寫成規則）

- **R6／情感錨首尾呼應。** 開場與結尾用同一個具體事件（同一場典禮、同一句得獎感言），中段材料全部服務於「讓這個片刻在讀完全文後意義變重」。這比抽象總結收尾更能承載立體群像「有推進」的要求，因為讀者可以親身感受到「同一件事，讀完之後看到的重量不一樣了」。
- **R7／敏感公共議題材料一律走「紀實不評斷」括號化處置，且要有顯性文字標記。** 不是靜靜地少寫，是要在正文裡放一句類似「這部分，把事情記下來就好」的顯性收束句，把讀者的期待從「這裡要下判斷了」轉回「這是紀錄」。這比隱性克制更安全，因為它明確告訴讀者作者的立場邊界在哪，避免讀者自行腦補立場。
- **R8／爭議材料要「兩造具名並陳」而非各打五十大板。** 郭力昕的批評具名引語、官方保護論的立場也具名並陳，林生祥拒領的動機與金曲獎「聽見了但保留設計」的反應都寫進去——立體群像處理爭議時，「具名並陳」本身就是一種不選邊卻不迴避的姿態，比匿名化的「有人認為……也有人認為……」更有公信力也更抗炎上。
- **R9／把「批評者被邀請上台」寫成不可取代的瞬間，而不是寫成辯護詞。** 林生祥拒領、珂拉琪卡在分類縫隙，都不是拿來替金曲獎辯護的材料，而是拿來證明「這個機構容得下自己被挑戰」的具體事件——技巧是敘事焦點放在事件本身的戲劇性（三十秒的拒領演說籌畫兩年），而不是放在事後的機構回應聲明。

### 2-5 失敗／勉強點

v1 的失敗軌跡本身沒有留下可讀的投影報告，這是本次讀檔清單的限制，所有判斷只能倒推自 v2 的 `rationale.why_this_hook`。但正文結構本身留下一個「勉強點」：語言分類爭議一節（「四種語言，四個舞台」）份量明顯重於其他 facet，篇幅與情感密度都逼近可以獨立撐起一篇矛盾驅動文章的程度——這代表這篇文章仍然帶著「本來想走矛盾驅動」的體重殘留，只是被壓進了立體群像的框架裡而不是被真正稀釋掉。這提示：**炎上不是題目本身錯了，是骨架型別選錯了；材料的政治重量本身沒有消失，只是被重新分配到更多節、用更克制的語氣呈現**。

## 3. Shopping Design——媒體識讀自我指涉的立體群像

### 3-1 實際文體形狀：**遞歸放大式機制群像（recursive-scale mechanism portrait）**

錨點動作是「分辨」，但這篇的特殊之處在於論點結構是**遞歸的**：文章教讀者「分辨」是什麼，同時要求讀者最後把這套分辨能力，用回文章討論的對象（雜誌）自己身上。v2 藍圖明寫這個結構：「它把這能力練得越廣、擴成名單與嘉年華，讀者最後越需要把同一套手藝，用回這本雜誌自己」。

### 3-2 論點形態與骨架動作序列

論點：「Shopping Design 真正教會台灣的，不是品味本身，而是「分辨」可以被練成一種能力；它把這能力練得越廣、擴成名單與嘉年華，讀者最後越需要把同一套手藝，用回這本雜誌自己——包括看見它同時在做媒體與生意。」骨架五步（v2）：①立起悖論（「採購」＝品味變動作） → ②找出這能力從哪來（廣告文案出身的編輯） → ③看它怎麼長成一個機制（一期→一年→產業，三級規模階梯） → ④信任邊界（同一張執照上的媒體與廣告） → ⑤交還讀者（誠徵設計封面，讀者反過來分辨這本雜誌）。v2 明寫真依賴：「3 預設 2 的能力；4 預設 3 的規模；5 預設 4 的邊界」。

### 3-3 型別擠壓痕跡：立體群像哪裡不合身

**(a) 三個規模層級天然想各自獨立成節，是面向巡禮最頑固的復發點。** v2 §0 直言 before 版本的病：「已 ship 早期版本（投影前）曾是八個 section 面向巡禮：**中間紙本／BEST100／DesignBIZ 幾乎可互換**」。§3 對此下了硬規：「禁止「紙本」「BEST100」「DesignBIZ」各自升成可 shuffle 的平行 H2；內部順序建議：一期命題 → 一年名單 → 產業活動（scale ladder）」。這揭示一個機構類報導的常見陷阱：機構的「事業擴張史」天生就是一串時間排列的產品／計畫清單，寫手的直覺會是「每個計畫一節」，但這正是面向巡禮的溫床——各節看似有時間順序，實際上互相替換也不影響論證。

**(b) 商業模式揭露（雙重執照）天然想升格成拆穿式脊椎，須被強制降權。** v2 明訂：「**證明鏈權重（v2 編輯室炎上席）**：主脊是「分辨手藝的完成式＝媒體識讀／交還讀者」。業配、雙重執照、信任邊界是**讓立體更厚的一面**，不是 contrarian 拆穿脊椎，也不是論點唯一證明引擎」。這與馬祖案的財務降級、金曲獎的政治材料降級是同一種擠壓：機構類主題裡「這個機構其實也是一門生意／也有黑歷史」的材料，永遠有把整篇文章拉向 Type 2（矛盾驅動）的引力，立體群像要靠明文的權重宣告才壓得住。

**(c) 創辦人／總編輯的個人履歷想長成獨立的雙人小傳。** v2 §3 對此有明確配額：「**履歷預算**：黃／李各最多 1–2 拍服務「可練」；許舜英、《在台北生存》、離任後弧、金鼎獎條目 → 見 §4 砍」。機構傳記型主題常常源自一兩位創辦人的個人事蹟，這些事蹟本身故事性強，容易膨脹成獨立的人物小傳段落，稀釋掉機構論點的主線。

### 3-4 可複製的投影策略（寫成規則）

- **R10／規模階梯三證共一步。** 當機構的成長史是「同一動作在不同規模上重演」（一期→一年→一產業，或馬祖案的空間→時間→名字），這些規模層級必須寫進同一個 H2 內部的段落遞進，不可拆成平行小標。判斷方法：napkin test——把每個規模層級的標題抽出來，若讀者看標題猜不出誰在前誰在後，就是還沒做到規模階梯。
- **R11／陰影 facet 中性命名，不用「掀開／拆穿」動詞。** v2 明文：「中性命名，勿「掀開／拆穿」」。機構的商業模式、財務結構、爭議材料寫進立體群像時，動詞選擇本身要避開偵探敘事語態，用「同一張執照上」「另一面」「也要面對的問題」這類承認式語言，而不是「掀開真相」「拆穿假面」這類揭露式語言。
- **R12／履歷預算制。** 為任何機構主題裡出現的個人（創辦人、總編輯、繼承人）設定明確的「拍數上限」（例：1-2 拍），超過的個人事蹟一律砍或併成一句，防止人物小傳吃掉機構論點的篇幅配額。
- **R13／遞歸結尾——讓讀者對文章對象本身動用文章教的能力。** 這是本篇獨有、值得泛化的技巧：如果文章的論點是「教會讀者一種判斷能力」，結尾可以把這個能力反身指向被寫的對象自己（「你學會了分辨，最後也該拿它來分辨這本雜誌」），比單純總結全文更有推進感，也自然帶出「信任邊界」這個陰影 facet 不需要額外的道德說教。

### 3-5 失敗／勉強點

v2 已是編輯室三席 revise 後的定案版本，本身沒有再被批評為失敗，但 §0 保留的「面向巡禮教材」證明這篇也走過跟馬祖類似的路：**機構主題原生的材料形狀（多個時間點的多個計畫）天生偏向面向巡禮，需要一次額外的「規模階梯」重寫才能收斂**。這跟馬祖 v1→v3→v4 三輪失敗屬於同一族群的病：機構/品牌題材因為材料本身按時間序排列（創刊、BEST100、設計小聚、風格經濟學院、DesignBIZ Fest），寫手的第一直覺幾乎必然是編年體羅列，這是所有機構傳記型主題共有的重力場，不只是馬祖特例。

## 4. 台灣企業：統一企業——沒有投影報告可查的直讀分析

（本篇任務未提供對應投影報告，以下分析純粹來自正文結構逆推，不涉及「v1 病歷」層級的證據。）

### 4-1 實際文體形狀：**容器隱喻雙代傳承群像（container-metaphor generational portrait）**

全文用「容器」隱喻貫穿：開場「它更像一個容器」，中段標題「從一包麵到一座生活圈」，結尾「你走進的是一家便利商店，帶走的卻是一個台南麵粉廠花了半個多世紀、一格一格把「日常」兩個字裝進你生活的證據」。這與馬祖的「借」、Shopping Design 的「分辨」屬於同一種手法：**單一動詞／名詞當隱喻錨，逐節代入不同材料層**。但這篇獨有的結構是把**企業成長史**與**兩代領導人的個人傳記**焊在一起——高清愿創業、60 歲交棒；羅智先接班、60 歲同樣交棒——用「60 歲交棒」這個具體數字，把企業制度史（決不做萬年總經理）跟兩位真人的生命階段做出精確的疊合。

### 4-2 論點形態與骨架動作序列

論點隱含在開場與結尾的呼應句裡，非顯性單句陳述：「早餐配的那顆茶葉蛋、颱風夜煮的那包統一肉燥麵……很大一塊，都是這家台南麵粉廠一格一格裝進台灣人生活裡的」。骨架動作序列：①創業起點（麵粉廠、三好一公道） → ②便利商店線的逆襲（賠七年才轉盈，止血先於展店） → ③把「一間店」變成「一台辦事機器」（ibon、OPEN 小將） → ④觸手伸進生活各個空檔（星巴克、康是美、黑貓宅急便、博客來、夢時代） → ⑤最戲劇性的拼圖：家樂福併購（含價金三階段變化、常見誤會更正） → ⑥兩代人的六十歲交棒 → ⑦中國市場（紀實不下判斷） → ⑧誠實面對陰影：食安風暴＋加盟勞動條件 → ⑨收尾回到「容器」隱喻與開場的颱風夜畫面。

### 4-3 型別擠壓痕跡：立體群像哪裡不合身

**(a) 食安風暴材料具備天然的矛盾驅動／公共議題引力，用「三次中彈都在下游」的精細時間軸把它壓成群像的一個誠實 facet。** 文中明寫這種張力控制：「統一不是那場黑心風暴的主犯，但也不是全身而退的無辜第三方，這兩件事可以同時成立」，並用一個顯性警示框宣告立場邊界：「⚠️ 爭議觀點：把統一在 2014 食安風暴裡的位置講清楚，比選邊站更重要」——這跟金曲獎的「這部分把事情記下來就好」、馬祖的財務降級、Shopping Design 的陰影中性命名，是**同一族的防炎上裝置**，證明機構類主題不論產業（藝術策展、音樂獎、媒體、食品零售），都會在陰影段落遇到同一種型別擠壓，且都靠類似的「顯性宣告灰色地帶、拒絕二元判斷」句式化解。

**(b) 兩代領導人的個人傳記與企業成長史互相纏繞，逼近「品牌傳記＋人物傳記」的雙軌並行，比 Shopping Design 更深。** Shopping Design 用「履歷預算」把創辦人個人事蹟壓到最低（1-2 拍），但統一企業的高清愿與羅智先，兩人的個人生命節點（13 歲當童工、38 歲創業、60 歲交棒；女婿身分、60 歲同樣交棒）**本身就是企業論點的證據**（「決不做萬年總經理」這句企業家規，只有靠兩代人各自六十歲交棒的真實對照才能被驗證），無法像 Shopping Design 那樣壓到最低而不傷論點。這代表機構傳記型主題內部還有一個子判準：**當「創辦人的個人生命節點」本身就是機構論點的直接證據（而非背景裝飾）時，履歷預算規則要放寬，個人傳記與機構傳記必須交織而非分離**。

**(c) 常見誤會更正段落是本篇獨有的技巧，接近「好奇謎題」但功能是防禦性的。** 「大潤發不是統一買的，是全聯福利中心……併購的」、「台灣無印良品……已經不在統一版圖裡」——這類段落不服務「這個機構是什麼」的正面論證，而是清理讀者既有的錯誤認知，功能介於 PROJECTION 七技法裡的「好奇謎題」與一種新的「除錯」功能之間。企業規模夠大、跨足夠多產業時，公眾對「這家公司到底做了什麼」的認知本身就充滿以訛傳訛，這類更正段落是機構傳記型獨有、其他四篇都沒有的一種材料類型。

### 4-4 可複製的投影策略（寫成規則）

- **R14／人事節點與制度論點嚴格對照才能交織書寫。** 只有當「創辦人 X 歲做了 Y」這個個人事實本身就是企業論點（制度、文化、策略）的直接證據時，才允許放寬履歷配額、讓個人傳記與機構傳記交織；否則個人事蹟仍應套用 Shopping Design 式的履歷預算，壓到最低拍數。
- **R15／誤解澄清段落，用來防禦而非論證。** 企業規模夠大、多角化夠深時，主動列出 1-2 個「常見的誤會」（如「不是這家公司做的」）並更正，可以在不服務主論點的情況下，替讀者掃清雜訊，是機構傳記型可複製的專屬技巧，其他四類主題（藝術活動、獎項、媒體）此技巧使用頻率較低（金曲獎僅一處類似「阿Q桶麵不是原住民語演唱人獎」式的正名，統一企業則有兩處完整段落）。
- **R16／灰色地帶要有顯性宣告句，且句式要同時承認正反兩面。** 「不夠壞、也不夠乾淨」這種雙重否定式的判斷句，比單純「有好有壞」更精確，值得作為機構陰影段落收束句的固定句式模板。

### 4-5 失敗／勉強點

因為沒有投影報告可對照，無法確認這篇是否也走過面向巡禮的失敗版本。但正文本身有一處明顯的規模壓力：中國業務段（「海峽對岸的老壇酸菜」）與家樂福併購段（「吃下家樂福，和一張退回 10 億的收據」）都各自帶有完整的、可以獨立成篇的複雜度（併購三階段價金、公平會附加負擔；中港台三本不同財報範疇），這代表企業規模一旦跨足到「三個不同法律主體、三份不同財報」的層級，光靠「容器」隱喻已經開始吃緊——容器隱喻能撐住「統一把日常生活的各種面向都裝進來」這條主線，但撐不住「統一中控是完全不同財報主體、不能混算」這種結構性複雜度，後者需要獨立的說明句（「這篇文章寧可只陳述規模，不掰百分比」），顯示隱喻錨本身在極端規模的機構面前也有覆蓋不到的角落，需要輔助性的「範疇釐清」句法補位。

## 5. 面向巡禮負例檔（AAMA）記錄的教訓

`_negative-facet-tour-AAMA.md` 是編輯室結構席用來訓練辨識面向巡禮的標準反例，六個判準全部故意寫壞，逐條對照真實案例的失敗軌跡，剛好等於一份「面向巡禮體檢表」：

1. **論點=摘要句，無人會不同意**：「AAMA 是台灣重要的創業導師計畫」，檔案自己標註「（故意摘要、無人會不同意。）」——對照馬祖 v1/v2「這套自我敘事的語言」雖然不是摘要句，但一樣犯了「讀者拿不到具體洞見」的病，只是偽裝成有洞見的抽象句，比 AAMA 這種赤裸摘要句更難抓。
2. **骨架是名詞面向、可任意重排**：「創辦人介紹／導師名單／學員成就／基金會組織／年度活動／未來展望」，檔案標註「（各段可互換，互不預設。）」——這正是 Shopping Design before 版「中間紙本／BEST100／DesignBIZ 幾乎可互換」的赤裸版本。
3. **全局功能是事後貼標籤，不是推進鏈上的一步**：每節「全局功能」欄位只是重述段落主題本身（「介紹人物」「介紹導師」「介紹組織」），對照馬祖 v3 §0 診斷第 3 條：「每節都填了「全局功能」欄、gate 五題全打勾，但那些功能是替既有面向找理由，不是先有推進再排 section」——AAMA 檔案示範的正是這種「填了欄位但沒有真推進」的敷衍模式。
4. **減法空白**：「（故意留空——沒做選擇。）」——這條教訓最鋒利：**沒有做出任何取捨，本身就是面向巡禮的鐵證**。四篇真實案例（馬祖、金曲獎、Shopping Design、統一企業）都有大量具體的減法清單（馬祖 v4 §4 列了十幾項砍除材料、Shopping Design v2 §4 有「第二刀」的完整清單），減法的存在與否可以當成快速篩檢面向巡禮的第一道測試。
5. **echo map 錨字空洞、可套用任何主題**：主軸錨只有「重要」二字，各段變奏是「都很重要」——這是最赤裸的警示：一個立體群像若把 echo map 寫成可以套用在任何機構身上的空泛詞（「重要」「珍貴」「不可或缺」），基本上等於承認論點本身沒有特定性。對照馬祖 v4 的錨「借」、Shopping Design 的錨「分辨」、統一企業的隱含錨「容器」——這些字都是**這個機構獨有、換一個機構就套不上的動詞／名詞**，這正是好錨與空洞錨的判準分界。

這份負例檔記錄的核心教訓，可濃縮成一句可操作規則：**判斷一份投影藍圖是不是面向巡禮，不看它有沒有填「全局功能」「扣回主軸」這些欄位（面向巡禮也會填），要看欄位內容能不能通過「套用到另一個同類機構身上是否依然成立」的測試——套得上就是空洞，套不上才是真論點。**

## 6. Lane 級合成：提議新文體型別

四篇真實案例＋一份負例檔顯示同一個更深的結構性事實：**機構／品牌／地方類主題，材料原生形狀（時間序的計畫清單、多屆疊加的活動紀錄、創辦人個人史、爭議陰影）天生具備強烈的面向巡禮引力與 Type 2/3 越界引力，立體群像不是「自然合身」的預設畫布，而是需要一組額外紀律（座標前置、規模階梯、履歷預算、陰影中性命名、灰色地帶宣告句）才撐得住的畫布。** 基於這個發現，提出以下三個新文體／新紀律提案。

### 提案一：認識導覽型（現況判斷：不必獨立成第四型別，但必須成為立體群像對零認知主題的強制前置關卡）

- **名稱**：認識導覽型（Orientation-First Portrait Gate）
- **適用判準**：主題公眾知名度低（觀察指標：一般讀者無法在不查資料的情況下說出「這是什麼規模、誰辦的、在哪裡」），且材料仍支持得起一個統合式洞見（若連洞見都撐不起，見下方「邊界」）。判準可操作化為 v4 揭發的具體提問：「八節讀完，讀者答得出誰辦的／多大量級／哪裡／跟多少人有關嗎？」答不出來就要開這道關卡。
- **論點形態**：不是獨立文體的「另一種論點」，而是立體群像論點種子必須攜帶的**座標配重**——第一節的「全局功能」除了「立起論點本體」，必須同時寫「建立座標」，如 v4 對馬祖 section 1 的判定：「這一節同時回答「長什麼樣」與「這是什麼」——上一版只答了前者」。
- **骨架形狀**：立體群像第一節（把讀者放進現場）內部拆成兩層：物質細節層（具體地點、作品、動作）＋座標數字層（主辦、規模、地理範圍、與居民關係），兩層必須縫在同一段落而非分成正文與側欄。
- **最大失敗模式**：把座標數字獨立成一個側欄／說明框（如馬祖 v3 曾把「給打算去一趟的人」整理成獨立的 `tw-note` 說明框），看似有交代，實際上讀者讀正文時仍然「答不出來」——因為座標被隔離在正文敘事之外，沒有真正被讀者「經歷」到。
- **邊界**：若材料研究深度真的還不足以支撐「有推進的統合式洞見」（例如剛開幕、資料極薄的新機構），則不勉強套用立體群像，直接寫成純粹的認識導覽型獨立成篇——不下論點，只做定向：是什麼、在哪、什麼時候、怎麼去、多少錢，論證退到「這是一份可核對的清單」層級，統合洞見留給資料更厚時的下一次重寫（馬祖走了三版才夠格立體群像即是此路徑的示範）。**不可反過來做**：資料已經夠厚卻只寫認識導覽型，會讓文章停在旅遊指南層級，浪費立體群像本該達到的推進深度。

### 提案二：機構／品牌傳記型（Institutional Biography，區別於人物傳記）

- **名稱**：機構／品牌傳記型
- **適用判準**：主題是一個持續運作的組織（企業、媒體、策展計畫主辦單位），而非單一個人；組織同時具備「對外宣稱的功能/能力」（如 Shopping Design 的「教你分辨」、統一的「容器」）與「內部真實的營運結構」（廣告收入、供應鏈、財報、勞動條件）兩層，且兩層之間存在可寫的張力。
- **論點形態**：「這個機構宣稱／被理解為做 X，而它做 X 的方式本身帶出一個結構性後果 Y（後果可以是正面的規模化、也可以是負面的信任邊界問題），兩者是同一個機制的兩面，不是「優點另外還有缺點」的並列清單。」（對照 Shopping Design：分辨能力放大＝規模化＋信任邊界模糊，同一動作的兩面）
- **骨架形狀**：個人養成期（履歷預算制，1-2 拍，除非個人生命節點本身就是機構論點的直接證據——見統一企業 R14）→ 機制形成（怎麼從單一動作變成可重複的方法）→ 規模階梯（同一動作在不同規模上重演，三證共一步，禁止平行 H2）→ 信任邊界／陰影（中性命名，讓立體更厚而非拆穿）→ 收尾（交還判斷權給讀者，或用灰色地帶宣告句收束）。
- **最大失敗模式**：兩種failure mode 各佔一半案例。(1) **面向巡禮復發**：規模階梯的每一級各自升成獨立 H2（Shopping Design before 版、統一企業的家樂福/中國業務也有這個壓力）。(2) **陰影段落越界成矛盾驅動的脊椎**：財務、業配、食安風暴這類材料因為戲劇性強，容易在寫作過程中不自覺地從「厚度」升格成「整篇真正的論點」，需要 R7/R11/R16 這類顯性防呆句式才壓得住。
- **邊界**：與純人物傳記的分野在於——人物傳記的「個人生命節點」本身就是敘事單位，機構傳記型的「個人生命節點」只有在直接證明機構論點時才進入骨幹（如高清愿與羅智先各自 60 歲交棒，直接證明「決不做萬年總經理」的企業家規），否則一律走履歷預算制降權處理。若主題的「機構」其實只是一個人的作品集合體（無持續組織、無其他成員），應退回人物傳記型，不套用此型。

### 提案三：週期性活動記事型（作為立體群像家族內的專屬骨架子模式，非獨立第四型別）

- **名稱**：週期性活動記事型（Recurring-Edition Chronicle Pattern）
- **適用判準**：主題是按固定週期重複舉辦的活動（藝術節、頒獎典禮、雙年展），材料同時包含「單一屆的具體現場事實」（日期、得獎名單、展點）與「跨屆累積的模式／紀錄」（連莊紀錄、常設作品累積、規則沿革）。馬祖（三屆＋延伸展＋第四屆籌備）與金曲獎（三十七屆歷史＋最近一屆現在進行式）都是這個判準的示範。
- **論點形態**：機構透過「這一屆做了什麼」與「跨屆累積出了什麼」的疊加，逐步定義自己是什麼——論點通常是「這個活動一年一年在回答同一個問題」（金曲獎：「這座島怎麼聽自己」）或「同一個方法在每一屆被重新驗證」（馬祖：「借」的方法論貫穿三屆）。
- **骨架形狀**：情感錨首尾呼應（用最近一屆或最具代表性一屆的具體片刻開場與收尾，R6）→ 中段按跨屆模式而非逐屆編年展開（紀錄保持人、規則沿革、累積留下的常設作品，避免寫成「第一屆…第二屆…第三屆…」的編年體，那會退化成面向巡禮）→ 用一個 `tw-timeline` 類型的視覺化模組承載純粹的屆別事實密度，把敘事段落解放出來去談跨屆模式而非逐屆流水帳。
- **最大失敗模式**：**編年體退化**——最省力也最危險的寫法是逐屆條列（第一屆如何、第二屆如何……），這會直接退回面向巡禮（每一屆可以互換順序、加法不是乘法），是週期性活動材料最大的重力陷阱，也是馬祖 v3 §0 診斷第 2 條點名的「facet 1／facet 2／facet 3」病灶最容易復發的材料類型。
- **邊界**：只處理「屆與屆之間的敘事編排」問題，不是獨立文體——骨架仍然是立體群像的七技法（時代縮影、傳承與世代、不可取代的瞬間尤其吃重），本提案只是把「多屆疊加」形式化成一條專屬的骨架排列建議，供投影階段直接調用，不必每次重新摸索。若活動只辦過一屆或屬於一次性事件（無週期性），不適用本模式，回退到一般立體群像或提案一（認識導覽型）。

### 交叉發現：機構類主題的陰影材料具有跨案例一致的重力模式

四篇案例的陰影段落（馬祖的財務缺口與茶室倫理、金曲獎的兩岸政治材料、Shopping Design 的業配與雙重執照、統一企業的食安風暴與勞動條件）全部展現同一種張力：**這類材料天生具備把整篇文章拖向 Type 2（矛盾驅動）或 Type 3（多觀點立場議題）的重力**，而四個案例的成功處置全部依賴同一族防呆句式——顯性宣告灰色地帶（「不夠壞、也不夠乾淨」）、紀實不評斷框（「這部分，把事情記下來就好」）、中性命名（拒用「掀開／拆穿」）、因果降級為查證缺口（拒用「必然後果」語法）。這組句式已經不只是單篇的寫作技巧，而是**機構類立體群像的通用防炎上元件**，建議獨立收進 EDITORIAL.md 或 PROJECTION.md 作為「陰影 facet 處置四句式」的固定條目，供未來任何機構／品牌類文章直接調用，不必每次重新發明。
