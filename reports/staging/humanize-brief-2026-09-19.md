# 人味重寫工單 — 2026-09-19（哲宇 callout 後三篇同修）

## 觸發

哲宇讀完 9/18 上線的〈誰算低薪〉〈台灣油價機制與中油〉〈金鐘獎〉：

> 「這幾篇有一個共同問題，非常文謅謅，而且讓人難以閱讀，沒有人味。完全不像之前黃魚鴞或是居住正義的專題，會讓人想閱讀，我大概讀到第一個段落就不想看了。」

三篇都過了全部形式閘門（article-health hard=0、prose-health、15 位冷讀者、三輪 release 主編）。閘門守的是「對不對」，沒有一道在問「想不想讀下去」。這份工單只修一件事：**把人味寫回去，事實與腳註一條不動**。

數字密度只是表面。真正的差別：黃魚鴞開場是**一個人在某一天做了一件事，然後發生了一件讓人心裡一沉的事**；三篇新文開場是**一個機關在某一天公布了一組數字**。前者讀者會跟著人走，後者讀者在第一段就被要求記住四個數字和一個職稱。

第二個病灶是**口徑防禦**：冷讀者每問一次「這是哪個口徑」，寫手就在正文多塞一個「本國籍全時受僱員工」「經常性薪資」「稅前批售價」。〈誰算低薪〉第一段這類詞出現七次。精確度每加一分，人味就掉一分——這些限定詞讀者不需要在正文讀到，它們屬於腳註或策展人筆記。

## 正面範例：黃魚鴞的前三段（照這個呼吸寫）

> 1994 年的某一天，孫元勳在花蓮太魯閣砂卡礑溪畔的一棵樹上找到一個巢。崖薑蕨是這座島最大的附生蕨類，粗壯如羽毛的葉片從樹幹四面散開，巢就築在那簇蕨類的中央。巢裡只有一隻雛鳥。等他下次回到這棵樹，雛鳥的父親已被獵人射殺，母鳥棄巢。他把雛鳥帶回家，太太協助照養。後來這隻小鳥野放失敗，送進台北市立動物園，被命名為「嘿美」。
>
> 那是台灣第一個被精確定位的黃魚鴞繁殖巢位。三十年後的今天，孫元勳的研究室追蹤過 91 個領域，但被精確定位的巢位仍是個位數。

短句。一個人。一個動作接一個動作。數字出現時是「一隻」「91 個」「個位數」，每個都扛得起自己的意義。腳註在，但讀的時候感覺不到它。

## 反面範例：誰算低薪現在的第一段（不要這樣）

> 2026 年 9 月 14 日下午四點，主計總處發布 7 月的薪資統計，國勢普查處副處長譚文玲坐在記者面前解釋一組數字：本國籍全時受僱員工 7 月的每月經常性薪資中位數 41,397 元，三分之二是 27,598 元，最低工資是 29,500 元。她的結論是一句話：「低薪的門檻是2萬7598元⋯⋯」

一句話四個數字、一個職稱、一個機關全名，然後一段逐字公文引語。事實全對，讀者已經走了。

## 這次要做的（每篇一隻 fresh Opus 寫手）

1. **重寫開場到第三個 H2 為止的全部散文**，之後各節逐段順一遍。標準是 EDITORIAL §三（前三句決定讀者留不留）+ §六（朋友介紹台灣的口氣）+ §十（念出來）。開場必須是**一個具體的人在一個具體時刻做一件事**，不是機關公布數字、不是名單、不是「先把座標擺好」。
2. **每段最多一個需要讀者記住的數字**；其餘數字退進 `tw-*` 模組、表格或腳註。30 秒概覽保留但重寫成三到四句人話，不超過三個數字。
3. **口徑限定詞（本國籍全時受僱員工／經常性薪資／稅前批售價／獎勵要點／第 N 屆 vs N 年度）在正文第一次出現時用一次人話解釋，之後不再重複**；需要精確口徑的地方用腳註或一則 `> **📝 策展人筆記**` 收。
4. **句長**：平均 35 字以下，一句話一件事。念出來會喘的句子拆掉。
5. **事實與腳註零變動**：不新增主張、不刪腳註（腳註可以從正文句子搬到段尾，但 `[^n]` 一個都不能少、對應的事實不能改）。完稿後跑 `python3 scripts/tools/fact-atom-diff.py`（或 Stage 3.8 定稿站用的同一把尺）對照重寫前後，任何原子不一致就退回。
6. **不要為了人味捏造場景**：MANIFESTO §10 第六型（場景動作細節）是這次最大的風險。可用的「人」只能來自研究報告與現有腳註裡已經有的人與引語（例：低薪那篇有許宇甄、譚文玲、Threads 上「我又拉低平均了」的貼文；油價那篇有雅虎加油站的婦女與陳姓阿嬤；金鐘那篇有 1965 年嚴家淦頒獎、歷屆得主）。沒有人的段落用「你」——朋友介紹的第二人稱——不用捏一個人出來。
7. **冷讀換問題**：派兩位 fresh context 冷讀者（Sonnet），只給重寫後的正文，問三題：(a) 讀到哪一段你想關掉？為什麼？(b) 用三句話跟朋友轉述這篇；(c) 哪一段你會想截圖分享？不問「哪裡困惑」——那把尺上一輪已經量夠了，這次量的是想不想讀。兩位都在第一個 H2 之前沒想關掉才算過。
8. **自檢儀器**（重寫前後各跑一次）：

   ```bash
   python3 scripts/tools/opening-readability.py <file>          # 前四段數字密度 ≤ 5/百字、句長 ≤ 45、口徑詞 < 4；目標往黃魚鴞（1.5 / 31）走
   python3 scripts/tools/article-health.py <file> --check=prose-health   # hard=0
   python3 scripts/tools/prose-flow.py <file>                            # 0 hard
   ```

   注意：金鐘獎現在的開場在這把尺上是 ✅（2.3 / 34），但它的第一段是八家電台的名單、沒有一個人——尺只抓得到數字與句長，抓不到「有沒有人」。所以第 7 條的冷讀者問題才是真正的閘門，儀器只是不讓你往反方向走。

## 不做的

- 不動研究報告、不動投影藍圖的論點、不動 `tw-*` 模組的資料（模組標題可以改口語）
- 不換標題（title 過了 EDITORIAL §Title，先不動；description 可以順）
- 不下架：文章在線上，重寫直接 ship 覆蓋（merge first, polish later）
