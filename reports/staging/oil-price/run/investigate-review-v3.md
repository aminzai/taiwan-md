### 重點親核 1：12.29% 與「10.5＋0.7」（`ey-cpc-20260912.txt` L99）

原文逐字：「依油價公式計算漲幅為12.29%。……政府擴大貨物稅減徵，汽、柴油分別吸收3.7元及2.1元，……台灣中油公司各再吸收6.8元及8.7元，合計汽、柴油各共吸收10.5元及10.8元(附表1)，國內汽、柴油價格各調漲0.7元及0.6元。」

汽油側：3.7（貨物稅）＋6.8（中油）＝10.5（合計吸收），另外牌價調漲 0.7。§11 把「10.5＋0.7＝11.2」定性為「公式價與牌價的累積差距」而非「本週調幅」，這個定性跟原文結構一致——原文明確把「合計吸收 10.5」與「零售價調漲 0.7」分成兩個獨立欄位，10.5 是被吸收掉、沒反映到牌價上的部分，0.7 才是牌價本身的漲幅，兩者相加才等於公式全額反映的差距。§11 也明說「新聞稿沒有列算式」，未過度推論，**核對通過**。

### 重點親核 2：經濟部「油氣」vs 自由時報「汽柴油」（`ey-moea-4217.txt` L99–101、`ltn-budget-breakdown.txt` L88）

`ey-moea-4217.txt`：「共編列1,809.35億元以補貼價差。其中，補助台灣中油公司吸收未足額調升油氣所需經費 1,014.31 億元，補助台電公司至8月底能源成本價差711.04億元，及補助國內桶裝瓦斯生產業者84億元。」——前句脈絡「穩定汽柴油、天然氣及家用液化石油氣價格」，1,014.31 億本身用字是「油氣」，語意含糊（中油同時賣汽柴油與天然氣）。

`ltn-budget-breakdown.txt` L88：「經濟部次長賴建信在行政院院會後記者會指出」段落前一句：「包含補貼中油汽柴油凍漲經費1014億元」——這是自由時報記者的敘述句（緊鄰賴建信記者會段落），用字是「汽柴油」，較窄。

兩份文本對同一筆 1,014.31（1014）億的用字確實不同（「油氣」vs「汽柴油」），且兩者出處不同（經濟部書面稿 vs 自由時報記者會報導），§11 沒有斷言哪個對，只寫「兩份官方說法未對齊」「兩說並存、不斷言」，**核對通過**，用字忠實反映來源差異。

### 重點親核 3（本評閱主要發現）：§8.A 逐週表 6/20–7/18「五週中油欄吸收 0」

§8.A 完整表格（行 501–505，欄位依表頭為「亞鄰＋專案平穩吸收」＝ §11 所稱「中油自己那欄」）：

| 公布日     | 生效區間  | 亞鄰＋專案平穩吸收 | 累計吸收          |
| ---------- | --------- | ------------------ | ----------------- |
| 2026-06-20 | 6/22-6/28 | 0/0                | 約177億（峰值）   |
| 2026-06-27 | 6/29-7/5  | 0/0                | 約172.6億         |
| 2026-07-04 | 7/6-7/12  | 0/0                | 約167.1億         |
| 2026-07-11 | 7/13-7/19 | 0/0                | 約160.7億         |
| 2026-07-18 | 7/20-7/26 | **0.3/1.1**        | 約155.6億（低點） |

§11 第 3 條原文：「§8.A 逐週表 6/20–7/18 五週，中油自己那欄吸收為 0（降價已反映），累計數卻由 177→172.6→167.1→160.7→155.6。」

**核對結果：不準確。** 五個累計數字（177/172.6/167.1/160.7/155.6）對應的五個公布日確實是 6/20、6/27、7/4、7/11、7/18，但「中油自己那欄吸收為 0」只對前四週（6/20–7/11）成立；第五週（7/18 公布，生效區間 7/20–7/26）的「亞鄰＋專案平穩吸收」欄位是 **0.3／1.1**，不是 0。也就是說產生 155.6 億（本輪最低點）這個數字的那一週，中油其實有恢復吸收（汽油 0.3 元、柴油 1.1 元），並非「吸收為 0 而累計數仍下降」。

這條錯誤同步出現在本次交件的 investigate claim #12：「累計吸收 6/20–7/18 五週中油欄吸收 0 而累計數下降」，以及該 claim 的 `support` 欄「逐字一致」——這個定性對第五週不成立。

**影響評估**：底層洞察（累計吸收金額是「預估」值、非逐週增量加總、6 月下旬至 7 月中旬因牌價實際調降而真實走低）本身有 §8.A 執行摘要與逐週表充分支持，不受影響；甚至第五週吸收轉正卻累計仍下降，是比「五週皆 0」更值得寫的現象（更能證明「預估」而非流水帳）。但「五週吸收為 0」這個具體敘述本身是誤讀了自己整理的表格，屬於可核對、可修正的事實錯誤，不是「官方未解釋」的缺口類型，而是本報告內部數據不一致。這正是本輪冷讀回修的目標（把冷讀者抓出的可疑推論改成可查證的陳述）卻在同一輪產生的新的可查證錯誤，建議退回修正：把「五週」改為「四週吸收 0＋第五週轉為 0.3/1.1 但累計仍降」，或至少拿掉「五週皆為 0」這句。

## (c) 是否有把「官方未寫」推成機制斷言

檢查 claim #12 的 `doesNotSupport` 欄：「不支持任何對 3.7 vs 3.415 差距的機制推測（營業稅等）；不支持「每週重算」的機制描述（只能說週報稱預估）；不支持「回收條款尚未啟動」（週報未寫）；不支持「杜拜一向較布蘭特便宜」（本輪未查）」。

四項都明確列出「這條不支持什麼」，且對照 §11 正文（第 2、3、4、7、8 條），正文用字確實都停在「未解釋」「未寫」「未對齊」層次，沒有把缺口偷渡成機制斷言（例如沒有寫「因為營業稅另計所以差 3 毛」、沒有寫「每週重算」是官方說法、沒有寫「回收條款已啟動或未啟動」）。**這部分核對通過，符合「陳述缺口、不推測」的紀律。**
