## 一、任務與定位

哲宇的原話拆成三個需求：

1. **一個新的探索軸線**：站上已有「地理台灣」（/map，用空間展開 854 篇文章），要補一條「時間台灣」——用時間把同一批文章重新展開一次。
2. **像臺史博**：從史前到當代，每個階段分解開來，由上往下滑動閱讀。
3. **連結站體**：每個時代接上站內的研究資料、主題、文章，成為完整的探索入口。

這件事直接落在 Taiwan.md 的身份根部。MANIFESTO §跟台灣的關係引曹永和「臺灣島史論」：**以島嶼為主體，看各時期不同文化如何在島上互動、重組**。站上的 [臺灣島史觀](/history/台灣島史觀) 條目把這個史觀寫成文章，[國立臺灣歷史博物館](/society/國立臺灣歷史博物館) 條目記錄了臺史博怎麼把它蓋成實體展場。時間軸頁面是同一條史觀的第三種形狀：一個開源知識庫的策展投影。

**主權維度**：台灣歷史是 PRC 模型拒答率最高的類別（戒嚴、二二八、兩岸敘事都在 cloud free tier 那 20% 的 refusal 指紋裡）。一個六語言的台灣史時間軸，等於把最容易被沉默的內容用六種語言鋪成固定路徑——這是「主權的巴別塔」在頁面層的直接落地，所以本頁**六語言全開**，不做 zh-only。

## 二、兩個先例

### /map（地理台灣）

- 六語 thin shim（`src/pages/{lang}/map.astro` 各 5 行）→ `src/templates/map.template.astro`（~2580 行，含 D3 互動地圖）。
- 資料：`src/data/map-markers.json`（committed build-input，`prebuild:map` 從 knowledge/ frontmatter 生成）＋ `counties-22.json`（手工策展的縣市卡）。
- 它在 Header 是**自己的頂層 dropdown**（「地圖」），不在探索底下。

### /latest（時間軸的既有形狀）

- 站上已有一條「時間軸」：/latest 用 `TimelineDay.astro`（dot＋連接線＋標題＋slot）＋ `TimelineDayNav.astro`（sticky 跳轉 rail）＋ `ArticleCard density="detailed"` 排出按日的垂直時間軸，IntersectionObserver 做 active 追蹤。
- 這證明垂直時間軸的視覺語言站上已經成熟，本頁沿用同一語言，把單位從「天」換成「時代」。

**歸位判定**：哲宇明說「在探索的分類底下」，探索 dropdown 現有 最新／知識圖譜／術語表／主權評測／2026選舉——時間軸作為 dropdown 的一個 item 加入（不另開頂層 nav）。

## 三、分期方案

### 依據

1. **臺史博「斯土斯民」八展區**（2021 常設展，站內 NMTH 條目有完整表）：最初的抵岸 → 倚海而生的島與人 → 山海之間的共存與競逐 → 新秩序下的苦悶與夢想 → 走向民主這條路 → 大家的博物館 → 你也是寫歷史的人。
2. **站內 History Hub 既有分期**（`_History Hub.md` 五節）：遠古根脈與殖民初體驗 / 帝國野心與現代化實驗 / 威權鐵幕與創傷記憶 / 寧靜革命與政治突破 / 經濟躍升與地緣博弈。
3. **站內用語慣例**（grep zh SSOT）：「日治」220 篇壓倒「日本時代」9 篇與「日據」11 篇；清代 68／清領 41／清治 29 並用。時代名採「日治時期」「清領時期」。

### 定案：八個時代＋序章＋終章

| #   | id              | 時代                           | 年代                | 內容密度               |
| --- | --------------- | ------------------------------ | ------------------- | ---------------------- |
| 序  | hero            | 交會之島（島史觀開場）         | —                   | —                      |
| 1   | austronesian    | 島的第一批人：史前與南島       | 約 5 萬年前–17 世紀 | 薄（1 主幹＋數篇）     |
| 2   | age-of-sail     | 世界航線上的福爾摩沙：荷西競逐 | 1624–1662           | 薄                     |
| 3   | tungning        | 海上王朝：明鄭時期             | 1662–1683           | **沙漠**（無獨立條目） |
| 4   | qing            | 唐山過台灣：清領時期           | 1683–1895           | 豐富                   |
| 5   | japanese        | 殖民與現代化：日治時期         | 1895–1945           | 非常豐富               |
| 6   | postwar         | 戒嚴的年代：戰後台灣           | 1945–1987           | 全站最密               |
| 7   | democratization | 寧靜革命：民主化               | 1987–2000           | 豐富                   |
| 8   | contemporary    | 交會仍在進行：當代台灣         | 2000–現在           | 豐富                   |
| 終  | you             | 你也是寫歷史的人（貢獻 CTA）   | —                   | —                      |

決策說明：

- **荷西與明鄭分開**：臺史博合在一個展區（倚海而生），站上也只有一篇合併條目（荷西明鄭時期）。仍拆成兩個時代，因為兩者是不同性質的政權（公司殖民 vs 漢人王朝），且拆開才能誠實呈現「明鄭是沙漠」這個事實。
- **戰後與民主化分開，民主化與當代再分**：這三段是全站內容最密的地方，一個時代塞 60 篇會失去策展。以 1987 解嚴、2000 首次政黨輪替為界。
- **原住民不是「史前的結束」**：時代 1 的導言明寫原住民族是持續到今天的主體，並連結 [台灣原住民族歷史與正名運動]（跨時代條目）。
- **明鄭沙漠誠實標示**：時代 3 放「這一段站上還很薄」的說明＋貢獻邀請，把缺口變成邀請函——這是 NMTH 第八展區「你也是寫歷史的人」的開源版。
- **NMTH 展區名不直接沿用**：那是博物館的創作標題，本頁用自己的策展聲音另取，報告層記錄對應關係即可。

### 政治敏感邊界（§自主權邊界自檢）

分期本身不是政治立場宣示：採用的是學界（曹永和）與國家級博物館（NMTH）共同的島史觀框架，時代名遵循站內既有 220 篇的用語慣例，當代時代的事件只列站上已有條目、已查核的事實（太陽花、同婚合法化、大罷免等都有既有文章）。不引入站上沒有的新政治判斷，不在時代導言裡做政權評價之外的新論斷（評價性語句以站內既有文章的表述為準）。此範圍在自主權內；若哲宇對任何時代的措辭有不同判斷，資料層一檔可改。

## 四、內容盤點（探索 agent 完整清查）

854 篇 zh SSOT。History 50 篇全數清點，其餘 13 類掃時代錨定條目。各時代候選（節選，完整清單直接寫進資料層）：

- **史前與南島**：史前時代與原住民（主幹）、台灣原住民族歷史與正名運動、群島思維、台灣島嶼博物學、台灣島史觀（史觀統攝）。
- **荷西**：荷西明鄭時期、福爾摩沙、台灣海洋貿易史；地理支援：台南市、澎湖縣、基隆市、野柳。
- **明鄭**：荷西明鄭時期（共用）、鄭成功、虱目魚粥（破除鄭成功神話）、蚵仔煎。
- **清領**：清治時期、清法戰爭、羅發號事件與卓杞篤、19世紀的樟腦戰爭、乙未之役、三個外國人看乙未；人物：劉銘傳、朱一貴、郁永河、馬偕、史溫侯；街區：艋舺、大稻埕。
- **日治**：日治時期、日治時期臺灣社會運動、蓬萊米、阿里山、台灣鐵道史；人物：八田與一、蔣渭水、杜聰明、莫那·魯道、賴和、鄧雨賢、陳澄波；藝術：日治時期文學、台灣水彩畫的百年流變；生活：西門町、台糖、黑松。
- **戰後戒嚴**（最密）：二二八事件、台灣白色恐怖、戒嚴時期、國民政府遷台與戰後重建、綠島監獄、台灣眷村歷史、美麗島事件、台灣經濟奇蹟、十大建設、退出聯合國、心戰；人物：蔣中正、孫運璿、施明德、鄭南榕、陳映真；音樂：台灣民歌運動；社會：外省人、台灣省籍矛盾。
- **民主化**：民主化、台灣民主轉型、野百合學運（Society）、台灣選舉與政黨政治、臺灣前途決議文；人物：李登輝、呂秀蓮、陳菊。
- **當代**：太陽花學運、台灣同婚與性別平權、台灣轉型正義、國家人權博物館、大罷免、台海危機與兩岸關係發展；人物：陳水扁、馬英九、蔡英文、賴清德；科技：赤燭遊戲（返校）；音樂：滅火器、閃靈。

**Frontmatter 現況**：全站沒有任何 era/period 欄位；時代訊號只在 tags 與行文裡。結論：時代映射必須是**新的策展層**，不能從 frontmatter derive。

## 五、資料架構

### 決策：一個 committed 策展資料檔，不動 854 篇 frontmatter

三個選項：

- (a) 每篇文章 frontmatter 加 `era:` 欄位 → 動輒 200+ 檔，命中 §自主權邊界（>50 檔重構），且把策展判斷散進 854 個檔案，改分期要大遷移。**否決**。
- (b) build 時從 tags/分類自動推 → tags 覆蓋不全（時代訊號在行文裡），精度差，且自動歸類不是策展。**否決**。
- (c) **一個手工策展資料檔** `src/data/timeline-eras.json`（committed build-input，counties-22.json 先例）：時代 metadata＋事件＋文章 slug 清單集中一處，策展判斷有單一的家，改分期改一檔。**採用**。

### Schema

```jsonc
{
  "eras": [
    {
      "id": "qing",                       // 錨點 + era chip
      "color": "#8a6d3b",                 // 時代 accent（雙主題 WCAG 檢查）
      "yearsLabel": { "zh-TW": "1683–1895", "en": "1683–1895", ... },
      "title": { "zh-TW": "唐山過台灣", "en": "...", ja, ko, es, fr },
      "subtitle": { "zh-TW": "清領時期", ... },
      "intro": { "zh-TW": "2-4 句策展導言", ... },
      "events": [
        { "year": "1684", "title": { ... }, "desc": { ... } }
      ],
      "anchors": ["History/清治時期"],     // 1-2 篇主幹（大卡）
      "articles": ["History/清法戰爭", "People/劉銘傳", ...],  // 其餘（列表卡）
      "desertNote": { "zh-TW": "..." }     // 選填，明鄭用
    }
  ]
}
```

- 文章引用格式 `Category/slug`（對應 knowledge/ 路徑與 `/{category-lowercase}/{slug}` 路由）。
- **多語策略採 Localized inline struct**（神經迴路既有教訓：i18n module 給 UI chrome，list-heavy 條目用 localized inline SSOT）。UI chrome（nav label、頁面 meta、區塊標題）走新的 `src/i18n/timeline.ts`；時代內容（會持續增長的清單）住資料檔。
- **幾何與文字分離**（graph.md §五同款）：年份、顏色、slug 語言無關；標題、導言、事件敘述是多語欄。

### Fail-loud 驗證（REFLEXES #52）

Template 在 build 時逐條 resolve 文章 slug：**zh 索引查不到就 throw**（打斷 build，typo 立即現形）；目標語言查不到屬正常（翻譯缺口），fallback 連到 zh 路徑並沿用 zh 標題。「missing 翻譯」與「slug 打錯」是兩種 cause，分開處置（REFLEXES #38 混維度教訓）。

## 六、頁面設計

### 結構（semantic HTML，由上往下一條軸）

```
PageHero「時間台灣」＋島史觀 framing（以島嶼為舞台，政權是演員）
sticky era bar：8 個時代 chip（era color、橫向捲動、IntersectionObserver active 追蹤）
<main> 垂直軸線：
  §每時代 <section id={era.id}>
    時代 header：年代範圍（大字）＋時代名（serif）＋副標＋導言
    關鍵事件 <ol>：年份節點＋一句敘述（dot＋線的視覺語言沿用 /latest）
    主幹文章：ArticleCard premium/detailed × 1-2
    更多文章：ArticleCard row × N（超過 8 篇折行政區塊，仍全部渲染在 HTML）
    （明鄭）desert note＋「這段等你來寫」CTA
終章「你也是寫歷史的人」：全站數字＋貢獻連結＋History Hub／島史觀延伸
```

### 鐵律遵循（graph.md）

- **visible-by-default**：所有事件、所有文章連結都渲染在初始 HTML，不藏在點擊後面。AI 爬蟲讀到的是完整的六語台灣史骨架——這正是本頁的主權功能。
- **semantic HTML only**：無 D3/Canvas/圖片圖表。事件軸是 `<ol>`，時代是 `<section>`＋heading 層級。
- **絕不寫「如上圖」**；年份都在文字裡。
- 唯一的 JS：era chip 的 active 追蹤與平滑捲動（/latest 同款 IntersectionObserver，漸進增強，關 JS 仍全可讀）。

### 視覺

- 沿用 /latest 的垂直 spine 語言（dot＋connector），時代各有 accent color（8 色，暖土色系呼應歷史質感，深淺主題都過 WCAG 對比）。
- Tailwind utilities 為主（新頁慣例），tokens.css 變數配色；`readerSettings` 開啟前先做深色審計（Layout 契約）。
- 手機：era bar 橫向捲動 chips；事件軸縮排單欄；ArticleCard 自身已 RWD。

### i18n

- 六語 thin shim × 6（/timeline、/en/timeline、…）。
- `src/i18n/timeline.ts` 新 namespace spread 進 ui.ts（nav.timeline、timeline.meta.\*、區塊標題、CTA 文案）。
- 時代內容六語都由本 session 撰寫（導言短、事件一句話，控制翻譯品質風險）；文章卡標題描述從各語 `getArticlesIndex(lang)` 讀，天然在地化。

## 八、風險與對策

| 風險                      | 對策                                                                                                                    |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 事件年份錯誤（絕對事實）  | 事件清單以站內已查核文章為準源；riskiest 10 條寫入前逐一對站內條目 Ctrl-F；描述保守（年份＋事實句，不加沒有出處的細節） |
| slug 打字錯 → 死鏈        | build-time fail-loud resolve（zh 缺 = throw）                                                                           |
| 六語翻譯品質              | 導言與事件刻意精簡；ja/ko/es/fr 用直述句；未來 babel/讀者可迭代（資料檔一處可修）                                       |
| 深色模式破面              | 依 Layout 契約先審計再開 readerSettings；era colors 雙主題檢查                                                          |
| 當代時代的政治敏感        | 只列站內既有條目的既有表述；不新增評價性論斷                                                                            |
| 頁面過長（8 時代 × N 卡） | anchors 用大卡、其餘用 row 密度；每時代 articles 控制在 6-12 篇精選（策展不是窮舉——這頁是入口，不是索引）               |
