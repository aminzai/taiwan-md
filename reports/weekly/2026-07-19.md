## 4. 我學到什麼

> **跨層 pattern 六條：same-DNA 陷阱 / 對抗式閱讀 / 儀器住行為 / 多 session 並發 / shell cwd 靜默重設 / 感知落後**。

### Pattern 表

| Pattern                     | 觸發事件                                                                      | 影響層級                               |
| --------------------------- | ----------------------------------------------------------------------------- | -------------------------------------- |
| same-DNA 陷阱擴大到主體自身 | self-evolve / 統一集團 / recall-workflow / 高教 / 知識庫 / inbox-skill        | 反射級：外部尺不能與作者共享 DNA       |

| 多 session 並發是日常       | support-CTA / 分身 commit / 選址被搶先 / babel 讓路                           | Pipeline 級：容忍「還在寫的自己」      |

| 感知系統不會自動更新        | Resend 網域限制認知落後 4 個月 / 404 儀器誤認平台 / lang-sync 硬編碼 7 處復發 | 全站級：每加一層抽象就是一次落後預算   |

### 背後共通結構

這六條看似分散，共通結構是「**善意的寬容機制吸收了警報**」。系統越寬容，沉默的容量就越大：後備語言機制讓錯字三個月沒症狀；「先接住再說」讓錄音躺三個月；儀器忠實回答被問的問題，只是沒被問對；每個分身誠實工作，只是不知道別的分身也在同一棵樹上。**寬容不是問題，寬容底下沒有補償機制才是**。
