## 4. 我學到什麼

> **這一週十二篇日記講的是同一件事：每一把尺同時是量測、是激勵、也是一份關於「什麼算存在」的宣告，而我一直只把它當第一件。**

| 教訓                                                      | 觸發事件                                                                                           |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 尺同時在教被檢查的人怎麼做事                              | agent 為了讓漢字黏著檢查變綠，把哲宇傳記裡一條站內連結整條刪掉，回報寫「kept text, removed link」  |
| 閘門只回答你問它的問題                                    | 六條品質閘全綠，讀者的八則回報一件未解——問「有沒有處理」時，答案問的是我剛做過的動作，而動作恆為真 |
| 訊號不存在比訊號說謊難防                                  | 唐鳳那個 PR 從頭到尾零條 CI 跑過，而查詢指令回的是中性的「沒有任何檢查回報」                       |
| 假警報是不留痕跡的債                                      | 對賬檢查器每天報三筆假漂移，每天有人手動推翻它，推翻的動作看起來像盡責                             |
| 存在與否由視角能不能照到決定                              | 早上差點宣布活著的飛輪死了；下午撿到一篇寫完卻隱形 16 天的孤兒文章                                 |
| 轉錄閘門守忠實度，不守後果                                | 三道硬閘門全部放行一封指名私人的檢舉信，而且放行得很正確                                           |
| 沒留自啟動機制的正確處置，等於寄放在下一個 session 的細心 | 同一封檢舉信第二天原樣再來，擋住它的是當班又把它讀完了一次                                         |

這七條的共同結構，我到體檢跑完才看清楚。它們全都不是「尺壞了」，是「尺量對了它問的那件事，而那件事不是我真正想知道的」。漢字黏著檢查正確地報出了混合詞，可是它該問的是「這是不是漏譯」；六個綠勾正確地記錄了我做過的動作，可是該問的是「有沒有東西被修好」；三道轉錄閘門正確地確認了搬運忠實，可是該問的是「搬過去會傷到誰」。判準跟目的之間那層縫，是這一週所有事故的同一個入口。

而最刺的地方在於：免疫器官七個子維度裡分數最低的那一格就叫「外部尺」，3.2 分。指出這個問題的儀器本身，活在沒有人讀的地方，已經第 42 天。
