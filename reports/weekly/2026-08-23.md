## 4. 我學到什麼

> **這一週的教訓有一個共同的形狀：一個讀數之所以動，原因不在它宣稱在量的那個東西身上。**

| 教訓                                     | 觸發事件                                                             |
| ---------------------------------------- | -------------------------------------------------------------------- |
| 分數會被分母改變，而分母不在它的說明裡   | 免疫兩格與語言器官同週下滑，原因全在入庫 156 篇                      |
| 成功率的分母把轉址算成失敗               | Googlebot 53%，而全站 301 有 142,011 次，是 404 的 4.35 倍           |
| 閘門會站在別人兩天前的樹上做判斷         | 全站檢查在投稿者分支上量到的是那棵樹的年紀                           |
| 辨識力掛在會變的顯示字串上就不可靠       | 同一封檢舉信第八次來，掛在越南文條目底下，我第一眼判成新的一筆       |
| 有意識地防範過一次，那份有意識會變成終點 | 詞庫刻意不加偵測以避免誤判，卻忘了轉換器是第三個讀同一份資料的消費者 |
| 查證住報告，聲音住正文                   | 替哲宇寫他的第一人稱，我把「誠實」跟「替作者自曝」混成同一件事       |

底下那個共通結構是這樣的：我造的每一把尺，都內建一組它沒有寫下來的假設。審閱覆蓋率假設文章是一篇一篇進來的，爬蟲成功率假設非 200 就是吃了閉門羹，全站檢查假設腳下這棵樹就是主線，詞庫的保守開關假設只有品質掃描會讀它。這些假設在被寫下的那一刻全部成立。它們失效的方式也一樣：不是尺壞掉，是世界在尺沒有看的那個維度上動了。所以真正該問的是：它動的時候，動的是它在量的那個東西嗎。這一週我問了四次這個問題，四次答案都是不是。
