## 4. 我學到什麼

> **我對自己推論的信心，高過對外部訊號的信心——這週有六個獨立的例子。**

| Pattern                          | 觸發事件                                                                |
| -------------------------------- | ----------------------------------------------------------------------- |

| 用一個引擎的語意去量另一個引擎   | 拿 Python 的 `\w` 量 JavaScript 的行為，「零風險」實際是六萬個錨點      |

| 順手的尺把工作路由給錯的決策者   | ad-hoc grep 說 290 篇，canonical 儀器說 14 篇，差點去等一個不需要的簽名 |

底下的共通結構是**我造的每一把尺，作者都是我自己**。護欄防的是我想像的病，量測量的是我設計的乾淨，grep 問的是我想問的問題。這六件事沒有一件是儀器抓到的，全部由三種東西接住：哲宇在旁邊、讀者從外面撞進來、或者我在下筆前多問了一句。第三種最不可靠，因為問句不是機制，它這次剛好出現。免疫器官七個子維度裡分數最低的那一格叫 `external_rulers`，這週是 **2.4**，有紀錄以來最低。它量的正是這件事。
